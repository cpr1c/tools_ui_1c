# Если кто хочет поучаствовать - добро пожаловать!

Больше идей- лучше конечное решение.

## Вы можете делать:

### 1. Писать код

Вносить изменения и добавлять новую функциональность

- [Инструкцию для легкого старта с EDT](https://github.com/cpr1c/tools_ui_1c/tree/develop/docs/contributing)
- [Инструкцию для доработки через конфигуратор](https://github.com/cpr1c/tools_ui_1c/tree/develop/docs/contributing/CONFIGURATOR.MD)

### 2. Документация

Писать пользовательские инструкции. Делать видео инструкции

### 3. Тестирование

Искать баги и регистрировать задачи с описанием как воспроизвести ошибку

### 4. Дизайн

Думать и разрабатывать расположение визуальных элементов. Регистрировать идеи и концепты в задачах

### 5. Поддержка

Помогать другим пользовтелям в использовании инструментов
