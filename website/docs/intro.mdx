# О подсистеме

**Универсальные инструменты 1С** — подсистема с набором обработок для разработчиков и администраторов систем на базе платформы 1С:Предприятие 8. Предназначена для управляемых форм.

## О продукте

Подсистема объединяет десятки полезных инструментов в единый интерфейс: консоли запросов и кода, редакторы данных, средства администрирования, обмена и отладки. Многие инструменты — адаптированные форки проверенных решений сообщества с разрешения авторов.

## Системные требования

| Параметр  | Значение                                       |
| --------- | ---------------------------------------------- |
| Платформа | 1С:Предприятие **8.3.12** и выше               |
| ОС        | Windows x86/x64, Linux x86/x64                 |
| Клиент    | Толстый и тонкий клиент; веб-клиент — частично |
| Режим     | Без модальности и синхронных вызовов           |

## Способы поставки

- **Расширение конфигурации (CFE)** — основной способ для постоянного использования
- **Портативная обработка (EPF)** — для разовых задач и отладки без установки расширения

## Лицензия

Подсистема распространяется под лицензией [GNU GPL v3.0](https://github.com/cpr1c/tools_ui_1c/blob/master/LICENSE). Код открыт: можно копировать и распространять с сохранением открытости исходного кода.
