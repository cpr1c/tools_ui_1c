# Отладка запроса через УИ_._От

**Сценарий.** Сложный запрос с несколькими соединениями и временными таблицами возвращает неожиданный результат. Нужно увидеть, какие данные реально попадают в каждую временную таблицу и каков финальный результат.

## Шаг 1. Написать запрос в коде

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
 |    Товары.Ссылка КАК Товар,
 |    Товары.Код КАК КодТовара,
 |    Остатки.КоличествоОстаток КАК Остаток
 |ПОМЕСТИТЬ ВТ_ТоварыСОстатками
 |ИЗ
 |    Справочник.Номенклатура КАК Товары
 |        ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ОстаткиТоваров.Остатки() КАК Остатки
 |        ПО Товары.Ссылка = Остатки.Номенклатура
 |ГДЕ
 |    Товары.ЭтоГруппа = Ложь";

Запрос.МенеджерВременныхТаблиц = Новый МенеджерВременныхТаблиц;
```

## Шаг 2. Добавить отладку

```bsl
Запрос2 = Новый Запрос;
Запрос2.МенеджерВременныхТаблиц = Запрос.МенеджерВременныхТаблиц;
Запрос2.Текст =
"ВЫБРАТЬ
 |    ВТ_ТоварыСОстатками.Товар,
 |    ВТ_ТоварыСОстатками.КодТовара,
 |    ВТ_ТоварыСОстатками.Остаток
 |ИЗ
 |    ВТ_ТоварыСОстатками КАК ВТ_ТоварыСОстатками
 |ГДЕ
 |    ВТ_ТоварыСОстатками.Остаток < 10";

УИ_._От(Запрос2, "Товары с остатком менее 10");
```

## Шаг 3. Открыть данные в тонком клиенте

После выполнения кода откройте форму **Данные для отладки** через меню **Универсальные инструменты → Данные для отладки**. Найдите запись с комментарием «Товары с остатком менее 10».

## Шаг 4. Просмотр результата

В открывшейся форме доступны:

- **Результат** — итоговая выборка запроса
- **Параметры** — все переданные параметры
- **Временные таблицы** — содержимое каждой временной таблицы, созданной в процессе выполнения
- **Текст запроса** — полный текст с подсветкой синтаксиса
