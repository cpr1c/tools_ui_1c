# Создание прототипа формы

**Сценарий.** Требуется быстро спроектировать форму нового документа «Заявка на закупку» для согласования с заказчиком до написания кода.

## Шаг 1. Открыть редактор прототипов

Меню **Универсальные инструменты → Редактор прототипов форм**.

## Шаг 2. Разместить элементы

Создайте новую форму и добавьте следующие элементы:

| Элемент | Тип | Свойства |
| ------- | --- | -------- |
| Шапка документа | Группа | Заголовок: «Заявка на закупку № _» |
| Дата | Поле ввода | Заголовок: «Дата» |
| Автор | Поле ввода | Заголовок: «Автор» |
| Статус | Поле выбора | Список: «Новая, На согласовании, Утверждена, Отклонена» |
| Товары | Таблица | Колонки: Номенклатура, Количество, Цена, Сумма |
| Комментарий | Поле ввода | Многострочное |
| Кнопки | Панель | «Записать», «Провести», «Печать» |

## Шаг 3. Генерация кода

Нажмите **Сгенерировать код**. Редактор создаст готовый код формы для 1С, который можно скопировать и вставить в конфигуратор. Например, фрагмент описания элементов:

```bsl
Элементы.ГруппаШапка = Форма.Добавить(Тип("ГруппаФормы"), "ГруппаШапка");
Элементы.ГруппаШапка.Вид = ВидГруппыФормы.ОбычнаяГруппа;
Элементы.ГруппаШапка.Заголовок = "Заявка на закупку № _";

Элементы.Дата = Форма.Добавить(Тип("ПолеФормы"), "Дата");
Элементы.Дата.Заголовок = "Дата";
Элементы.Дата.ПутьКДанным = "Объект.Дата";
```

## Шаг 4. Экспорт

Готовый прототип можно экспортировать в формат 1С и открыть прямо в конфигураторе для дальнейшей доработки.
