# Сравнение данных из двух баз

**Сценарий.** Сравнить элементы справочника «Номенклатура» в рабочей (тест) и эталонной (промышленная) базах, чтобы найти расхождения перед выгрузкой.

## Шаг 1. Открыть Консоль сравнения данных

Меню **Универсальные инструменты → Консоль сравнения данных**.

## Шаг 2. Настроить источники

**Источник А — текущая база 1С 8:**
- Тип: **Текущая база 1С 8**
- Запрос:
```bsl
ВЫБРАТЬ
    Номенклатура.Ссылка КАК Ссылка,
    Номенклатура.Код КАК Код,
    Номенклатура.Наименование КАК Наименование,
    Номенклатура.СтавкаНДС КАК СтавкаНДС
ИЗ
    Справочник.Номенклатура КАК Номенклатура
```

**Источник Б — внешняя база через COM:**
- Тип: **База 1С 7.7 / 8 (COM-соединение)**
- Строка соединения: `File="\\server\bases\production";`
- Запрос: аналогичный запрос по той же структуре

## Шаг 3. Настроить ключи сравнения

Добавьте поле **Код** как ключевое. Консоль будет сопоставлять строки по коду номенклатуры.

## Шаг 4. Выполнить сравнение

Нажмите **Сравнить данные**. Результат покажет:

- **Совпадают** — строки, идентичные в обоих источниках
- **Различаются** — строки с разными значениями полей
- **Только в А** — элементы, присутствующие только в тестовой базе
- **Только в Б** — элементы, присутствующие только в промышленной базе

По строкам с расхождениями можно перейти к просмотру различий по каждому полю.
