# Массовое редактирование справочника

**Сценарий.** В справочнике «Номенклатура» необходимо установить ставку НДС 20% для всех товаров, у которых ставка НДС не заполнена.

## Шаг 1. Открыть групповую обработку

Перейдите в меню **Универсальные инструменты → Групповая обработка**.

## Шаг 2. Выбрать объект обработки

В поле «Объект обработки» укажите **Справочник.Номенклатура**.

Установите отбор: `НДССтавка = Неопределено` — чтобы обработать только позиции без заполненной ставки.

## Шаг 3. Настроить действие

В блоке «Обработка» напишите код:

```bsl
Объект = Ссылка.ПолучитьОбъект();
Объект.СтавкаНДС = Перечисления.СтавкиНДС.НДС20;
Объект.Записать();
```

## Шаг 4. Запустить обработку

Нажмите **Выполнить**. Подсистема обработает все элементы, попавшие под условие отбора. Прогресс отображается в статусной строке.

## Альтернатива: Редактор реквизитов объекта

Если нужно изменить реквизит у небольшого числа объектов без написания кода:

1. Откройте **Универсальные инструменты → Редактор реквизитов объекта**
2. Выберите «Номенклатура»
3. Установите фильтр по нужным элементам
4. Выберите реквизит «СтавкаНДС» и задайте новое значение
5. Нажмите **Записать**
