# Редактор кода

Подсистема включает редактор кода на базе Monaco/Ace с подсветкой синтаксиса BSL. Взаимодействие — из клиентского контекста через общий модуль **УИ_РедакторКодаКлиент**.

Полная документация API и инструкция по подключению — в [репозитории продукта](https://github.com/cpr1c/tools_ui_1c/tree/develop/docs/РедакторКода).

## Подключение на форму

1. Добавьте элемент **ПолеТекстовогоДокумента**, связанный с реквизитом формы типа **Строка(0)**.
2. Отключите автозаполнение контекстного меню у элемента.
3. В модуль формы добавьте экспортную переменную:

```bsl
&НаКлиенте
Перем УИ_РедакторКодаКлиентскиеДанные Экспорт;
```

4. В **ПриСозданииНаСервере**:

```bsl
УИ_РедакторКодаСервер.ФормаПриСозданииНаСервере(ЭтотОбъект);
// или с указанием вида редактора:
УИ_РедакторКодаСервер.ФормаПриСозданииНаСервере(ЭтотОбъект, "Ace");
```

5. Для каждого редактора на форме:

```bsl
УИ_РедакторКодаСервер.СоздатьЭлементыРедактораКода(ЭтотОбъект, "Сервер", Элементы.ПолеАлгоритмаСервер);
```

6. В **ПриОткрытии**:

```bsl
УИ_РедакторКодаКлиент.ФормаПриОткрытии(ЭтотОбъект, Неопределено);
```

7. Скопируйте подключаемые обработчики из [документации репозитория](https://github.com/cpr1c/tools_ui_1c/blob/develop/docs/РедакторКода/ПодключениеНаФорму/README.md).

## Основные методы УИ_РедакторКодаКлиент

| Метод | Назначение |
| ----- | ---------- |
| `УстановитьТекстРедактора(Форма, Идентификатор, Текст)` | Установить текст редактора |
| `ТекстКодаРедактора(Форма, Идентификатор)` | Получить текст кода |
| `ГраницыВыделенияРедактора(Форма, Идентификатор)` | Текущее выделение |
| `УстановитьГраницыВыделения(...)` | Установить выделение |
| `ВставитьТекстПоПозицииКурсора(...)` | Вставка текста |
| `ВыделенныйТекстРедактора(...)` | Выделенный фрагмент |
| `ДобавитьКомментарииСтрокРедактора(...)` | Закомментировать строки |
| `УдалитьКомментарииСтрокРедактора(...)` | Раскомментировать строки |
| `ПереключитьВидимостьРедактора(...)` | Показать/скрыть редактор |

Для каждого метода есть вариант `...ЭлементаФормы`, принимающий элемент формы вместо идентификатора.

:::tip
Полный перечень методов с сигнатурами — в [README редактора кода](https://github.com/cpr1c/tools_ui_1c/blob/develop/docs/РедакторКода/README.md).
