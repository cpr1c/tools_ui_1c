# Редактор кода

Подсистема включает редактор кода на базе **Monaco** или **Ace** с подсветкой синтаксиса BSL. Взаимодействие осуществляется из клиентского контекста через общий модуль **УИ_РедакторКодаКлиент**.

:::info
Подсистема поддерживает два типа редакторов: **Monaco** (по умолчанию) и **Ace**. Некоторые методы (оригинальный текст) работают только для Monaco. Для каждого метода есть вариант `...ЭлементаФормы`, принимающий элемент формы (`ПолеФормы`) вместо строкового идентификатора.
:::

## Подключение на форму

Пошаговая инструкция по встраиванию редактора кода на форму 1С вынесена в отдельное [руководство](/docs/guides/code-editor-setup) в разделе **Руководства**.

## Методы

### `УстановитьТекстРедактораЭлементаФормы(Форма, Элемент, Текст, УстанавливатьОригинальныйТекст = Ложь)`

Устанавливает текст редактора по элементу формы.

**Параметры:**
- `Форма` — `ФормаКлиентскогоПриложения`.
- `Элемент` — `ПолеФормы`. Элемент формы редактора.
- `Текст` — `Строка`. Новый текст редактора.
- `УстанавливатьОригинальныйТекст` — `Булево` (необязательный). Устанавливать оригинальный текст.

### `ВставитьМакроКолонкуРедактораЗапроса(Форма, ИдентификаторРедактора)`

Вставляет макроколонку запроса в редактор.

**Параметры:**
- `Форма` — `ФормаКлиентскогоПриложения`.
- `ИдентификаторРедактора` — `Строка`. Идентификатор редактора.

---

### `ВставитьМакроКолонкуРедактораЗапросаЭлементаФормы(Форма, Элемент)`

Вставляет макроколонку запроса в редактор по элементу формы.

**Параметры:**
- `Форма` — `ФормаКлиентскогоПриложения`.
- `Элемент` — `ПолеФормы`. Элемент формы редактора.

---

### `ОткрытьКонструкторЗапроса(ТекстЗапроса, ОписаниеОповещенияОЗавершении, РежимКомпоновки = Ложь)`

Открывает конструктор запроса с переданным текстом.

**Параметры:**
- `ТекстЗапроса` — `Строка`. Текст запроса.
- `ОписаниеОповещенияОЗавершении` — `ОписаниеОповещения`.
- `РежимКомпоновки` — `Булево` (необязательный, по умолчанию `Ложь`).

---

### `ОткрытьКонструкторФорматнойСтроки(ФорматнаяСтрока, ОписаниеОповещенияОЗавершении)`

Открывает конструктор форматной строки с переданным значением.

**Параметры:**
- `ФорматнаяСтрока` — `Строка`.
- `ОписаниеОповещенияОЗавершении` — `ОписаниеОповещения`.

---

### `ПоделитьсяКодом(Код, ЭтоЗапрос, ВладелецФормы = Неопределено)`

Открывает форму для загрузки кода в сервис и получения ссылки.

**Параметры:**
- `Код` — `Строка`. Код для публикации.
- `ЭтоЗапрос` — `Булево`. Признак запроса.
- `ВладелецФормы` — `ФормаКлиентскогоПриложения` (необязательный).

---

### `НачатьЗагрузкуКодаИзСервиса(ОписаниеОповещения, ВладелецФормы = Неопределено)`

Начинает загрузку кода из сервиса по ссылке. Результат приходит в `ОписаниеОповещения`.

**Параметры:**
- `ОписаниеОповещения` — `ОписаниеОповещения`. Обработчик результата.
- `ВладелецФормы` — `ФормаКлиентскогоПриложения` (необязательный).

---

### `НачатьСборкуОбработокДляИсполненияКода(Форма, ОписаниеОповещенияОЗавершении, ИменаПредустановленныхПеременных = Неопределено, ИдентификаторыРедакторовДляИсполненияНаКлиенте = Неопределено)`

Начинает сборку внешних обработок для выполнения кода из редакторов на форме.

**Параметры:**
- `Форма` — `ФормаКлиентскогоПриложения`.
- `ОписаниеОповещенияОЗавершении` — `ОписаниеОповещения`.
- `ИменаПредустановленныхПеременных` — `Структура, Неопределено` (необязательный). Имена предустановленных переменных для каждого редактора.
- `ИдентификаторыРедакторовДляИсполненияНаКлиенте` — `Массив из Строка, Неопределено` (необязательный). Редакторы, код которых выполняется на клиенте.

## Серверные методы

### `УИ_РедакторКодаСервер.ФормаПриСозданииНаСервере(Форма, ВидРедактора = Неопределено)`

Инициализирует подсистему редактора на сервере при создании формы.

**Параметры:**
- `Форма` — `ФормаКлиентскогоПриложения`.
- `ВидРедактора` — `Строка` (необязательный). Явное указание редактора (`"Monaco"` или `"Ace"`). По умолчанию — `Неопределено` (автовыбор).

---

### `УИ_РедакторКодаСервер.СоздатьЭлементыРедактораКода(Форма, ИдентификаторРедактора, ПолеРедактора, СобытияРедактора = Неопределено, ЯзыкРедактора = "bsl", ГруппаКомманднойПанели = Неопределено)`

Создаёт элементы редактора кода на форме.

**Параметры:**
- `Форма` — `ФормаКлиентскогоПриложения`.
- `ИдентификаторРедактора` — `Строка`. Уникальный в пределах формы идентификатор. Должен соответствовать правилам именования переменных.
- `ПолеРедактора` — `ПолеФормы`. Поле редактора.
- `СобытияРедактора` — `Неопределено, Структура` (необязательный). Имена процедур формы для обработки событий. Список поддерживаемых событий — в `УИ_РедакторКодаСервер.НовыйПараметрыСобытийРедактора`.
- `ЯзыкРедактора` — `Строка` (необязательный, по умолчанию `"bsl"`). Язык редактора кода.
- `ГруппаКомманднойПанели` — `ГруппаФормы` (необязательный). Группа командной панели, куда будут добавлены кнопки.

## Примеры

### Установка и получение текста редактора

```bsl
УИ_РедакторКодаКлиент.УстановитьТекстРедактора(ЭтотОбъект, "Код", "Сообщить(1)", Истина);

Текст = УИ_РедакторКодаКлиент.ТекстКодаРедактора(ЭтотОбъект, "Код");
```

### Работа с выделением и комментариями

```bsl
// Получить границы выделения
Границы = УИ_РедакторКодаКлиент.ГраницыВыделенияРедактора(ЭтотОбъект, "Код");

// Установить выделение (строки 1-5, вся строка)
УИ_РедакторКодаКлиент.УстановитьГраницыВыделения(ЭтотОбъект, "Код", 1, 0, 5, 0);

// Закомментировать выделенные строки
УИ_РедакторКодаКлиент.ДобавитьКомментарииСтрокРедактора(ЭтотОбъект, "Код");

// Раскомментировать
УИ_РедакторКодаКлиент.УдалитьКомментарииСтрокРедактора(ЭтотОбъект, "Код");
```

### Вставка текста и управление видимостью

```bsl
// Вставить текст в позицию курсора
УИ_РедакторКодаКлиент.ВставитьТекстПоПозицииКурсора(ЭтотОбъект, "Код", "Новый текст");

// Скрыть редактор
УИ_РедакторКодаКлиент.ПереключитьВидимостьРедактора(ЭтотОбъект, "Код", Ложь);

// Переключить видимость
УИ_РедакторКодаКлиент.ПереключитьВидимостьРедактора(ЭтотОбъект, "Код");
```
