# Редактор кода

Подсистема включает редактор кода на базе **Monaco** или **Ace** с подсветкой синтаксиса BSL. Взаимодействие осуществляется из клиентского контекста через общий модуль **УИ_РедакторКодаКлиент**.

- Модуль (клиент): **УИ_РедакторКодаКлиент**
- Модуль (сервер): **УИ_РедакторКодаСервер**

:::info
Подсистема поддерживает два типа редакторов: **Monaco** (по умолчанию) и **Ace**. Некоторые методы (оригинальный текст, контекст, определение метода) работают только для Monaco. Для каждого метода есть вариант `...ЭлементаФормы`, принимающий элемент формы (`ПолеФормы`) вместо строкового идентификатора.
:::

## Подключение на форму

Пошаговая инструкция по встраиванию редактора кода на форму 1С вынесена в отдельное [руководство](/docs/guides/code-editor-setup) в разделе **Руководства**.

## Методы

| Метод | Описание |
| ----- | -------- |
| `УстановитьТекстРедактора(Форма, Идент, Текст, УстОриг = Ложь)` | Установить текст редактора |
| `УстановитьОригинальныйТекстРедактора(Форма, Идент, Текст)` | Установить оригинальный текст (Monaco) |
| `УстановитьОригинальныйТекстРедактораРавнымТекущему(Форма, Идент)` | Оригинал = текущему |
| `ТекстКодаРедактора(Форма, Идент)` | Получить текст кода |
| `ОригинальныйТекстКодаРедактора(Форма, Идент)` | Оригинальный текст (Monaco) |
| `ГраницыВыделенияРедактора(Форма, Идент)` | Текущие границы выделения |
| `УстановитьГраницыВыделения(Форма, Идент, НачСтр, НачКол, КонСтр, КонКол)` | Установить выделение |

| `УдалитьКомментарииСтрокРедактора(Форма, Идент)` | Раскомментировать строки |
| `ДобавитьПереносСтрокРедактора(Форма, Идент)` | Добавить переносы строк |
| `УдалитьПереносСтрокРедактора(Форма, Идент)` | Удалить переносы строк |

| `ПреобразоватьТекстЗапросаИзВыраженияВстроенногоЯзыкаРедактораКода(Форма, Идент)` | Преобразовать текст запроса |
| `ДобавитьКонтекстРедактораКода(Форма, Идент, Контекст)` | Добавить контекст автодополнения (Monaco) |

## Примеры

### Установка и получение текста редактора

```bsl
УИ_РедакторКодаКлиент.УстановитьТекстРедактора(ЭтотОбъект, "Код", "Сообщить(1)", Истина);

Текст = УИ_РедакторКодаКлиент.ТекстКодаРедактора(ЭтотОбъект, "Код");
```

### Работа с выделением и комментариями

```bsl
// Получить границы выделения
Границы = УИ_РедакторКодаКлиент.ГраницыВыделенияРедактора(ЭтотОбъект, "Код");

// Установить выделение (строки 1-5, вся строка)
УИ_РедакторКодаКлиент.УстановитьГраницыВыделения(ЭтотОбъект, "Код", 1, 0, 5, 0);

// Закомментировать выделенные строки
УИ_РедакторКодаКлиент.ДобавитьКомментарииСтрокРедактора(ЭтотОбъект, "Код");

// Раскомментировать
УИ_РедакторКодаКлиент.УдалитьКомментарииСтрокРедактора(ЭтотОбъект, "Код");
```

### Вставка текста и управление видимостью

```bsl
// Вставить текст в позицию курсора
УИ_РедакторКодаКлиент.ВставитьТекстПоПозицииКурсора(ЭтотОбъект, "Код", "Новый текст");

// Скрыть редактор
УИ_РедакторКодаКлиент.ПереключитьВидимостьРедактора(ЭтотОбъект, "Код", Ложь);

// Переключить видимость
УИ_РедакторКодаКлиент.ПереключитьВидимостьРедактора(ЭтотОбъект, "Код");
```
