# HTTP-сервисы

Публикуемые HTTP-сервисы для интеграции и прямого обмена данными.

## HTTP-сервис УИ_ПубликуемыеФункции

HTTP-сервис предоставляет REST-подобный доступ к функциям подсистемы. Позволяет выполнять методы через HTTP-запросы без открытия сеанса 1С.

### Публикуемые эндпоинты

| Эндпоинт | Метод | Описание |
| -------- | ----- | -------- |
| `/УИ_ПубликуемыеФункции/Выполнить` | POST | Выполнение произвольного кода |
| `/УИ_ПубликуемыеФункции/ВызватьМетод` | POST | Вызов метода с параметрами |
| `/УИ_ПубликуемыеФункции/Статус` | GET | Проверка доступности сервиса |

### Аутентификация

- Базовая аутентификация HTTP (Basic Auth)
- Поддержка токенов (Bearer)
- Настройка прав выполняется в конфигурации HTTP-сервиса

### Пример запроса

```bsl
Результат = УИ_КоннекторHTTP.PostJson(
    "http://localhost/УИ_ПубликуемыеФункции/Выполнить",
    Новый Структура("Код", "Сообщить(ТекущаяДата());"),
    Новый Структура("Authorization", "Basic " + Base64Строка("Пользователь:Пароль"))
);
```

## Интеграция с universal-xml-exchange

HTTP-сервис используется для прямого обмена данными с модулем [Универсальный XML-обмен](/docs/tools/exchange-tools/universal-xml-exchange):

- Получение данных справочников и документов
- Отправка изменений из внешних систем
- Загрузка XML-пакетов удалённо

```bsl
Результат = УИ_КоннекторHTTP.PostJson(
    "http://server/УИ_ПубликуемыеФункции/ВызватьМетод",
    Новый Структура(
        "ИмяМетода,Параметры",
        "УИ_ВыгрузкаЗагрузкаXML.ВыгрузитьДанные",
        Новый Массив
    ),
    Заголовки
);
```

:::tip
Для интерактивного тестирования эндпоинтов используйте [Консоль HTTP](/docs/tools/development-tools/http-console) или [Консоль веб-сервисов](/docs/tools/development-tools/web-service-console).
:::
