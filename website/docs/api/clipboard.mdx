# Буфер обмена ОС

Клиентский модуль для работы с буфером обмена операционной системы из 1С.

- Модуль: **УИ_БуферОбменаКлиент**
- Репозиторий: [github.com/cpr1c/clipboard_1c](https://github.com/cpr1c/clipboard_1c)

## Методы

| Метод | Описание |
| ----- | -------- |
| `КопироватьСтрокуВБуфер(Строка, Асинхронно)` | Копирует строку в буфер обмена |

Параметр `Асинхронно` (Истина/Ложь, по умолчанию Ложь) определяет режим выполнения.

## Примеры

### Синхронное копирование

```bsl
УИ_БуферОбменаКлиент.КопироватьСтрокуВБуфер("Моя строка для копирования в буфер обмена");
```

### Асинхронное копирование

```bsl
УИ_БуферОбменаКлиент.КопироватьСтрокуВБуфер("Асинхронное копирование", Истина);
```

## Поддерживаемые платформы

- **Windows** — через COM-объекты (MSForms)
- **Linux** — через вызов `xclip`
- **macOS** — через `pbcopy`

:::tip
Для расширенной работы с файловой системой и текстом на сервере используйте [Файловый менеджер](/docs/tools/administration-tools/file-manager).
:::
