# Коннектор HTTP

HTTP-клиент для 1С — аналог Python Requests. Реализован на базе библиотеки [Connector](https://github.com/vbondarevsky/Connector).

- Модуль: **УИ_КоннекторHTTP**
- Репозиторий: [github.com/vbondarevsky/Connector](https://github.com/vbondarevsky/Connector)

## Методы

| Метод | Описание |
| ----- | -------- |
| `Get(URL, ПараметрыЗапроса, Заголовки, Таймаут)` | GET-запрос |
| `Post(URL, Тело, Заголовки, Таймаут)` | POST-запрос |
| `Put(URL, Тело, Заголовки, Таймаут)` | PUT-запрос |
| `Delete(URL, ПараметрыЗапроса, Заголовки, Таймаут)` | DELETE-запрос |
| `GetJson(URL, ПараметрыЗапроса, Заголовки, Таймаут)` | GET с автоматическим парсингом JSON |
| `PostJson(URL, Данные, Заголовки, Таймаут)` | POST с сериализацией тела в JSON |

## Примеры

### GET-запрос

```bsl
Результат = УИ_КоннекторHTTP.Get("https://api.github.com/repos/cpr1c/tools_ui_1c");
Если Результат.КодСостояния = 200 Тогда
    Сообщить(Результат.ТелоКакСтрока());
КонецЕсли;
```

### POST с телом

```bsl
Результат = УИ_КоннекторHTTP.Post(
    "https://httpbin.org/post",
    "тело запроса",
    Новый Структура("Content-Type", "text/plain")
);
```

### Отправка JSON

```bsl
Данные = Новый Структура();
Данные.Вставить("title", "Новая задача");
Данные.Вставить("completed", Ложь);

Результат = УИ_КоннекторHTTP.PostJson(
    "https://jsonplaceholder.typicode.com/todos",
    Данные
);
```

### GET с параметрами и заголовками

```bsl
Параметры = Новый Структура("q,per_page", "1С", 10);
Заголовки = Новый Структура("Authorization", "Bearer token");

Результат = УИ_КоннекторHTTP.GetJson(
    "https://api.github.com/search/issues",
    Параметры,
    Заголовки
);
```

## Обработка ошибок

```bsl
Результат = УИ_КоннекторHTTP.Get("https://example.com/api");
Если Результат.КодСостояния = 0 Тогда
    Сообщить("Ошибка соединения: " + Результат.Ошибка);
Иначе
    Сообщить("Статус: " + Результат.КодСостояния);
КонецЕсли;
```

## Таймаут

Таймаут задаётся в секундах четвёртым параметром:

```bsl
Результат = УИ_КоннекторHTTP.Get("https://example.com", , , 10);
```

## Proxy

Настройка прокси-сервера:

```bsl
Результат = УИ_КоннекторHTTP.Get(
    "https://example.com",
    ,,
    ,
    ,
    Новый Структура("HTTP,HTTPS", "http://proxy:8080", "http://proxy:8080")
);
```

:::tip
Для интерактивной работы с HTTP-запросами используйте [Консоль HTTP](/docs/tools/development-tools/http-console).
:::
