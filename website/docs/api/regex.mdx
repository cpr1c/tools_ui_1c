# Регулярные выражения

Клиент-серверный модуль для работы с регулярными выражениями в 1С на базе CFE-расширения.

- Модуль: **УИ_РегулярныеВыраженияКлиентСервер**
- Репозиторий: [github.com/cpr1c/RegEx1C_cfe](https://github.com/cpr1c/RegEx1C_cfe)

## Методы

| Метод | Описание |
| ----- | -------- |
| `Совпадает(Строка, Шаблон)` | Проверяет, соответствует ли строка шаблону |
| `НайтиПервое(Строка, Шаблон)` | Находит первое совпадение |
| `НайтиВсе(Строка, Шаблон)` | Находит все совпадения |
| `Заменить(Строка, Шаблон, Замена)` | Заменяет совпадения в строке |
| `Разделить(Строка, Шаблон)` | Разделяет строку по шаблону |

## Примеры

### Проверка совпадения

```bsl
Результат = УИ_РегулярныеВыраженияКлиентСервер.Совпадает(
    "Hello world",
    "([A-Za-z]+)\s+([a-z]+)"
); // Истина
```

### Поиск первого совпадения

```bsl
Совпадение = УИ_РегулярныеВыраженияКлиентСервер.НайтиПервое(
    "Цена: 1500 руб.",
    "\d+"
);
Сообщить(Совпадение.Значение); // 1500
```

### Поиск всех совпадений

```bsl
ВсеСовпадения = УИ_РегулярныеВыраженияКлиентСервер.НайтиВсе(
    "Товар: A-001, A-002, B-003",
    "[A-Z]-\d+"
);
Для каждого Совпадение Из ВсеСовпадения Цикл
    Сообщить(Совпадение.Значение);
КонецЦикла;
```

### Замена по шаблону

```bsl
Результат = УИ_РегулярныеВыраженияКлиентСервер.Заменить(
    "01.01.2024, 15.03.2024",
    "(\d{2})\.(\d{2})\.(\d{4})",
    "$3-$2-$1"
);
// 2024-01-01, 2024-03-15
```

### Разделение строки

```bsl
Части = УИ_РегулярныеВыраженияКлиентСервер.Разделить(
    "один,два;три|четыре",
    "[,;|]"
);
```

:::tip
Для интерактивного конструирования и тестирования регулярных выражений используйте [Конструктор регулярных выражений](/docs/tools/development-tools/regex-constructor).
:::
