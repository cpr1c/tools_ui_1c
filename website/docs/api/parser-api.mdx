# Парсер встроенного языка

Встроенный парсер языка 1С (BSL) позволяет анализировать, трансформировать и генерировать программный код.

## Обзор

Парсер построен по классической двухфазной схеме: лексический анализатор (токенизатор) и синтаксический анализатор (AST). Результат разбора — абстрактное синтаксическое дерево (AST).

## Типы токенов

- `Идентификатор` — имена переменных, функций, методов
- `Число` — числовые литералы
- `Строка` — строковые литералы
- `КлючевоеСлово` — операторы языка (Если, Тогда, Для, Цикл и др.)
- `Оператор` — знаки операций (+, -, *, /, =, &#x3C;&#x3E;)
- `Комментарий` — комментарии кода
- `Препроцессор` — директивы препроцессора (&НаКлиенте, #Если и др.)

## Структура AST

AST представляет иерархию узлов:

- **Модуль** — корневой узел всего модуля
- **Область** — блок `#Область ... #КонецОбласти`
- **Процедура / Функция** — объявление метода
- **Если / Тогда / Иначе** — условный оператор
- **Для / ДляКаждого / Цикл** — циклы
- **Выражение** — любое выражение (вызов метода, присваивание, обращение к свойству)

## Visitor (подписки)

```bsl
Парсер = УИ_ПарсерВстроенногоЯзыка();
Парсер.УстановитьПодписку("Процедура", ОбработчикПроцедуры);
Парсер.УстановитьПодписку("ВызовМетода", ОбработчикВызова);
Парсер.Разобрать(ИсходныйКод);
```

## Обработка ошибок

```bsl
Попытка
    AST = Парсер.Разобрать(Код);
Исключение
    Сообщить("Ошибка разбора: " + ОписаниеОшибки());
КонецПопытки;
```

## Замена кода

```bsl
Парсер.ДобавитьЗамену(
    "ТипСтроки",
    "ТипСтроки(Парам1, Парам2)",
    "ТипСтроки2(Парам1, Парам2, ДополнительныйПараметр)"
);
```

## Подключаемые плагины

| Плагин | Назначение |
| ------ | ---------- |
| **УИ_ПлагинАвтодополнение** | Автодополнение кода в редакторе |
| **УИ_ПлагинФорматирование** | Форматирование кода |
| **УИ_ПлагинРефакторинг** | Переименование, извлечение метода |
| **УИ_ПлагинПроверкаСинтаксиса** | Валидация кода |
