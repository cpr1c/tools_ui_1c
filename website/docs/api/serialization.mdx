# Библиотека сериализации 1С

Сериализация и десериализация данных 1С и объектов СКД (системы компоновки данных) в простые структуры и JSON.

- Обработка: **УИ_ПреобразованиеДанныхJSON**
- Репозиторий: [github.com/arkuznetsov/SerLib1C](https://github.com/arkuznetsov/SerLib1C)
- Лицензия: MPL-2.0

## Инициализация

```bsl
СериализаторJSON = Обработки.УИ_ПреобразованиеДанныхJSON.Создать();
```

## Методы

| Метод | Назначение |
| ----- | ---------- |
| `ЗначениеВСтруктуру(Значение)` | Преобразует произвольное значение 1С в структуру |
| `СтруктураВЗначение(Структура, ТипРезультата)` | Восстанавливает значение из структуры |
| `ЗаписатьОписаниеОбъектаВJSON(Структура)` | Сериализует структуру в строку JSON |
| `ПрочитатьОписаниеОбъектаИзJSON(JSON)` | Десериализует JSON обратно в структуру |

## Примеры

### Сериализация элемента справочника

```bsl
СериализаторJSON = Обработки.УИ_ПреобразованиеДанныхJSON.Создать();

Ссылка = Справочники.Номенклатура.НайтиПоКоду("00001");
Объект = Ссылка.ПолучитьОбъект();

Структура = СериализаторJSON.ЗначениеВСтруктуру(Объект);
СтрокаJSON = СериализаторJSON.ЗаписатьОписаниеОбъектаВJSON(Структура);
```

### Десериализация обратно в объект

```bsl
Структура = СериализаторJSON.ПрочитатьОписаниеОбъектаИзJSON(СтрокаJSON);
ВосстановленныйОбъект = СериализаторJSON.СтруктураВЗначение(
    Структура,
    Тип("СправочникОбъект.Номенклатура")
);
```

### Сериализация настроек СКД

```bsl
СтруктураСКД = СериализаторJSON.ЗначениеВСтруктуру(НастройкиКомпоновкиДанных);
JSONНастроек = СериализаторJSON.ЗаписатьОписаниеОбъектаВJSON(СтруктураСКД);

// Сохранение в регистр сведений
Запись = РегистрыСведений.НастройкиОтчетов.СоздатьМенеджерЗаписи();
Запись.Пользователь = ТекущийПользователь();
Запись.НастройкиJSON = JSONНастроек;
Запись.Записать();
```

:::tip
Сериализация используется в компонентах обмена, в частности в [Универсальном XML-обмене](/docs/tools/exchange-tools/universal-xml-exchange).
:::
