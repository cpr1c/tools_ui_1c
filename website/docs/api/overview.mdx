# Обзор API

Подсистема предоставляет программный интерфейс для использования из своего кода и из формы **Вычислить выражение** отладчика.

## Библиотеки

### Коннектор HTTP

Удобный HTTP-клиент — аналог Python Requests для 1С.

- Модуль: **УИ_КоннекторHTTP**
- Документация: [github.com/vbondarevsky/Connector](https://github.com/vbondarevsky/Connector)

```bsl
Результат = УИ_КоннекторHTTP.GetJson("https://api.github.com/events");
```

### Библиотека сериализации 1С

Сериализация/десериализация данных 1С и объектов СКД в простые структуры.

- Обработка: **УИ_ПреобразованиеДанныхJSON**
- Документация: [github.com/arkuznetsov/SerLib1C](https://github.com/arkuznetsov/SerLib1C)

```bsl
СериализаторJSON = Обработки.УИ_ПреобразованиеДанныхJSON.Создать();
СтруктураИстории = СериализаторJSON.ЗначениеВСтруктуру(ДанныеСохранения);
СериализуемаяСтрокаJSON = СериализаторJSON.ЗаписатьОписаниеОбъектаВJSON(СтруктураИстории);
```

### Буфер обмена ОС

- Модуль: **УИ_БуферОбменаКлиент**
- Репозиторий: [github.com/cpr1c/clipboard_1c](https://github.com/cpr1c/clipboard_1c)

```bsl
УИ_БуферОбменаКлиент.КопироватьСтрокуВБуфер("Моя строка для копирования в буфер обмена");
```

### Регулярные выражения

- Модуль: **УИ_РегулярныеВыраженияКлиентСервер**
- Репозиторий: [github.com/cpr1c/RegEx1C_cfe](https://github.com/cpr1c/RegEx1C_cfe)

```bsl
УИ_РегулярныеВыраженияКлиентСервер.Совпадает("Hello world", "([A-Za-z]+)\s+([a-z]+)"); // Истина
```

## Функции модуля УИ_ (отладчик)

Вызываются из формы вычисления выражения или через `УИ_._...`.

### Выполнение кода — `_ДУ`

```bsl
УИ_._ДУ("Сообщить(П)", "Хорошо")

// С возвратом значения (переменная Р)
УИ_._ДУ("Сообщить(П); Р=П2;", "Хорошо", "Привет")
```

На вход — до 5 параметров `П`, `П2`…`П5` помимо кода.

### Виртуальные таблицы — `_ВТ`

```bsl
УИ_._ВТ(Запрос)
УИ_._ВТ(Запрос.МенеджерВременныхТаблиц)
```

### Сравнение таблиц значений — `_ТЗСр`

```bsl
УИ_._ТЗСр(ТаблицаБазовая, ТаблицаСравнения)
УИ_._ТЗСр(ТаблицаБазовая, ТаблицаСравнения, "Номенклатура,Количество")
```

### XML в структуры — `_XMLОбъект`

```bsl
УИ_._XMLОбъект(ЧтениеXML)
УИ_._XMLОбъект("C:\1.xml")
УИ_._XMLОбъект(Поток)
УИ_._XMLОбъект("C:\1.xml", Ложь) // без упрощения структур
```

### Отладка — `_От` и `_ОтФ`

См. [Отладка из кода](/docs/guides/debugging).
