# Запуск 1С под нужным пользователем

Функция доступна в инструменте **Навигатор по метаданным** (закладка «Пользователи»).

## Порядок действий

1. Перейдите на закладку **Пользователи**.
2. Нажмите **Обновить** для заполнения таблицы пользователей.
3. Укажите время ожидания запуска до восстановления пароля (по умолчанию 20 секунд).
4. Установите активность на нужного пользователя.
5. Из меню **Запуск под пользователем** выберите вид запускаемого клиента.

## Механизм работы

1. Перед запуском выбранному пользователю устанавливается пароль **qwerty123456**.
2. Выполняется запуск с новым паролем.
3. Ожидается указанное в настройках время.
4. Восстанавливается первоначальный пароль.

:::caution
Используйте инструмент осознанно: временная смена пароля затрагивает учётную запись пользователя в базе.
:::
