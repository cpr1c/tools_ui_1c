# Запуск 1С под нужным пользователем

Функция доступна в инструменте **Навигатор по метаданным** (закладка «Пользователи»).

## Порядок действий

1. Перейдите на закладку **Пользователи**.
2. Нажмите **Обновить** для заполнения таблицы пользователей.
3. Укажите, сколько секунд ждать входа пользователя до восстановления пароля (по умолчанию 20 секунд).
4. Установите активность на нужного пользователя.
5. Из меню **Запуск под пользователем** выберите вид запускаемого клиента.

## Механизм работы

1. Перед каждым запуском инструмент генерирует временный пароль методом `СлучайноеЧисло()` платформенного генератора псевдослучайных чисел. Пароль учитывает политику паролей выбранного пользователя, а если политики нет — настройки информационной базы. Длина пароля — не меньше 12 символов и не меньше минимальной длины по политике. Пароль содержит прописные и строчные латинские буквы и цифры, а при включённой проверке сложности — ещё и специальные символы.
2. Параметры запуска вместе с временным паролем записываются в файл в отдельном каталоге внутри рабочего каталога данных пользователя ОС. В Linux и macOS этот каталог создаётся с правами `700`, поэтому файл не могут прочитать другие пользователи компьютера. Клиент 1С запускается с ключом `/@ <имя файла>`, поэтому пароль не попадает в командную строку процесса и не виден в списке процессов.
3. Пользователю устанавливается временный пароль, и запускается клиент 1С.
4. Открывается окно ожидания входа, которое блокирует окно инструмента. Раз в секунду оно проверяет список сеансов информационной базы, а шкала показывает, сколько осталось до восстановления пароля. Как только у пользователя появился новый сеанс, первоначальный пароль восстанавливается, а каталог с файлом параметров удаляется. Если сеанс не появился за указанное время, пароль восстанавливается по его истечении. Кнопка **Восстановить пароль сейчас** прерывает ожидание и сразу восстанавливает пароль; закрытие окна действует так же.
5. Если клиент 1С не удалось запустить, первоначальный пароль восстанавливается сразу.

Если у пользователя пароль не установлен и разрешена аутентификация 1С:Предприятия, временный пароль не нужен: клиент запускается сразу, а учётная запись пользователя не меняется.

Запуск под пользователем недоступен в веб-клиенте.

:::caution
Используйте инструмент осознанно: временная смена пароля затрагивает учётную запись пользователя в базе.
:::
