# Разработка плагинов

Парсер встроенного языка 1С в Универсальных инструментах поддерживает плагины (модули-обработчики) на базе OneScript-парсера [osparser](https://github.com/oscript-library/osparser).

## API плагина

При открытии плагину передаются объекты парсера:

| Переменная | Назначение |
| ---------- | ---------- |
| `Типы` | Типы узлов парсера |
| `Токены` | Типы токенов |
| `Исходник` | Исходный текст модуля |
| `ТаблицаТокенов` | Результат токенизации |
| `ТаблицаОшибок` | Ошибки парсинга |
| `ТаблицаЗамен` | Замены в исходном коде |
| `Стек` | Стек синтаксического анализа |
| `Счетчики` | Счётчики узлов |
| `Директивы` | Директивы препроцессора |
| `Аннотации` | Аннотации модуля |
| `СимволыПрепроцессора` | Символы препроцессора |

## Доступные подписки

- `ПосетитьОператорПрисваивания` / `ПокинутьОператорПрисваивания`
- и другие события обхода дерева парсера

## Функции обработки ошибок

```bsl
Процедура Ошибка(Текст, Начало, Конец = Неопределено, ЕстьЗамена = Ложь)
```

```bsl
Процедура Замена(Текст, Начало, Конец = Неопределено)
```

```bsl
Процедура Вставка(Текст, Позиция)
```
