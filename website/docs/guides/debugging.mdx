# Вызов отладки объектов: УИ_._От / УИ_._ОтФ

Функции, ориентированные на использование в режиме отладки. Их можно вызывать из отладчика через диалог **Вычислить выражение**, а также из произвольного кода через модуль **УИ_**.

## Логика работы

Данные отлаживаемого объекта сохраняются в хранилище настроек(_От) или в специальную папку на сервере(_ОтФ). Соответствующий инструмент запускается из формы ["Данные для отладки"](/docs/tools/debugging-tools/debug-data)

## Вызов

```bsl
УИ_._От(ОбъектОтладки, Параметр2, Параметр3, Параметр4, Параметр5)
```

Вместо `ОбъектОтладки` передаётся переменная с одним из поддерживаемых типов (запрос, СКД, менеджер временных таблиц и т.д.). Все параметры **кроме первого** можно указывать в произвольном порядке.

Для сохранения данных отладки в файлы используйте `УИ_._ОтФ` — вызывается аналогично `УИ_._От`. Данные сохраняются во временный каталог на сервере.



## Поддерживаемые объекты

### Запрос

Отладка запроса открывает его текст, параметры и результат в консоли запросов. Можно передать готовый объект `Запрос` — отладятся в том числе менеджеры временных таблиц, если они уже назначены запросу.

```bsl
УИ_._От(Запрос)
УИ_._От(Запрос, "Запрос из сложной формы")
```

### Менеджер временных таблиц

Откроется консоль запросов с пустым текстом, но с уже заполненными временными таблицами из переданного менеджера.

```bsl
УИ_._От(МенеджерВременныхТаблиц)
УИ_._От(Запрос.МенеджерВременныхТаблиц)
```

### Схема компоновки данных

Отладка СКД открывает скомпонованный результат отчёта. Поддерживаются внешние наборы данных и менеджер временных таблиц.

```bsl
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД)
УИ_._От(СхемаКомпоновкиДанных)                                        // с настройками по умолчанию
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборыДанных)
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборыДанных, МенеджерВременныхТаблиц)
```

### Таблица формы (динамический список)

Извлекает схему компоновки и настройки динамического списка, после чего открывает их в консоли отчётов.

```bsl
УИ_._От(Элементы.Список)
```

### Ссылочный объект

Открывает форму просмотра и редактирования переданной ссылки на объект базы данных.

```bsl
УИ_._От(СсылкаНаОбъектБД)
```

### HTTP-запрос

Отладка строкового и файлового содержимого HTTP-запроса, а также прокси.

```bsl
УИ_._От(HTTPЗапрос, СоединениеHTTP)
```

## Наименование объекта отладки

Чтобы задать понятное имя для сохраняемого объекта, передайте **строку** в одном из дополнительных параметров:

```bsl
УИ_._От(Запрос, "Мой запрос")
УИ_._От(Запрос, , , "Мой запрос")
УИ_._От(СхемаКомпоновкиДанных, "Отчет по остаткам")
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборы, МенеджерВременныхТаблиц, "Отчет по остаткам")
УИ_._От(Элементы.Список, "Список заказов")
УИ_._От(СсылкаНаОбъектБД, "Ссылка")
УИ_._От(HTTPЗапрос, СоединениеHTTP, "Получение списка задач")
УИ_._От(HTTPЗапрос, "Получение списка задач", СоединениеHTTP)
```

## Сохранение данных отладки в файлы

Метод `УИ_._ОтФ` работает аналогично `УИ_._От`, но сохраняет результат не в справочник, а в файлы во временном каталоге на сервере.
