# Отладка из кода

Универсальные инструменты предоставляют программный вызов отладки из формы **Вычислить выражение** отладчика или из произвольного кода через модуль **УИ_**.

## Вызов отладки

```bsl
УИ_._От(ОбъектОтладки, Параметр2, Параметр3, Параметр4, Параметр5)
```

Все параметры кроме первого можно указывать в произвольном порядке.

Для сохранения данных отладки в файлы используйте `УИ_._ОтФ` — аналогично `УИ_._От`. Данные сохраняются во временный каталог на сервере.

## Логика работы

- **Толстый клиент** — форма консоли открывается сразу по окончании вызова.
- **Сервер, тонкий или веб-клиент** — информация сохраняется в справочник **Данные для отладки**. Отладка запускается из списка этого справочника.

## Поддерживаемые объекты

### Запрос

```bsl
УИ_._От(Запрос)
УИ_._От(Запрос, "Запрос из сложной формы")
```

### Менеджер временных таблиц

```bsl
УИ_._От(МенеджерВременныхТаблиц)
УИ_._От(Запрос.МенеджерВременныхТаблиц)
```

### Схема компоновки данных

```bsl
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД)
УИ_._От(СхемаКомпоновкиДанных)
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборыДанных)
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборыДанных, МенеджерВременныхТаблиц)
```

### Таблица формы (динамический список)

```bsl
УИ_._От(Элементы.Список)
```

### Ссылочный объект

```bsl
УИ_._От(СсылкаНаОбъектБД)
```

### HTTP-запрос

```bsl
УИ_._От(HTTPЗапрос, СоединениеHTTP)
```

## Наименование объекта отладки

Для задания наименования передайте **строку** одним из дополнительных параметров:

```bsl
УИ_._От(Запрос, "Мой запрос")
УИ_._От(СхемаКомпоновкиДанных, "Отчет по остаткам")
УИ_._От(HTTPЗапрос, СоединениеHTTP, "Получение списка задач")
```
