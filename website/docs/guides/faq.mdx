# Часто задаваемые вопросы

## Как установить без БСП?

Расширение устанавливается как обычное расширение конфигурации — БСП не требуется. Установка описана в разделе [Установка](/docs/guides/installation).

## Инструменты не появляются в интерфейсе?

1. Проверьте, что расширение активно.
2. Убедитесь, что пользователю назначена роль **УИ_ПолныеПрава**.
3. Обновите конфигурацию базы данных.
4. Перезапустите сеанс.

## Ошибки прав доступа?

Назначьте пользователю роль **УИ_ПолныеПрава**. Для ограниченного доступа используйте подчинённые роли из состава расширения.

## Что выбрать: расширение или портативную поставку?

| Сценарий | Рекомендация |
| -------- | ------------ |
| Постоянная работа в своей базе | Расширение |
| Разовые задачи на чужой базе | Портативная |
| Нельзя менять конфигурацию | Портативная |

## Инструменты не работают в веб-клиенте?

Некоторые инструменты поддерживают веб-клиент частично. Основной функционал доступен в толстом и тонком клиенте.

Поддерживается **1С:Предприятие 8.3.12 и выше** на Windows и Linux.
