# Обновление

Инструменты можно обновить двумя способами: автоматически (из программы) или вручную.

## Способ 1. Автоматическое обновление (из программы)

Если у вас установлено расширение или полная версия конфигурации:

1. Запустите 1С:Предприятие
2. В командной панели нажмите **Инструменты → Проверить наличие обновлений**
3. Если новая версия найдена:
   - **Для расширения** — нажмите **Обновить**, программа сама скачает и установит новую версию
   - **Для портативной версии** — будет предложено скачать новый файл `.epf`
   - **Для поставки в виде конфигурации** — будет предложено скачать новый файл `.cf`

## Способ 2. Обновление вручную

Выполните установку новой версии [по инструкции](/docs/guides/installation.mdx)

## Что проверить после обновления

- Все инструменты отображаются в интерфейсе
- Консоль запросов, Консоль кода, Навигатор по метаданным работают
- При наличии БСП — проверьте [совместимость версий](/docs/guides/bsp-integration)

## Совет

Перед обновлением расширения сделайте резервную копию базы. Если есть возможность — сначала протестируйте новую версию на тестовой базе.
