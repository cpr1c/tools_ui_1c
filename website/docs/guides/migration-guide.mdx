# Миграция между версиями

## Обновление расширения

1. Скачайте новую версию **UI.cfe** на [странице Скачать](/download).
2. Откройте конфигуратор информационной базы.
3. Перейдите в **Конфигурация → Расширения конфигурации**.
4. Удалите старую версию расширения.
5. Добавьте новое расширение из файла.
6. Установите флаг **Активно**.
7. Обновите конфигурацию базы данных.

## Проверка обратной совместимости

Перед обновлением ознакомьтесь с [CHANGELOG](https://github.com/cpr1c/tools_ui_1c/blob/master/CHANGELOG.md) на наличие критических изменений.

:::warning
Некоторые версии могут содержать изменения, требующие ручной донастройки. Всегда проверяйте раздел **Breaking changes**.
:::

## Интеграция с БСП

При наличии БСП убедитесь, что обновлённая версия совместима с вашей версией библиотеки. См. [Интеграция с БСП](/docs/guides/bsp-integration).

## Создание резервной копии

Перед миграцией рекомендуется:

- Создать резервную копию базы данных.
- Зафиксировать текущую версию расширения и БСП.
- При возможности протестировать новую версию на тестовой базе.

## Проверка после обновления

- Убедитесь, что все инструменты отображаются в интерфейсе.
- Проверьте работу ключевых инструментов: Консоль запросов, Консоль кода, Навигатор по метаданным.
- При использовании портативной поставки замените **.epf**-файл на актуальный.

## Обновление портативной поставки

Просто замените файл `УИ_ПортативныеУниверсальныеИнструменты.epf` на новую версию.
