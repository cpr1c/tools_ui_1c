# Отладка внешних обработок БСП

Инструкция по отладке дополнительных отчётов и обработок через механизм БСП.

## Как пользоваться

1. Сохраните файл отчёта или обработки на диск в конфигураторе.
2. Запустите режим предприятия.
3. Добавьте обработку в конфигурацию как внешнюю (справочник **ДополнительныеОтчетыИОбработки**).
4. В форме списка дополнительных обработок нажмите **Настройка отладки**.
5. Укажите имя файла на диске (открытого в конфигураторе) и при желании пользователя, под которым нужна отладка.

:::warning
Обработка подключается на сервере. Для серверной базы путь к файлу указывается **относительно сервера**.
:::

6. В конфигураторе откройте указанный файл и поставьте точки останова. Обновлять можно на лету — достаточно пересохранить файл. «Обновить из файла» делать не нужно.
7. По окончании отладки не забудьте обновить обработку в базе данных.

## Отладка под пользователем

Если пользователь указан, отладка выполняется только при запуске обработки под этим пользователем. Если не указан — под любым.

## Принцип работы

Подменяется функция БСП `ДополнительныеОтчетыИОбработки.ПодключитьВнешнююОбработку`: нужная обработка создаётся не в памяти, а подключается как файл с диска. Информация для отлаживаемой обработки хранится в хранилище системных настроек.
