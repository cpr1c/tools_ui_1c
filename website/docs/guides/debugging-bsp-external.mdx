# Отладка внешних обработок БСП

Если вы разрабатываете дополнительный отчёт или обработку для БСП, и хотите отлаживать их как обычный внешний файл в Конфигураторе — используйте встроенный механизм отладки.

## Как настроить

1. Откройте обработку в Конфигураторе и **сохраните файл на диск** (через `Файл -> Сохранить` или `Ctrl+S`)
2. Запустите режим предприятия
3. Добавьте эту обработку в справочник **Дополнительные отчеты и обработки** (через `Администрирование -> Печатные формы, отчеты и обработки -> Дополнительные отчеты и обработки`)
4. В форме списка нажмите **Настройка отладки** (кнопка над таблицей)
5. Укажите путь к файлу на диске (который открыт в Конфигураторе). При желании можно указать пользователя — тогда отладка будет срабатывать только при работе под ним

   :::warning
   База может быть серверной. В этом случае путь к файлу указывается **относительно сервера 1С**, а не вашего локального ПК.
   :::

6. В Конфигураторе откройте этот же файл и поставьте точки останова. Изменения можно вносить на лету — просто пересохраните файл (`Ctrl+S`). Команда **Обновить из файла** не требуется
7. После завершения отладки не забудьте обновить обработку в базе — иначе в ней останется старый код без ваших правок

## Если нужен конкретный пользователь

Если в настройке указан пользователь — отладка сработает только при запуске обработки под ним. Если не указан — под любым пользователем.

## Как это работает

Стандартный механизм БСП загружает обработку в память. Универсальные инструменты подменяют функцию `ДополнительныеОтчетыИОбработки.ПодключитьВнешнююОбработку` — вместо загрузки из базы обработка подключается как файл с диска. Информация о том, какой файл для какой обработки отлаживать, хранится в хранилище системных настроек.
