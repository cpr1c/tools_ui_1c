# Интеграция с БСП

Подсистема интегрируется с [Библиотекой стандартных подсистем (БСП)](https://its.1c.ru/db/bspdoc).

## Подменю «Инструменты» в формах объектов

В списки и формы объектов добавляется подменю **Инструменты** (формы должны быть подключены к подсистеме «Подключаемые команды»):

| Пункт | Описание |
| ----- | -------- |
| **Добавить к сравнению** | Добавляет выделенные объекты к сравнению для инструмента «Сравнение объектов» |
| **Редактировать объект** | Открывает текущий объект в редакторе реквизитов |
| **Сравнить объекты** | Открывает «Сравнение объектов» с выделенными ссылками (только для списков) |
| **Найти ссылки на объект** | Открывает «Поиск ссылок на объект» для текущего объекта |
| **Выгрузить объекты в XML** | Выгрузка выбранных объектов с подчинёнными ссылками через «Выгрузка загрузка XML» |

## Отладка дополнительных обработок и отчётов БСП

Подсистема поддерживает удобную отладку дополнительных отчётов и обработок БСП. Подробная инструкция — в разделе [Отладка внешних обработок БСП](/docs/guides/debugging-bsp-external).

Кратко:

1. Сохраните файл обработки/отчёта на диск в конфигураторе.
2. Запустите режим предприятия.
3. Добавьте обработку в справочник **ДополнительныеОтчетыИОбработки**.
4. В форме списка нажмите **Настройка отладки**, укажите путь к файлу на диске.
5. В конфигураторе откройте файл и поставьте точки останова. Пересохранение файла обновляет код без «Обновить из файла».

:::tip
При серверной базе путь к файлу указывается **относительно сервера**, так как обработка подключается на сервере.
:::

Принцип работы: подменяется функция БСП `ДополнительныеОтчетыИОбработки.ПодключитьВнешнююОбработку` — обработка подключается как файл с диска, а не создаётся в памяти. Настройки хранятся в хранилище системных настроек.
