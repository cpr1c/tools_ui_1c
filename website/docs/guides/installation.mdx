# Установка

## Выберите способ установки

### Расширение конфигурации (CFE) — постоянное использование

Подходит для штатной работы в своей базе. Инструменты встраиваются в интерфейс и доступны в отдельном разделе.

1. Скачайте файл **UI.cfe** на [странице Скачать](/download)
2. Откройте конфигуратор информационной базы
3. Перейдите в **Конфигурация → Расширения конфигурации**
4. Добавьте расширение из файла **UI.cfe**
5. Установите флаг **Активно** и при необходимости снимите **Безопасный режим** (зависит от политики базы)
6. Обновите конфигурацию базы данных
7. Запустите режим «1С:Предприятие» — раздел **Инструменты** появится в интерфейсе

#### Права доступа

Для полного доступа к инструментам расширения назначьте роль **УИ_ПолныеПрава** нужным пользователям.

### Портативная поставка (EPF) — без установки

Внешняя обработка **UI_Portable.epf**. Не требует изменения конфигурации. Удобна для:

- разовых задач на чужой базе
- отладки через модуль **УИ_** (см. [Отладка в портативном варианте](/docs/guides/debugging-portable))
- использования в сеансах, где нельзя менять конфигурацию

После скачивания просто откройте файл через **Файл → Открыть** в режиме «1С:Предприятие».
