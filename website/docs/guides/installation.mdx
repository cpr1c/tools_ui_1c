# Установка

## Скачивание

Актуальную сборку расширения можно скачать на [странице Скачать](/download). Файл расширения: **UI.cfe**.

Также доступна портативная поставка — внешняя обработка **УИ_ПортативныеУниверсальныеИнструменты.epf**.

## Установка расширения

1. Откройте конфигуратор информационной базы.
2. Перейдите в **Конфигурация → Расширения конфигурации**.
3. Добавьте расширение из файла **UI.cfe**.
4. Установите флаг **Активно** и при необходимости **Безопасный режим** (зависит от политики базы).
5. Обновите конфигурацию базы данных.
6. Запустите режим «1С:Предприятие» — раздел **Универсальные инструменты** появится в интерфейсе.

## Права доступа

Для полного доступа к инструментам назначьте роль **УИ_ПолныеПрава** нужным пользователям.

## Портативная поставка

Портативные инструменты запускаются как внешняя обработка без установки расширения. Удобны для:

- разовых задач на чужой базе;
- отладки через модуль **УИ_** (см. [Отладка в портативном варианте](/docs/guides/debugging-portable));
- использования в сеансах, где нельзя менять конфигурацию.

## Сборка из исходников

Для самостоятельной сборки потребуются платформа 1С, EDT и OneScript. Подробности — в [README репозитория](https://github.com/cpr1c/tools_ui_1c#сборка-в-бинарные-файлы).

Кратко:

```bash
# Установка зависимостей сборки (из корня репозитория)
opm install

# Linux: экспорт XML и сборка CFE
./build.sh --platformSource=/opt/1cv8/x86_64/8.3.XX.XXXX --edtSource=/path/to/edt xml
./build.sh --platformSource=... --edtSource=... cfe
```

Доступные команды сборки: `xml`, `cfe`, `cf`, `epf`.

Переменные окружения вместо параметров:

- `TOOLS_UI_1C_BUILDER_PLATFORM_PATH`
- `TOOLS_UI_1C_BUILDER_EDT_PATH`
