# Устранение неполадок

## Расширение не загружается

1. Проверьте, что расширение добавлено в конфигурацию и активно.
2. Убедитесь, что версия платформы не ниже 8.3.12.
3. Проверьте логи предприятия на наличие ошибок загрузки расширения.

## "Failed to create external handler"

Ошибка возникает при использовании внешних компонент (например, конструктора регулярных выражений) на Linux. Убедитесь, что установлены зависимости Wine (для Windows-компонент).

:::note
Конструктор регулярных выражений работает только в Windows.
:::

## Данные отладки не сохраняются в тонком клиенте

При отладке через тонкий или веб-клиент данные сохраняются в справочник **Данные для отладки**. Проверьте, что пользователь имеет права на запись в этот справочник. Используйте `УИ_._ОтФ` для сохранения во временный каталог — подробнее в [Отладка](/docs/guides/debugging).

## HTTP-консоль не работает

- Проверьте сетевое подключение.
- Убедитесь, что на сервере не заблокирован исходящий трафик.
- Проверьте корректность URL и параметров запроса.

## Регулярные выражения не работают на Linux

Для работы регулярных выражений на Linux необходим модуль **RegEx1C_cfe**. Убедитесь, что он подключён. Проверьте настройки в разделе **Регулярные выражения** интерфейса инструментов.

## Синхронные вызовы в веб-клиенте

:::warning
Веб-клиент не поддерживает синхронные вызовы. Некоторые инструменты с синхронным кодом могут работать некорректно в веб-клиенте.
:::

## Ошибки при сборке из исходников

См. раздел [Сборка из исходников](/docs/guides/build-from-source). Убедитесь, что установлены все зависимости и правильно указаны пути к платформе и EDT.
