# Отладка в портативном варианте

В портативной поставке доступны **все методы**, вызываемые через модуль **УИ_**.

## Вариант 1: Однократный запуск портативных инструментов в сеансе

### Плюсы

- Не нужна доступность каталога инструментов с сервера
- Работает в тонком клиенте
- Единый механизм для всех вариантов использования
- Краткий вызов — не нужно знать путь к хранению инструментов

### Минусы

- В каждом сеансе нужно однократно запускать портативные инструменты
- Работает только в том сеансе, где запущены инструменты. Недоступно в фоновых заданиях, веб-сервисах, HTTP-сервисах и т.п.

### Варианты запуска

**Клиентский контекст** (тонкий клиент любой базы, толстый клиент клиент-серверной базы):

```bsl
ПолучитьФорму("ВнешняяОбработка.УИ_.Форма")._От(Ссылка);
```

**Серверный контекст** (любая база, толстый клиент файловой базы):

```bsl
ВнешниеОбработки.Создать("УИ_")._От(Запрос)
```

## Вариант 2: Через файл обработки портативной поставки

### Плюсы

- Можно использовать без открытия инструментов
- После однократного использования в сеансе становится доступен вариант №1 без его ограничений

### Минусы

- Доступно только в контексте сервера и в толстом клиенте
- Папка с инструментами должна быть доступна в контексте отладки

Перед использованием при включённой защите от опасных действий нужно однократно запустить портативные инструменты в базе:

```bsl
ВнешниеОбработки.Создать("ПутьДоОбработкиПортативныхИнструментов", Ложь)._От(Запрос)
```

Пример:

```bsl
ВнешниеОбработки.Создать("/mnt/Disk/Git/tools_ui_1c/build/Портативная/УИ_ПортативныеУниверсальныеИнструменты.epf", Ложь)._От(Запрос)
```
