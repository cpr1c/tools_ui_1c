# Прочие использованные проекты

- [jsoneditor](https://github.com/josdejong/jsoneditor) — редактор JSON с деревом и подсветкой
- [xml-parser](https://github.com/khorevaa/xml-parser) — основа для чтения XML в простые структуры данных
- [bsl_console](https://github.com/salexdv/bsl_console) — редактор кода 1С на базе Monaco
- [osparser](https://github.com/oscript-library/osparser) — парсер встроенного языка 1С
- [tool1cd](https://github.com/e8tools/tool1cd) — утилита для размеров таблиц файловой базы
- [ace-for-1c](https://github.com/LevkinSergey/ace-for-1c) — сборка редактора Ace с поддержкой веб-клиента
- [ace-colaborator-1c](https://github.com/LevkinSergey/ace-colaborator-1c) — плагин совместного редактирования для Ace
- [_37583](https://github.com/pm74/_37583) — основа для механизма алгоритмов
- [debug_external_dataprocessor](https://github.com/partizand/debug_external_dataprocessor) — основа для отладки внешних обработок БСП
- [yaxunit](https://github.com/bia-technologies/yaxunit) — пример и инструменты для настройки actions
- [cfe2cf](https://github.com/best-tech/cfe2cf) — конвертация расширения в конфигурацию
