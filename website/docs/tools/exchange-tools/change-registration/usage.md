# Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Регистрация изменений**.

## Регистрация изменений

1. Выберите объекты метаданных для отслеживания;
2. Настройте период регистрации;
3. Нажмите **Зарегистрировать изменения**;
4. Просмотрите результат в списке изменений.

## Просмотр изменений

В таблице отображаются:
- Имя объекта;
- Вид изменения (создание, изменение, удаление);
- Дата и время изменения;
- Представление изменённых данных.

## Экспорт изменений

Список изменений можно экспортировать в табличный документ для передачи в другую базу или сохранения в файл.

## Программный вызов

```bsl
// Программная регистрация изменений
Параметры = Обработки.РегистрацияИзмененийДляОбмена.Создать();
Параметры.ОбъектыМетаданных.Добавить("Справочник.Номенклатура");
Параметры.ОбъектыМетаданных.Добавить("Документ.РеализацияТоваров");
Параметры.ДатаНачала = НачалоМесяца(ТекущаяДата());
Параметры.ЗарегистрироватьИзменения();

// Получение списка изменений
Изменения = Параметры.ПолучитьСписокИзменений();
Для Каждого Изменение Из Изменения Цикл
    Сообщить(Изменение.ИмяОбъекта + " - " + Изменение.ВидИзменения);
КонецЦикла;
```
