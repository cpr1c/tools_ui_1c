# Возможности

## Основные возможности

- **Автоматическая регистрация изменений** — отслеживание создания, изменения и удаления объектов метаданных;
- **Просмотр списка изменений** — удобный интерфейс для просмотра зарегистрированных изменений;
- **Экспорт изменений** — выгрузка списка изменений для дальнейшей обработки.

## Режимы регистрации

- **По объектам метаданных** — регистрация по выбранным справочникам, документам, регистрам;
- **По конкретным элементам** — регистрация изменений отдельных элементов или групп;
- **Полная регистрация** — отметка всех объектов как изменённых для полной синхронизации.

## Настройки

- **Период регистрации** — ограничение глубины отслеживания по дате;
- **Фильтр по видам объектов** — выбор конкретных видов для регистрации;
- **Автоматическая очистка** — удаление устаревших записей об изменениях.

## Интеграция

- Совместимость с подсистемой обмена данными;
- Использование в регламентных заданиях для автоматической регистрации;
- Интеграция с обработками выгрузки/загрузки XML.
