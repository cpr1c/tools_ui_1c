# Регистрация изменений для обмена

Форк обработки с диска ИТС, адаптированный под подсистему.

## Назначение

- Регистрация изменений объектов
- Подготовка к обмену данными
- Отслеживание изменений

## Особенности

- Автоматическая регистрация изменений
- Просмотр списка изменений
- Экспорт изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Регистрация изменений**
2. Настройте параметры регистрации
3. Выполните регистрацию изменений
4. Используйте изменения для обмена

## Возможности

## Основные возможности

- **Автоматическая регистрация изменений** — отслеживание создания, изменения и удаления объектов метаданных;
- **Просмотр списка изменений** — удобный интерфейс для просмотра зарегистрированных изменений;
- **Экспорт изменений** — выгрузка списка изменений для дальнейшей обработки.

## Режимы регистрации

- **По объектам метаданных** — регистрация по выбранным справочникам, документам, регистрам;
- **По конкретным элементам** — регистрация изменений отдельных элементов или групп;
- **Полная регистрация** — отметка всех объектов как изменённых для полной синхронизации.

## Настройки

- **Период регистрации** — ограничение глубины отслеживания по дате;
- **Фильтр по видам объектов** — выбор конкретных видов для регистрации;
- **Автоматическая очистка** — удаление устаревших записей об изменениях.

## Интеграция

- Совместимость с подсистемой обмена данными;
- Использование в регламентных заданиях для автоматической регистрации;
- Интеграция с обработками выгрузки/загрузки XML.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Регистрация изменений**.

## Регистрация изменений

1. Выберите объекты метаданных для отслеживания;
2. Настройте период регистрации;
3. Нажмите **Зарегистрировать изменения**;
4. Просмотрите результат в списке изменений.

## Просмотр изменений

В таблице отображаются:
- Имя объекта;
- Вид изменения (создание, изменение, удаление);
- Дата и время изменения;
- Представление изменённых данных.

## Экспорт изменений

Список изменений можно экспортировать в табличный документ для передачи в другую базу или сохранения в файл.

## Программный вызов

```bsl
// Программная регистрация изменений
Параметры = Обработки.РегистрацияИзмененийДляОбмена.Создать();
Параметры.ОбъектыМетаданных.Добавить("Справочник.Номенклатура");
Параметры.ОбъектыМетаданных.Добавить("Документ.РеализацияТоваров");
Параметры.ДатаНачала = НачалоМесяца(ТекущаяДата());
Параметры.ЗарегистрироватьИзменения();

// Получение списка изменений
Изменения = Параметры.ПолучитьСписокИзменений();
Для Каждого Изменение Из Изменения Цикл
    Сообщить(Изменение.ИмяОбъекта + " - " + Изменение.ВидИзменения);
КонецЦикла;
```

## Часто задаваемые вопросы

## Какие объекты поддерживают регистрацию изменений?

Справочники, документы, регистры сведений, регистры накопления, регистры бухгалтерии, регистры расчёта, планы видов характеристик, планы счетов, бизнес-процессы и задачи.

## Как отменить регистрацию конкретного изменения?

Выберите изменение в списке и нажмите **Снять отметку**. Изменение будет удалено из списка зарегистрированных.

## Нужно ли регистрировать изменения вручную?

Регистрация может выполняться как вручную, так и автоматически через регламентное задание. Для автоматической регистрации настройте задание **УИ_РегистрацияИзменений**.

## Как часто следует регистрировать изменения?

Рекомендуется выполнять регистрацию по расписанию (например, раз в час) перед плановым обменом данными. Для баз с высокой интенсивностью изменений — каждые 5-10 минут.

## Влияет ли регистрация на производительность?

Да, при большом количестве изменяемых объектов может наблюдаться временное замедление. Рекомендуется выполнять регистрацию в нерабочее время.

## Решение проблем

## Изменения не регистрируются

Проверьте, что выбран хотя бы один объект метаданных. Убедитесь, что за указанный период есть изменения.

## Список изменений пуст

Возможные причины:
- Объекты не были изменены с момента последней регистрации;
- Период регистрации не перекрывает даты изменений;
- Регистрация отключена для выбранных объектов.

## Ошибка при экспорте

Убедитесь, что файл назначения не открыт в другой программе. Проверьте права на запись в указанную папку.

## Дублирование изменений

Если изменение регистрируется повторно, значит с момента последней регистрации объект был модифицирован снова. Это нормальное поведение. Для очистки дублей используйте автоматическую очистку.

## Регистрация не запускается в регламентном задании

Проверьте настройки регламентного задания **УИ_РегистрацияИзменений**: расписание, активность, пользователя, от имени которого выполняется задание.
