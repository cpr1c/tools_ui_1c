# FAQ

## Какие объекты поддерживают регистрацию изменений?

Справочники, документы, регистры сведений, регистры накопления, регистры бухгалтерии, регистры расчёта, планы видов характеристик, планы счетов, бизнес-процессы и задачи.

## Как отменить регистрацию конкретного изменения?

Выберите изменение в списке и нажмите **Снять отметку**. Изменение будет удалено из списка зарегистрированных.

## Нужно ли регистрировать изменения вручную?

Регистрация может выполняться как вручную, так и автоматически через регламентное задание. Для автоматической регистрации настройте задание **УИ_РегистрацияИзменений**.

## Как часто следует регистрировать изменения?

Рекомендуется выполнять регистрацию по расписанию (например, раз в час) перед плановым обменом данными. Для баз с высокой интенсивностью изменений — каждые 5-10 минут.

## Влияет ли регистрация на производительность?

Да, при большом количестве изменяемых объектов может наблюдаться временное замедление. Рекомендуется выполнять регистрацию в нерабочее время.
