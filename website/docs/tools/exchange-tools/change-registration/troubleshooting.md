# Устранение неполадок

## Изменения не регистрируются

Проверьте, что выбран хотя бы один объект метаданных. Убедитесь, что за указанный период есть изменения.

## Список изменений пуст

Возможные причины:
- Объекты не были изменены с момента последней регистрации;
- Период регистрации не перекрывает даты изменений;
- Регистрация отключена для выбранных объектов.

## Ошибка при экспорте

Убедитесь, что файл назначения не открыт в другой программе. Проверьте права на запись в указанную папку.

## Дублирование изменений

Если изменение регистрируется повторно, значит с момента последней регистрации объект был модифицирован снова. Это нормальное поведение. Для очистки дублей используйте автоматическую очистку.

## Регистрация не запускается в регламентном задании

Проверьте настройки регламентного задания **УИ_РегистрацияИзменений**: расписание, активность, пользователя, от имени которого выполняется задание.
