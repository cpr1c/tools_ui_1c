# Устранение неполадок

## Ошибка при открытии файла

Файл может быть повреждён, открыт в другой программе или иметь неподдерживаемый формат. Закройте файл в Excel и повторите попытку.

## Неверное сопоставление типов

Если числовое значение загружается как строка, проверьте формат ячеек в исходном файле. Для Excel используйте числовой формат, а не текстовый.

## Ошибка «Не найден реквизит»

Проверьте, что имя реквизита приёмника указано точно. Имена реквизитов чувствительны к регистру.

## Данные не записываются в регистр

Убедитесь, что для регистра указаны все обязательные поля (измерения, ресурсы, реквизиты). Для периодических регистров обязательно указывать дату или период.

## Загрузка выполняется очень долго

Для больших файлов (более 10 000 строк) рекомендуется:
- Разделить файл на части;
- Отключить проверку дублей;
- Использовать пакетный режим загрузки.
