# Возможности

## Основные возможности

- **Загрузка из табличного документа** — импорт данных из форматов MXL, XLS, XLSX, CSV, ODS в справочники и табличные части;
- **Гибкая привязка колонок** — сопоставление колонок источника реквизитам приёмника данных;
- **Проверка корректности данных** — автоматическая валидация типов, обязательных полей и ссылочной целостности.

## Режимы загрузки

- **Загрузка в справочники** — создание и обновление элементов справочников;
- **Загрузка в табличные части** — заполнение табличных частей документов и справочников;
- **Загрузка в регистры** — запись движений в регистры сведений и накопления.

## Обработка данных

- **Поиск дублей** — автоматический поиск и предотвращение дублирования;
- **Трансформация данных** — приведение типов, форматирование строк, преобразование дат;
- **Пакетная загрузка** — обработка больших объёмов без потери производительности.

## Настройки

- Поддержка заголовков в первой строке файла;
- Произвольный порядок колонок при сопоставлении;
- Сохранение настроек привязки между сеансами.
