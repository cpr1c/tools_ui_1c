# Загрузка данных из табличного документа

Загрузка данных в справочники и табличные части из табличного документа.

## Назначение

- Быстрая загрузка данных из Excel/CSV
- Импорт данных в справочники
- Заполнение табличных частей

## Особенности

- Поддержка табличных документов
- Гибкая привязка колонок
- Проверка корректности данных

## Использование

1. Перейдите в меню **Универсальные инструменты → Загрузка данных из ТД**
2. Выберите табличный документ
3. Настройте привязку колонок
4. Выполните загрузку
