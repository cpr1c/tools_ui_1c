# Загрузка данных из табличного документа

Загрузка данных в справочники и табличные части из табличного документа.

## Назначение

- Быстрая загрузка данных из Excel/CSV
- Импорт данных в справочники
- Заполнение табличных частей

## Особенности

- Поддержка табличных документов
- Гибкая привязка колонок
- Проверка корректности данных

## Использование

1. Перейдите в меню **Универсальные инструменты → Загрузка данных из ТД**
2. Выберите табличный документ
3. Настройте привязку колонок
4. Выполните загрузку

## Возможности

## Основные возможности

- **Загрузка из табличного документа** — импорт данных из форматов MXL, XLS, XLSX, CSV, ODS в справочники и табличные части;
- **Гибкая привязка колонок** — сопоставление колонок источника реквизитам приёмника данных;
- **Проверка корректности данных** — автоматическая валидация типов, обязательных полей и ссылочной целостности.

## Режимы загрузки

- **Загрузка в справочники** — создание и обновление элементов справочников;
- **Загрузка в табличные части** — заполнение табличных частей документов и справочников;
- **Загрузка в регистры** — запись движений в регистры сведений и накопления.

## Обработка данных

- **Поиск дублей** — автоматический поиск и предотвращение дублирования;
- **Трансформация данных** — приведение типов, форматирование строк, преобразование дат;
- **Пакетная загрузка** — обработка больших объёмов без потери производительности.

## Настройки

- Поддержка заголовков в первой строке файла;
- Произвольный порядок колонок при сопоставлении;
- Сохранение настроек привязки между сеансами.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Загрузка данных из ТД**.

## Загрузка данных

1. Выберите источник — файл табличного документа (MXL, XLS, XLSX, CSV);
2. Укажите приёмник — справочник, документ или регистр;
3. Настройте привязку колонок: перетащите заголовки колонок на соответствующие реквизиты;
4. Проверьте данные в режиме предпросмотра;
5. Нажмите **Загрузить**.

## Пример привязки колонок

| Колонка файла | Реквизит приёмника |
|---------------|-------------------|
| Наименование  | Наименование      |
| Артикул       | Код               |
| Цена          | Цена              |
| Ед. изм.     | ЕдиницаИзмерения  |

## Программный вызов

```bsl
// Загрузка из табличного документа
Загрузка = Обработки.ЗагрузкаДанныхИзТабличногоДокумента.Создать();
Загрузка.ИмяФайла = "C:\data\items.xlsx";
Загрузка.ИмяПриёмника = "Справочник.Номенклатура";
Загрузка.Колонки.Очистить();
Загрузка.Колонки.Добавить("Наименование", "Колонка1");
Загрузка.Колонки.Добавить("Код", "Колонка2");
Загрузка.ВыполнитьЗагрузку();
```

## Часто задаваемые вопросы

## Какие форматы файлов поддерживаются?

Поддерживаются MXL (встроенный формат 1С), XLS, XLSX (Microsoft Excel), ODS (OpenOffice) и CSV (текстовый с разделителями).

## Можно ли загружать данные в регистры?

Да. Поддерживается загрузка в регистры сведений (периодические и непериодические) и регистры накопления.

## Как избежать дублирования элементов?

В настройках привязки укажите ключевые поля для поиска существующих элементов. Если элемент найден, он будет обновлён, а не создан заново.

## Как загрузить данные с заголовками?

Отметьте флаг **Первая строка — заголовки**. Имена колонок из первой строки будут автоматически подставлены в настройки привязки.

## Почему не загружается CSV-файл?

Проверьте разделитель полей и кодировку файла. Для кириллицы рекомендуется кодировка UTF-8 или CP1251. Разделитель по умолчанию — точка с запятой (;).

## Решение проблем

## Ошибка при открытии файла

Файл может быть повреждён, открыт в другой программе или иметь неподдерживаемый формат. Закройте файл в Excel и повторите попытку.

## Неверное сопоставление типов

Если числовое значение загружается как строка, проверьте формат ячеек в исходном файле. Для Excel используйте числовой формат, а не текстовый.

## Ошибка «Не найден реквизит»

Проверьте, что имя реквизита приёмника указано точно. Имена реквизитов чувствительны к регистру.

## Данные не записываются в регистр

Убедитесь, что для регистра указаны все обязательные поля (измерения, ресурсы, реквизиты). Для периодических регистров обязательно указывать дату или период.

## Загрузка выполняется очень долго

Для больших файлов (более 10 000 строк) рекомендуется:
- Разделить файл на части;
- Отключить проверку дублей;
- Использовать пакетный режим загрузки.
