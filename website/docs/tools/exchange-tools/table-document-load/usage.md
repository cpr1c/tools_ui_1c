# Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Загрузка данных из ТД**.

## Загрузка данных

1. Выберите источник — файл табличного документа (MXL, XLS, XLSX, CSV);
2. Укажите приёмник — справочник, документ или регистр;
3. Настройте привязку колонок: перетащите заголовки колонок на соответствующие реквизиты;
4. Проверьте данные в режиме предпросмотра;
5. Нажмите **Загрузить**.

## Пример привязки колонок

| Колонка файла | Реквизит приёмника |
|---------------|-------------------|
| Наименование  | Наименование      |
| Артикул       | Код               |
| Цена          | Цена              |
| Ед. изм.     | ЕдиницаИзмерения  |

## Программный вызов

```bsl
// Загрузка из табличного документа
Загрузка = Обработки.ЗагрузкаДанныхИзТабличногоДокумента.Создать();
Загрузка.ИмяФайла = "C:\data\items.xlsx";
Загрузка.ИмяПриёмника = "Справочник.Номенклатура";
Загрузка.Колонки.Очистить();
Загрузка.Колонки.Добавить("Наименование", "Колонка1");
Загрузка.Колонки.Добавить("Код", "Колонка2");
Загрузка.ВыполнитьЗагрузку();
```
