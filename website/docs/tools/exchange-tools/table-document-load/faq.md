# FAQ

## Какие форматы файлов поддерживаются?

Поддерживаются MXL (встроенный формат 1С), XLS, XLSX (Microsoft Excel), ODS (OpenOffice) и CSV (текстовый с разделителями).

## Можно ли загружать данные в регистры?

Да. Поддерживается загрузка в регистры сведений (периодические и непериодические) и регистры накопления.

## Как избежать дублирования элементов?

В настройках привязки укажите ключевые поля для поиска существующих элементов. Если элемент найден, он будет обновлён, а не создан заново.

## Как загрузить данные с заголовками?

Отметьте флаг **Первая строка — заголовки**. Имена колонок из первой строки будут автоматически подставлены в настройки привязки.

## Почему не загружается CSV-файл?

Проверьте разделитель полей и кодировку файла. Для кириллицы рекомендуется кодировка UTF-8 или CP1251. Разделитель по умолчанию — точка с запятой (;).
