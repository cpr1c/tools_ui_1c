# Возможности

## Основные возможности

- **Обмен по правилам** — выгрузка и загрузка данных с использованием правил обмена (ПВД, ПКО, ПС);
- **Прямая загрузка через HTTP** — передача данных напрямую в базу-приёмник через HTTP-сервис;
- **Фильтрация данных** — отбор объектов по периоду, отборам и видам.

## Режимы обмена

- **Двусторонний обмен** — синхронизация данных между двумя базами;
- **Односторонняя выгрузка** — только отправка данных;
- **Односторонняя загрузка** — только приём данных.

## HTTP-сервис

- Поддержка прямой загрузки через HTTP-сервис подсистемы **УИ_ПубликуемыеФункции**;
- Автоматическая обработка входящих сообщений;
- Поддержка авторизации и проверки подписи.

## Гибкая настройка

- Поддержка произвольных правил конвертации объектов;
- Настройка соответствия реквизитов;
- Обработка ссылок на несуществующие объекты.

## Интеграция

- Совместимость со стандартными механизмами обмена 1С;
- Поддержка форматов XML и ZIP;
- Интеграция с планировщиком заданий для автоматического обмена по расписанию.
