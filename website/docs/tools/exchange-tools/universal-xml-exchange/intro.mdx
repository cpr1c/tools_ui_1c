# Универсальный обмен данными XML

Выгрузка и загрузка по правилам обмена с фильтрами и прямой загрузкой через HTTP-сервис.

## Назначение

- Универсальный обмен данными между базами
- Прямая загрузка через HTTP-сервис
- Гибкая настройка правил обмена

## Особенности

- Поддержка правил обмена
- Прямая загрузка через HTTP
- Фильтрация данных

## Использование

1. Перейдите в меню **Универсальные инструменты → Универсальный обмен данными**
2. Настройте правила обмена
3. Выполните выгрузку или загрузку

## HTTP-сервис для обмена

Универсальный обмен поддерживает прямую выгрузку в базу через HTTP-сервис подсистемы **УИ_ПубликуемыеФункции**.

## Возможности

## Основные возможности

- **Обмен по правилам** — выгрузка и загрузка данных с использованием правил обмена (ПВД, ПКО, ПС);
- **Прямая загрузка через HTTP** — передача данных напрямую в базу-приёмник через HTTP-сервис;
- **Фильтрация данных** — отбор объектов по периоду, отборам и видам.

## Режимы обмена

- **Двусторонний обмен** — синхронизация данных между двумя базами;
- **Односторонняя выгрузка** — только отправка данных;
- **Односторонняя загрузка** — только приём данных.

## HTTP-сервис

- Поддержка прямой загрузки через HTTP-сервис подсистемы **УИ_ПубликуемыеФункции**;
- Автоматическая обработка входящих сообщений;
- Поддержка авторизации и проверки подписи.

## Гибкая настройка

- Поддержка произвольных правил конвертации объектов;
- Настройка соответствия реквизитов;
- Обработка ссылок на несуществующие объекты.

## Интеграция

- Совместимость со стандартными механизмами обмена 1С;
- Поддержка форматов XML и ZIP;
- Интеграция с планировщиком заданий для автоматического обмена по расписанию.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Универсальный обмен данными**.

## Настройка правил обмена

1. Загрузите правила обмена (файл XML с настройками ПВД/ПКО/ПС);
2. Настройте соответствие объектов и реквизитов при необходимости;
3. Проверьте корректность настроек кнопкой **Проверить**.

## Выгрузка данных

1. Выберите направление обмена;
2. Задайте период выгрузки;
3. Нажмите **Выгрузить данные**;
4. Сохраните файл обмена.

## Загрузка данных через HTTP-сервис

```bsl
// Пример отправки данных через HTTP-сервис
АдресСервиса = "http://server/УИ_ПубликуемыеФункции/ОбменДанными";
Соединение = Новый HTTPСоединение(АдресСервиса);
Запрос = Новый HTTPЗапрос();
Запрос.Заголовки.Вставить("Content-Type", "application/octet-stream");
Запрос.УстановитьИмяФайлаТела(ИмяФайлаОбмена);

Ответ = Соединение.ОтправитьДляОбработки(Запрос);
```

## Автоматический обмен по расписанию

Настройте регламентное задание **УИ_ОбменДанными** в конфигураторе. Оно будет выполняться автоматически по заданному расписанию.

## Часто задаваемые вопросы

## Нужны ли правила обмена для работы?

Да, для корректной работы требуется загрузить хотя бы минимальные правила обмена. Без правил обработка не сможет определить соответствие объектов.

## Можно ли использовать обработку без HTTP-сервиса?

Да. Выгрузка и загрузка через файл работает без HTTP-сервиса. Прямая загрузка через HTTP — дополнительная опция для автоматизации.

## Поддерживается ли обмен с нетиповыми конфигурациями?

Да, поддерживается. Для этого необходимо настроить правила обмена, описывающие соответствие объектов и реквизитов.

## Какие форматы файлов поддерживаются?

Поддерживаются XML и ZIP (сжатый XML). ZIP рекомендуется для больших объёмов данных.

## Как часто можно выполнять обмен?

Ограничений нет. При автоматическом обмене через регламентное задание рекомендуемый интервал — не чаще 1 раза в 5 минут.

## Решение проблем

## Ошибка HTTP-соединения

Проверьте, что HTTP-сервис опубликован на сервере и доступен по указанному адресу. Проверьте настройки брандмауэра.

## Ошибка «Не удалось загрузить правила обмена»

Файл правил повреждён или имеет неверную структуру. Загрузите правильный файл правил с диска ИТС или сформируйте заново.

## Данные не выгружаются

Проверьте, что выбран хотя бы один объект для выгрузки и указан период. Убедитесь, что в базе есть данные за указанный период.

## Дубли при загрузке

Настройте правила поиска дублирующихся объектов в правилах обмена. Укажите ключевые поля для поиска.

## Ошибка таймаута при HTTP-загрузке

Увеличьте таймаут в настройках HTTP-соединения на стороне отправителя. Разделите большой файл на несколько частей.
