# Универсальный обмен данными XML

Выгрузка и загрузка по правилам обмена с фильтрами и прямой загрузкой через HTTP-сервис.

## Назначение

- Универсальный обмен данными между базами
- Прямая загрузка через HTTP-сервис
- Гибкая настройка правил обмена

## Особенности

- Поддержка правил обмена
- Прямая загрузка через HTTP
- Фильтрация данных

## Использование

1. Перейдите в меню **Универсальные инструменты → Универсальный обмен данными**
2. Настройте правила обмена
3. Выполните выгрузку или загрузку

## HTTP-сервис для обмена

Универсальный обмен поддерживает прямую выгрузку в базу через HTTP-сервис подсистемы **УИ_ПубликуемыеФункции**.
