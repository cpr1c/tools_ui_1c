# Устранение неполадок

## Ошибка HTTP-соединения

Проверьте, что HTTP-сервис опубликован на сервере и доступен по указанному адресу. Проверьте настройки брандмауэра.

## Ошибка «Не удалось загрузить правила обмена»

Файл правил повреждён или имеет неверную структуру. Загрузите правильный файл правил с диска ИТС или сформируйте заново.

## Данные не выгружаются

Проверьте, что выбран хотя бы один объект для выгрузки и указан период. Убедитесь, что в базе есть данные за указанный период.

## Дубли при загрузке

Настройте правила поиска дублирующихся объектов в правилах обмена. Укажите ключевые поля для поиска.

## Ошибка таймаута при HTTP-загрузке

Увеличьте таймаут в настройках HTTP-соединения на стороне отправителя. Разделите большой файл на несколько частей.
