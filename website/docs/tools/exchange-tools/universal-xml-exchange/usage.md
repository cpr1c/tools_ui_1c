# Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Универсальный обмен данными**.

## Настройка правил обмена

1. Загрузите правила обмена (файл XML с настройками ПВД/ПКО/ПС);
2. Настройте соответствие объектов и реквизитов при необходимости;
3. Проверьте корректность настроек кнопкой **Проверить**.

## Выгрузка данных

1. Выберите направление обмена;
2. Задайте период выгрузки;
3. Нажмите **Выгрузить данные**;
4. Сохраните файл обмена.

## Загрузка данных через HTTP-сервис

```bsl
// Пример отправки данных через HTTP-сервис
АдресСервиса = "http://server/УИ_ПубликуемыеФункции/ОбменДанными";
Соединение = Новый HTTPСоединение(АдресСервиса);
Запрос = Новый HTTPЗапрос();
Запрос.Заголовки.Вставить("Content-Type", "application/octet-stream");
Запрос.УстановитьИмяФайлаТела(ИмяФайлаОбмена);

Ответ = Соединение.ОтправитьДляОбработки(Запрос);
```

## Автоматический обмен по расписанию

Настройте регламентное задание **УИ_ОбменДанными** в конфигураторе. Оно будет выполняться автоматически по заданному расписанию.
