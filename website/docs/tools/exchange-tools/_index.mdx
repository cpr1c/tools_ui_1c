# Инструменты обмена

Инструменты для выгрузки, загрузки и обмена данными между информационными базами.

## Содержание

- [Выгрузка загрузка XML с фильтрами](/docs/tools/exchange-tools/xml-upload-download) — XML обмен
- [Универсальный обмен данными XML](/docs/tools/exchange-tools/universal-xml-exchange) — универсальный обмен
- [Регистрация изменений для обмена](/docs/tools/exchange-tools/change-registration) — регистрация изменений
- [Загрузка данных из табличного документа](/docs/tools/exchange-tools/table-document-load) — загрузка из ТД

## HTTP-сервис для обмена

Универсальный обмен поддерживает прямую выгрузку в базу через HTTP-сервис подсистемы **УИ_ПубликуемыеФункции**.

## Интеграция с формами объектов

Из подменю **Инструменты** в списках объектов (при подключении к БСП) доступна команда **Выгрузить объекты в XML** — выгрузка выбранных объектов с подчинёнными ссылками.
