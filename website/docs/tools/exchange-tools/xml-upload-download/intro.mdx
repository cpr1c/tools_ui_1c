# Выгрузка загрузка XML с фильтрами

Перенос информации между однородными базами данных.

## Назначение

- Выгрузка и загрузка данных в формате XML
- Фильтрация переносимых данных
- Синхронизация баз данных

## Особенности

- Поддержка всех типов объектов
- Фильтрация по различным критериям
- Проверка целостности данных

## Использование

1. Перейдите в меню **Универсальные инструменты → Выгрузка загрузка XML**
2. Выберите объекты для выгрузки
3. Настройте фильтры
4. Выполните выгрузку или загрузку

## Возможности

## Основные возможности

- **Выгрузка объектов в XML** — выгрузка справочников, документов, регистров и других объектов метаданных в формат XML для последующей загрузки в другую базу.
- **Загрузка из XML с контролем** — загрузка данных из XML-файла с проверкой целостности и ссылочной целостности.
- **Гибкая фильтрация** — отбор по периоду, по конкретным объектам, по произвольным условиям отбора.

## Фильтрация данных

- **По периоду** — выгрузка только за указанный период;
- **По отборам** — настройка произвольных отборов по реквизитам объектов;
- **По видам объектов** — выбор конкретных справочников, документов, регистров;
- **По ссылкам** — выгрузка объектов по списку ссылок.

## Режимы работы

- **Полная выгрузка** — все данные без ограничений;
- **Выгрузка изменений** — только изменённые с момента последней выгрузки объекты;
- **Инкрементальная загрузка** — добавление и обновление существующих данных.

## Интеграция

- Совместимость со стандартными форматами XML 1С;
- Поддержка обмена между конфигурациями на одинаковых метаданных;
- Интеграция с подсистемой регистрации изменений.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Выгрузка загрузка XML**.

## Выгрузка данных

1. Выберите объекты для выгрузки в табличной части;
2. Настройте фильтры при необходимости (период, отборы);
3. Укажите путь для сохранения XML-файла;
4. Нажмите **Выполнить выгрузку**.

## Загрузка данных

1. Выберите ранее сохранённый XML-файл;
2. Настройте режим загрузки (замена/добавление);
3. Нажмите **Выполнить загрузку**.

## Программный вызов

```bsl
// Выгрузка с фильтром по периоду
ПараметрыВыгрузки = Обработки.ВыгрузкаЗагрузкаXML.Создать();
ПараметрыВыгрузки.ДатаНачала = НачалоМесяца(ТекущаяДата());
ПараметрыВыгрузки.ДатаОкончания = КонецМесяца(ТекущаяДата());
ПараметрыВыгрузки.ОбъектыВыгрузки.Добавить("Справочник.Номенклатура");
ПараметрыВыгрузки.ВыполнитьВыгрузку(ИмяФайла);

// Загрузка из файла
ПараметрыЗагрузки = Обработки.ВыгрузкаЗагрузкаXML.Создать();
ПараметрыЗагрузки.ВыполнитьЗагрузку(ИмяФайла);
```

## Советы

- Перед загрузкой рекомендуется создать резервную копию базы;
- Для больших объёмов используйте выгрузку по частям с фильтром по периоду.

## Часто задаваемые вопросы

## Можно ли выгружать только новые и изменённые объекты?

Да. Установите флаг **Выгружать только изменённые** и укажите дату начала периода. Будут выгружены объекты, изменённые после указанной даты.

## Как выгрузить только определённые элементы справочника?

Используйте вкладку **Отборы**. Добавьте строку отбора по нужному реквизиту, например: `Наименование Подобно "Товар%"` или `Родитель = &ВыбраннаяГруппа`.

## Поддерживается ли выгрузка табличных частей?

Да, табличные части выгружаются вместе с объектом-владельцем. Отдельная выгрузка табличных частей не поддерживается.

## Что делать, если файл XML не загружается?

Проверьте, что файл не повреждён, и что конфигурации источника и приёмника совпадают по составу метаданных. Различия в реквизитах могут приводить к ошибкам.

## Решение проблем

## Ошибка «Не найден объект метаданных»

Возникает при несовпадении метаданных в базах-отправителе и получателе. Убедитесь, что конфигурации идентичны.

## Ошибка при загрузке XML

Файл повреждён или имеет неверный формат. Откройте XML в текстовом редакторе и проверьте структуру на соответствие схеме XSD.

## Дублирование данных после загрузки

Включите режим **Замена существующих** при загрузке. Если объект уже существует, он будет обновлён, а не создан повторно.

## Некорректные ссылки после загрузки

Причина — нарушение порядка загрузки объектов. Выгружайте и загружайте данные в правильной последовательности: сначала справочники, затем документы, после — регистры.
