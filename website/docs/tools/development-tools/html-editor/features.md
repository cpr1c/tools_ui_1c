# Возможности

## Основные возможности

- **Подсветка синтаксиса HTML, CSS, JavaScript** — раздельные панели для каждого языка с цветовой подсветкой.
- **Предпросмотр в реальном времени** — мгновенное отображение результата в панели предпросмотра при выполнении кода.
- **Редактор на базе Ace** — мощный текстовый редактор с автодополнением, нумерацией строк и множеством тем оформления.
- **Изолированное выполнение** — JavaScript выполняется в изолированном iframe, что предотвращает влияние на основное приложение.

## Дополнительные возможности

- **Поддержка внешних библиотек** — возможность подключать CSS-фреймворки (Bootstrap, Tailwind) и JavaScript-библиотеки (jQuery, React) через CDN.
- **Сохранение проектов** — HTML/CSS/JS можно сохранить как единый HTML-файл или как отдельные файлы.
- **Настройка темы редактора** — переключение между светлой и тёмной темой.

## Интеграция

- HTML-шаблоны можно создавать в редакторе и затем использовать в [Консоли кода](/docs/tools/development-tools/code-console) для генерации HTML-писем или отчётов.
- Полученный HTML-код можно сохранить в [Редакторе JSON](/docs/tools/development-tools/json-editor) как часть структуры данных.
- Инструмент удобен для отладки HTML-шаблонов, используемых в СКД и печатных формах.
