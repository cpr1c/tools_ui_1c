# Редактор HTML

Отладка HTML/CSS/JavaScript с предпросмотром. Редакторы на базе [Ace](https://ace.c9.io/).

## Назначение

- Отладка HTML/CSS/JavaScript кода
- Предпросмотр результатов
- Быстрое тестирование фронтенд-частей

## Особенности

- Подсветка синтаксиса HTML, CSS, JavaScript
- Предпросмотр результатов
- Разделение на три панели: код, стили, скрипты

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор HTML**
2. Введите HTML, CSS и JavaScript код
3. Нажмите **Предпросмотр** или **F5**
4. Посмотрите результат в панели предпросмотра

## Возможности

## Основные возможности

- **Подсветка синтаксиса HTML, CSS, JavaScript** — раздельные панели для каждого языка с цветовой подсветкой.
- **Предпросмотр в реальном времени** — мгновенное отображение результата в панели предпросмотра при выполнении кода.
- **Редактор на базе Ace** — мощный текстовый редактор с автодополнением, нумерацией строк и множеством тем оформления.
- **Изолированное выполнение** — JavaScript выполняется в изолированном iframe, что предотвращает влияние на основное приложение.

## Дополнительные возможности

- **Поддержка внешних библиотек** — возможность подключать CSS-фреймворки (Bootstrap, Tailwind) и JavaScript-библиотеки (jQuery, React) через CDN.
- **Сохранение проектов** — HTML/CSS/JS можно сохранить как единый HTML-файл или как отдельные файлы.
- **Настройка темы редактора** — переключение между светлой и тёмной темой.

## Интеграция

- HTML-шаблоны можно создавать в редакторе и затем использовать в [Консоли кода](/docs/tools/development-tools/code-console) для генерации HTML-писем или отчётов.
- Полученный HTML-код можно сохранить в [Редакторе JSON](/docs/tools/development-tools/json-editor) как часть структуры данных.
- Инструмент удобен для отладки HTML-шаблонов, используемых в СКД и печатных формах.

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Редактор HTML**.
2. Введите HTML-код в верхней панели.
3. При необходимости добавьте CSS и JavaScript в соответствующие панели.
4. Нажмите **Предпросмотр** или **F5**.
5. Результат отобразится в панели предпросмотра справа.

## Сценарии использования

### Сценарий 1: Создание HTML-шаблона письма

```html
<!DOCTYPE html>
<html>
<head>
<style>
  body { font-family: Arial, sans-serif; }
  .header { background: #2c3e50; color: white; padding: 20px; }
  .content { padding: 20px; }
  .footer { font-size: 12px; color: #999; }
</style>
</head>
<body>
  <div class="header">
    <h1>Уведомление об оплате</h1>
  </div>
  <div class="content">
    <p>Уважаемый клиент, оплата получена.</p>
    <p>Сумма: <strong>15 000 руб.</strong></p>
  </div>
  <div class="footer">
    <p>С уважением, Бухгалтерия</p>
  </div>
</body>
</html>
```

### Сценарий 2: Отладка JavaScript-скрипта

```html
<!DOCTYPE html>
<html>
<body>
  <input type="text" id="name" placeholder="Введите имя">
  <button onclick="greet()">Приветствовать</button>
  <p id="result"></p>

  <script>
    function greet() {
      var name = document.getElementById('name').value;
      document.getElementById('result').textContent =
        'Привет, ' + name + '!';
    }
  </script>
</body>
</html>
```

### Сценарий 3: Тестирование печатной формы

Используйте редактор для отладки макета HTML-печатной формы перед интеграцией в конфигурацию 1С. После отладки скопируйте код для использования с `HTMLПисатель` в BSL.

## Часто задаваемые вопросы

## Общие вопросы

### Можно ли подключать внешние библиотеки?
Да, добавьте ссылки на CDN в HTML-коде, например: `<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css">`. Библиотеки загрузятся при предпросмотре.

### Работает ли JavaScript в предпросмотре?
Да, JavaScript выполняется в изолированном iframe. Все стандартные возможности браузера доступны (DOM, XMLHttpRequest, fetch).

### Как сохранить результат в один файл?
Используйте функцию «Сохранить как HTML» — все стили и скрипты будут встроены в один HTML-файл.

## Технические вопросы

### Почему скрипт не выполняется?
Проверьте консоль браузера на наличие ошибок (F12). Убедитесь, что скрипт не содержит синтаксических ошибок. В режиме предпросмотра скрипты выполняются после загрузки страницы.

### Поддерживается ли CSS Grid и Flexbox?
Да, предпросмотр использует современный браузерный движок, поэтому все современные возможности CSS (Grid, Flexbox, анимации) полностью поддерживаются.

### Как отключить предпросмотр?
Можно скрыть панель предпросмотра через меню «Вид» → «Панель предпросмотра». Это ускорит работу при редактировании больших файлов.

### Можно ли открыть HTML-файл с диска?
Да, используйте кнопку «Открыть файл» и выберите HTML-файл. Все три секции (HTML, CSS, JS) будут заполнены автоматически.

## Решение проблем

## Проблема: Предпросмотр не отображает изменения
**Причина:** Не нажата кнопка «Предпросмотр» или не сохранены изменения.
**Решение:** Нажмите **F5** или кнопку «Предпросмотр» для обновления iframe. Убедитесь, что изменения внесены в правильную панель (HTML, CSS или JS).

## Проблема: В предпросмотре отображается пустая страница
**Причина:** В HTML-коде отсутствует обязательная структура (`<!DOCTYPE html>`, `<html>`, `<body>`).
**Решение:** Добавьте минимальную структуру HTML-документа. Даже простой текст должен быть обёрнут в `<body>`.

## Проблема: Не загружаются стили Bootstrap
**Причина:** URL CDN недоступен или блокируется политикой безопасности.
**Решение:** Проверьте доступность CDN в браузере. Используйте альтернативные CDN (cdnjs, unpkg) или загрузите библиотеку локально.

## Проблема: Ошибка CORS в JavaScript
**Причина:** Скрипт пытается загрузить данные с другого домена, который не разрешает CORS.
**Решение:** Используйте режим `no-cors` для запросов или настройте сервер для поддержки CORS. Для тестирования используйте JSONP.

## Проблема: Медленно работает при большом HTML
**Причина:** В HTML-файле содержится много данных (например, большая таблица).
**Решение:** Временно скройте панель предпросмотра. Оптимизируйте HTML-код перед просмотром.
