# Часто задаваемые вопросы

## Общие вопросы

### Какие существуют горячие клавиши?
F5 — выполнить код, Ctrl+S — сохранить в файл, Ctrl+O — открыть файл, Ctrl+Z / Ctrl+Y — отмена / повтор действия.

### Можно ли выполнить только часть кода?
Да, выделите нужный фрагмент мышью и нажмите F5 — выполнится только выделенный участок.

### Сохраняется ли история выполненных команд?
Да, все команды автоматически сохраняются в истории. Вы можете повторно вызвать любую из них через панель истории.

## Технические вопросы

### Работает ли консоль на тонком клиенте?
Да, консоль кода полностью работает на тонком клиенте, толстом клиенте и в режиме веб-клиента.

### Почему не выполняется мой код?
Возможные причины: синтаксическая ошибка в коде, отсутствие прав на выполнение операций, использование несуществующих объектов метаданных. Проверьте панель ошибок — там отображается подробная диагностика.

### Как вставить результат выполнения в отчёт или документ?
Результат можно скопировать из панели результатов в буфер обмена (Ctrl+C) и вставить в любое приложение.

### Влияет ли выполнение кода на текущую сессию 1С?
Да, код выполняется в контексте текущего сеанса. Изменения данных (запись объектов) применяются непосредственно в базе данных, если не используется транзакция.
