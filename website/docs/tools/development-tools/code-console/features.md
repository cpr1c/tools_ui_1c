# Возможности

## Основные возможности

- **Подсветка синтаксиса BSL** — удобное цветовое выделение ключевых слов, операторов и комментариев, упрощающее чтение и написание кода.
- **Контекстная подсказка** — автодополнение методов, свойств и переменных при вводе. Работает для глобального контекста и типов 1С.
- **Выполнение выделенного кода** — возможность запустить не всю строку, а только выделенный фрагмент. Удобно при отладке небольших участков.
- **История выполнения** — автоматическое сохранение всех выполненных команд с возможностью повторного вызова.
- **Панель результатов** — вывод результата выполнения, сообщений об ошибках и диагностической информации в нижней части формы.
- **Сохранение и загрузка скриптов** — возможность сохранить код в файл и загрузить ранее сохранённый скрипт.

## Дополнительные возможности

- **Работа с внешними обработками** — код выполняется в контексте, аналогичном внешней обработке, что позволяет тестировать алгоритмы максимально приближенно к реальным условиям.
- **Горячие клавиши** — быстрый доступ к основным функциям: F5 — выполнить, Ctrl+S — сохранить, Ctrl+O — открыть.
- **Настройка шрифта и темы** — адаптация редактора под индивидуальные предпочтения.

## Интеграция

- Результат выполнения можно скопировать в буфер обмена или сохранить в текстовый файл.
- Код можно экспортировать в формат `.epf` для использования в качестве внешней обработки.
- Тесная интеграция с [Редактором JSON](/docs/tools/development-tools/json-editor) и [Консолью запросов](/docs/tools/development-tools/query-console) — результаты запросов и JSON можно обрабатывать напрямую в консоли кода.
