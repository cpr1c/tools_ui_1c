# Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Консоль кода**.
2. Введите код в текстовое поле редактора.
3. Нажмите кнопку **Выполнить** или клавишу **F5**.
4. Просмотрите результат в нижней панели.

## Сценарии использования

### Сценарий 1: Отладка алгоритма

Напишите и выполните небольшую функцию для проверки логики:

```1c
Функция РассчитатьСкидку(Цена, КоличествоТоваров)
    Если КоличествоТоваров > 10 Тогда
        Скидка = 0.15;
    ИначеЕсли КоличествоТоваров > 5 Тогда
        Скидка = 0.1;
    Иначе
        Скидка = 0;
    КонецЕсли;
    Возврат Цена * (1 - Скидка);
КонецФункции

Сообщить(РассчитатьСкидку(1000, 12));
```

### Сценарий 2: Пакетная операция с данными

Выполните массовое обновление данных напрямую:

```1c
Выборка = Справочники.Номенклатура.Выбрать();
Пока Выборка.Следующий() Цикл
    Если Выборка.Артикул = "" Тогда
        Попытка
            Выборка.Артикул = "ART-" + Строка(Выборка.НомерСтроки);
            Выборка.Записать();
        Исключение
            Сообщить("Ошибка: " + ОписаниеОшибки());
        КонецПопытки;
    КонецЕсли;
КонецЦикла;
```

### Сценарий 3: Проверка работы внешней обработки

Имитируйте подключение внешней обработки и проверьте экспортные процедуры:

```1c
Обработка = ВнешниеОбработки.Создать("ПутьКФайлу.epf");
Если Обработка.ЭкспортныеПроцедуры.Содержит("ВыполнитьПроверку") Тогда
    Результат = Обработка.ВыполнитьПроверку(ТекущаяДата());
    Сообщить(Результат);
КонецЕсли;
```
