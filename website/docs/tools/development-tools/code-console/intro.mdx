# Консоль кода

Выполнение кода из 1С без создания внешних обработок. Поддержка подсветки синтаксиса и контекстной подсказки.

## Назначение

Консоль кода позволяет быстро выполнить произвольный код BSL прямо из интерфейса 1С. Это удобно для:
- Отладки и тестирования фрагментов кода
- Быстрого выполнения одноразовых операций
- Проверки гипотез и экспериментов с кодом

## Особенности

- Подсветка синтаксиса BSL
- Контекстная подсказка
- История выполненных команд
- Возможность сохранения кода в файл

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль кода**
2. Введите код в поле ввода
3. Нажмите **Выполнить** или **F5**
4. Результат выполнения отобразится в нижней панели
