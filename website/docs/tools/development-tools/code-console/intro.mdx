# Консоль кода

Выполнение кода из 1С без создания внешних обработок. Поддержка подсветки синтаксиса и контекстной подсказки.

## Назначение

Консоль кода позволяет быстро выполнить произвольный код BSL прямо из интерфейса 1С. Это удобно для:
- Отладки и тестирования фрагментов кода
- Быстрого выполнения одноразовых операций
- Проверки гипотез и экспериментов с кодом

## Особенности

- Подсветка синтаксиса BSL
- Контекстная подсказка
- История выполненных команд
- Возможность сохранения кода в файл

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль кода**
2. Введите код в поле ввода
3. Нажмите **Выполнить** или **F5**
4. Результат выполнения отобразится в нижней панели

## Возможности

## Основные возможности

- **Подсветка синтаксиса BSL** — удобное цветовое выделение ключевых слов, операторов и комментариев, упрощающее чтение и написание кода.
- **Контекстная подсказка** — автодополнение методов, свойств и переменных при вводе. Работает для глобального контекста и типов 1С.
- **Выполнение выделенного кода** — возможность запустить не всю строку, а только выделенный фрагмент. Удобно при отладке небольших участков.
- **История выполнения** — автоматическое сохранение всех выполненных команд с возможностью повторного вызова.
- **Панель результатов** — вывод результата выполнения, сообщений об ошибках и диагностической информации в нижней части формы.
- **Сохранение и загрузка скриптов** — возможность сохранить код в файл и загрузить ранее сохранённый скрипт.

## Дополнительные возможности

- **Работа с внешними обработками** — код выполняется в контексте, аналогичном внешней обработке, что позволяет тестировать алгоритмы максимально приближенно к реальным условиям.
- **Горячие клавиши** — быстрый доступ к основным функциям: F5 — выполнить, Ctrl+S — сохранить, Ctrl+O — открыть.
- **Настройка шрифта и темы** — адаптация редактора под индивидуальные предпочтения.

## Интеграция

- Результат выполнения можно скопировать в буфер обмена или сохранить в текстовый файл.
- Код можно экспортировать в формат `.epf` для использования в качестве внешней обработки.
- Тесная интеграция с [Редактором JSON](/docs/tools/development-tools/json-editor) и [Консолью запросов](/docs/tools/development-tools/query-console) — результаты запросов и JSON можно обрабатывать напрямую в консоли кода.

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Консоль кода**.
2. Введите код в текстовое поле редактора.
3. Нажмите кнопку **Выполнить** или клавишу **F5**.
4. Просмотрите результат в нижней панели.

## Сценарии использования

### Сценарий 1: Отладка алгоритма

Напишите и выполните небольшую функцию для проверки логики:

```1c
Функция РассчитатьСкидку(Цена, КоличествоТоваров)
    Если КоличествоТоваров > 10 Тогда
        Скидка = 0.15;
    ИначеЕсли КоличествоТоваров > 5 Тогда
        Скидка = 0.1;
    Иначе
        Скидка = 0;
    КонецЕсли;
    Возврат Цена * (1 - Скидка);
КонецФункции

Сообщить(РассчитатьСкидку(1000, 12));
```

### Сценарий 2: Пакетная операция с данными

Выполните массовое обновление данных напрямую:

```1c
Выборка = Справочники.Номенклатура.Выбрать();
Пока Выборка.Следующий() Цикл
    Если Выборка.Артикул = "" Тогда
        Попытка
            Выборка.Артикул = "ART-" + Строка(Выборка.НомерСтроки);
            Выборка.Записать();
        Исключение
            Сообщить("Ошибка: " + ОписаниеОшибки());
        КонецПопытки;
    КонецЕсли;
КонецЦикла;
```

### Сценарий 3: Проверка работы внешней обработки

Имитируйте подключение внешней обработки и проверьте экспортные процедуры:

```1c
Обработка = ВнешниеОбработки.Создать("ПутьКФайлу.epf");
Если Обработка.ЭкспортныеПроцедуры.Содержит("ВыполнитьПроверку") Тогда
    Результат = Обработка.ВыполнитьПроверку(ТекущаяДата());
    Сообщить(Результат);
КонецЕсли;
```

## Часто задаваемые вопросы

## Общие вопросы

### Какие существуют горячие клавиши?
F5 — выполнить код, Ctrl+S — сохранить в файл, Ctrl+O — открыть файл, Ctrl+Z / Ctrl+Y — отмена / повтор действия.

### Можно ли выполнить только часть кода?
Да, выделите нужный фрагмент мышью и нажмите F5 — выполнится только выделенный участок.

### Сохраняется ли история выполненных команд?
Да, все команды автоматически сохраняются в истории. Вы можете повторно вызвать любую из них через панель истории.

## Технические вопросы

### Работает ли консоль на тонком клиенте?
Да, консоль кода полностью работает на тонком клиенте, толстом клиенте и в режиме веб-клиента.

### Почему не выполняется мой код?
Возможные причины: синтаксическая ошибка в коде, отсутствие прав на выполнение операций, использование несуществующих объектов метаданных. Проверьте панель ошибок — там отображается подробная диагностика.

### Как вставить результат выполнения в отчёт или документ?
Результат можно скопировать из панели результатов в буфер обмена (Ctrl+C) и вставить в любое приложение.

### Влияет ли выполнение кода на текущую сессию 1С?
Да, код выполняется в контексте текущего сеанса. Изменения данных (запись объектов) применяются непосредственно в базе данных, если не используется транзакция.

## Решение проблем

## Проблема: Не выполняется код, в панели результатов пусто
**Причина:** Возможно, в коде нет оператора, выводящего результат (Сообщить, Возврат), или код содержит синтаксическую ошибку.
**Решение:** Добавьте `Сообщить(Результат)` или `Возврат Результат` в конец кода. Проверьте панель ошибок на наличие сообщений.

## Проблема: Ошибка «Неизвестный тип» или «Неизвестный объект»
**Причина:** В коде используются объекты метаданных, которых нет в текущей конфигурации, или опечатка в имени.
**Решение:** Проверьте правильность написания имени объекта метаданных. Используйте контекстную подсказку для автодополнения.

## Проблема: Код выполняется слишком долго
**Причина:** Бесконечный цикл или очень большой объём обрабатываемых данных.
**Решение:** Добавьте проверки выхода из цикла. Используйте конструкцию `Пока ... Цикл` с явным счётчиком или условием. В крайнем случае прервите сеанс 1С и запустите заново.

## Проблема: Не сохраняется скрипт в файл
**Причина:** Отсутствие прав на запись в выбранную папку.
**Решение:** Запустите 1С от имени администратора или выберите другую папку для сохранения.

## Проблема: Контекстная подсказка не отображается
**Причина:** Отключено автодополнение в настройках.
**Решение:** Проверьте настройки редактора — опция «Показывать подсказки» должна быть включена.
