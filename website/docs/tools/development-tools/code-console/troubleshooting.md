# Устранение неполадок

## Проблема: Не выполняется код, в панели результатов пусто
**Причина:** Возможно, в коде нет оператора, выводящего результат (Сообщить, Возврат), или код содержит синтаксическую ошибку.
**Решение:** Добавьте `Сообщить(Результат)` или `Возврат Результат` в конец кода. Проверьте панель ошибок на наличие сообщений.

## Проблема: Ошибка «Неизвестный тип» или «Неизвестный объект»
**Причина:** В коде используются объекты метаданных, которых нет в текущей конфигурации, или опечатка в имени.
**Решение:** Проверьте правильность написания имени объекта метаданных. Используйте контекстную подсказку для автодополнения.

## Проблема: Код выполняется слишком долго
**Причина:** Бесконечный цикл или очень большой объём обрабатываемых данных.
**Решение:** Добавьте проверки выхода из цикла. Используйте конструкцию `Пока ... Цикл` с явным счётчиком или условием. В крайнем случае прервите сеанс 1С и запустите заново.

## Проблема: Не сохраняется скрипт в файл
**Причина:** Отсутствие прав на запись в выбранную папку.
**Решение:** Запустите 1С от имени администратора или выберите другую папку для сохранения.

## Проблема: Контекстная подсказка не отображается
**Причина:** Отключено автодополнение в настройках.
**Решение:** Проверьте настройки редактора — опция «Показывать подсказки» должна быть включена.
