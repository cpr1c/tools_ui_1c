# Часто задаваемые вопросы

## Общие вопросы

### Какие методы HTTP поддерживаются?
GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS. Любой метод можно указать вручную в поле ввода.

### Можно ли отправлять запросы с самоподписанным SSL-сертификатом?
Да. Если сертификат невалидный, появится предупреждение, но выполнение запроса не блокируется. При необходимости отключите проверку SSL в настройках.

### Сохраняется ли история запросов?
Да, все запросы автоматически сохраняются с указанием URL, метода и времени выполнения.

## Технические вопросы

### Как передать Basic-аутентификацию?
Добавьте заголовок `Authorization: Basic base64(login:password)` или воспользуйтесь встроенной формой ввода логина и пароля в интерфейсе.

### Почему приходит ответ с кодом 400?
Ошибка 400 Bad Request означает, что сервер не понял запрос. Проверьте правильность URL, формат тела запроса и обязательные заголовки.

### Как отправить запрос с файлом (multipart/form-data)?
Добавьте заголовок `Content-Type: multipart/form-data` и сформируйте тело запроса в соответствующем формате. Можно также использовать конструктор формы в интерфейсе.

### Работает ли консоль с прокси-серверами?
Да, HTTP-консоль использует системные настройки прокси, указанные в конфигурации 1С.
