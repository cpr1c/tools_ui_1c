# Консоль HTTP-запросов

Выполнение HTTP-запросов из 1С без создания внешних обработок. Удобный инструмент для тестирования веб-сервисов и API.

## Назначение

- Тестирование HTTP-запросов и веб-сервисов
- Быстрая отладка HTTP-взаимодействий
- Проверка ответов от внешних сервисов

## Особенности

- Поддержка всех методов HTTP (GET, POST, PUT, DELETE и др.)
- Настройка заголовков и тела запроса
- Просмотр кода ответа и заголовков

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль HTTP-запросов**
2. Укажите URL и метод запроса
3. Настройте заголовки и тело запроса (если нужно)
4. Нажмите **Выполнить** и посмотрите результат

## Примеры

```1c
// Пример GET-запроса
HTTPЗапрос = Новый HTTPЗапрос;
HTTPЗапрос.УстановитьТелоИзСтроки("");
HTTPЗапрос.Заголовки.Вставить("Content-Type", "application/json");
```
