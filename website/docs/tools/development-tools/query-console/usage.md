# Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Консоль запросов**.
2. Введите текст запроса в поле редактора.
3. Укажите значения параметров (если есть) в панели параметров.
4. Нажмите **Выполнить** или **F5**.
5. Результат отобразится в таблице в нижней части.

## Сценарии использования

### Сценарий 1: Простой запрос с параметром

```1c
ВЫБРАТЬ
    Ссылка,
    Наименование,
    Артикул
ИЗ
    Справочник.Номенклатура
ГДЕ
    Артикул ПОДОБНО &МаскаАртикула
```

### Сценарий 2: Запрос с временными таблицами

```1c
ВЫБРАТЬ
    Ссылка КАК Номенклатура
ПОМЕСТИТЬ ВТ_Товары
ИЗ
    Справочник.Номенклатура
ГДЕ
    ЭтоГруппа = Ложь
;

ВЫБРАТЬ
    ВТ_Товары.Номенклатура,
    Остатки.КоличествоОстаток
ИЗ
    ВТ_Товары КАК ВТ_Товары
        ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК Остатки
        ПО ВТ_Товары.Номенклатура = Остатки.Номенклатура
```

### Сценарий 3: Объединение результатов

```1c
ВЫБРАТЬ
    Ссылка,
    Наименование,
    "Контрагент" КАК ТипОбъекта
ИЗ
    Справочник.Контрагенты

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
    Ссылка,
    Наименование,
    "Номенклатура" КАК ТипОбъекта
ИЗ
    Справочник.Номенклатура
```
