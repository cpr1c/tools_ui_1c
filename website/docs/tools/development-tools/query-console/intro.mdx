# Консоль запросов

Разработка и выполнение запросов к базе данных. Форк [RequestConsole9000](https://github.com/hal9000cc/RequestConsole9000) с разрешения авторов.

## Назначение

Консоль запросов позволяет:
- Разрабатывать и отлаживать запросы к базе данных 1С
- Визуализировать результаты выполнения запросов
- Экспортировать результаты в различные форматы

## Особенности

- Подсветка синтаксиса запросов 1С
- Автодополнение таблиц и полей
- Визуализация результатов в виде таблицы
- Экспорт результатов в CSV, XML, табличный документ

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль запросов**
2. Введите запрос в поле ввода
3. Нажмите **Выполнить** или **F5**
4. Результат выполнения отобразится в нижней панели

## Примеры

```1c
Выбрать
  СправочникНоменклатура.Ссылок,
  СправочникНоменклатура.Наименование,
  СправочникНоменклатура.Артикул
Из
  Справочник.Номенклатура
Где
  Ссылка.Владелец = &Владелец
```
