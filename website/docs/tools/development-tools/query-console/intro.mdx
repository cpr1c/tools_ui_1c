# Консоль запросов

Разработка и выполнение запросов к базе данных. Форк [RequestConsole9000](https://github.com/hal9000cc/RequestConsole9000) с разрешения авторов.

## Назначение

Консоль запросов позволяет:
- Разрабатывать и отлаживать запросы к базе данных 1С
- Визуализировать результаты выполнения запросов
- Экспортировать результаты в различные форматы

## Особенности

- Подсветка синтаксиса запросов 1С
- Автодополнение таблиц и полей
- Визуализация результатов в виде таблицы
- Экспорт результатов в CSV, XML, табличный документ

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль запросов**
2. Введите запрос в поле ввода
3. Нажмите **Выполнить** или **F5**
4. Результат выполнения отобразится в нижней панели

## Примеры

```1c
Выбрать
  СправочникНоменклатура.Ссылок,
  СправочникНоменклатура.Наименование,
  СправочникНоменклатура.Артикул
Из
  Справочник.Номенклатура
Где
  Ссылка.Владелец = &Владелец
```

## Возможности

## Основные возможности

- **Подсветка синтаксиса запросов 1С** — удобное выделение ключевых слов языка запросов.
- **Автодополнение таблиц и полей** — при вводе отображается список доступных таблиц метаданных и их полей.
- **Визуализация результатов** — данные выводятся в виде таблицы с возможностью сортировки по столбцам.
- **Работа с параметрами** — удобное окно для указания значений параметров запроса.
- **Экспорт результатов** — выгрузка в CSV, XML, табличный документ MXL и XLS.

## Дополнительные возможности

- **Временные таблицы** — поддержка менеджера временных таблиц для сложных запросов.
- **Пакетные запросы** — выполнение нескольких запросов в одной сессии.
- **Сравнение результатов** — выполнение двух запросов и сравнение полученных таблиц.
- **Сохранение запросов** — возможность сохранить текст запроса в файл и загрузить ранее сохранённый.

## Интеграция

- Результаты запроса можно передать в [Консоль кода](/docs/tools/development-tools/code-console) для дальнейшей обработки.
- Взаимодействие с [Консолью отчётов](/docs/tools/development-tools/report-console) — запросы могут быть использованы как основа для отчётов СКД.
- Сгенерированный код запроса совместим с [Редактором СКД](/docs/tools/development-tools/skd-editor).

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Консоль запросов**.
2. Введите текст запроса в поле редактора.
3. Укажите значения параметров (если есть) в панели параметров.
4. Нажмите **Выполнить** или **F5**.
5. Результат отобразится в таблице в нижней части.

## Сценарии использования

### Сценарий 1: Простой запрос с параметром

```1c
ВЫБРАТЬ
    Ссылка,
    Наименование,
    Артикул
ИЗ
    Справочник.Номенклатура
ГДЕ
    Артикул ПОДОБНО &МаскаАртикула
```

### Сценарий 2: Запрос с временными таблицами

```1c
ВЫБРАТЬ
    Ссылка КАК Номенклатура
ПОМЕСТИТЬ ВТ_Товары
ИЗ
    Справочник.Номенклатура
ГДЕ
    ЭтоГруппа = Ложь
;

ВЫБРАТЬ
    ВТ_Товары.Номенклатура,
    Остатки.КоличествоОстаток
ИЗ
    ВТ_Товары КАК ВТ_Товары
        ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК Остатки
        ПО ВТ_Товары.Номенклатура = Остатки.Номенклатура
```

### Сценарий 3: Объединение результатов

```1c
ВЫБРАТЬ
    Ссылка,
    Наименование,
    "Контрагент" КАК ТипОбъекта
ИЗ
    Справочник.Контрагенты

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
    Ссылка,
    Наименование,
    "Номенклатура" КАК ТипОбъекта
ИЗ
    Справочник.Номенклатура
```

## Часто задаваемые вопросы

## Общие вопросы

### Какая версия языка запросов поддерживается?
Поддерживается полностью язык запросов 1С:Предприятие версии 8.3, включая все операторы (ВЫБРАТЬ, ПОМЕСТИТЬ, ОБЪЕДИНИТЬ, ИЗМЕНИТЬ, УНИЧТОЖИТЬ).

### Можно ли выполнять запросы к внешним источникам данных?
Да, если внешний источник данных подключён в конфигурации, его таблицы будут доступны в автодополнении.

### Как сохранить результат запроса в Excel?
Экспортируйте результат в табличный документ (кнопка «Экспорт»), затем откройте MXL-файл в 1С и сохраните как XLS.

## Технические вопросы

### Почему запрос выполняется с ошибкой «Неверный тип значения параметра»?
Проверьте, что тип значения параметра соответствует ожидаемому типу поля. Для ссылочных типов используйте конструкцию `Справочники.Имя.НайтиПоКоду("...")`.

### Как передать в запрос пустой список значений?
Используйте параметр с типом `СписокЗначений` или временную таблицу. В параметре запроса укажите значение `Новый СписокЗначений` и добавьте элементы.

### Работает ли автодополнение для полей временных таблиц?
Автодополнение для временных таблиц работает в ограниченном режиме. Рекомендуется сначала выполнить запрос создания временной таблицы, чтобы консоль получила её структуру.

### Можно ли отменить выполнение долгого запроса?
Да, нажмите кнопку «Отмена» на панели инструментов во время выполнения запроса.

## Решение проблем

## Проблема: Запрос не выполняется, ошибка «Неизвестная таблица»
**Причина:** Имя таблицы указано неверно или отсутствует в конфигурации.
**Решение:** Используйте автодополнение (Ctrl+Space) для выбора таблицы. Проверьте, что объект метаданных существует в текущей конфигурации.

## Проблема: Ошибка «Поле не найдено»
**Причина:** В запросе указано несуществующее поле или опечатка в имени.
**Решение:** Проверьте состав полей через автодополнение. Убедитесь, что поле доступно в контексте выбранной таблицы.

## Проблема: Результат не отсортирован
**Причина:** В запросе отсутствует конструкция УПОРЯДОЧИТЬ ПО.
**Решение:** Добавьте сортировку в явном виде: `УПОРЯДОЧИТЬ ПО Наименование ВОЗР`.

## Проблема: Ошибка при выполнении пакетного запроса
**Причина:** Нарушен порядок инструкций или неверный менеджер временных таблиц.
**Решение:** Каждая инструкция должна заканчиваться точкой с запятой. Убедитесь, что временные таблицы создаются до их использования.

## Проблема: Не отображается результат запроса
**Причина:** Запрос возвращает только помещение во временную таблицу без итоговой выборки.
**Решение:** Добавьте в конец пакета инструкцию `ВЫБРАТЬ ... ИЗ ВТ_...` для вывода данных.
