# Устранение неполадок

## Проблема: Запрос не выполняется, ошибка «Неизвестная таблица»
**Причина:** Имя таблицы указано неверно или отсутствует в конфигурации.
**Решение:** Используйте автодополнение (Ctrl+Space) для выбора таблицы. Проверьте, что объект метаданных существует в текущей конфигурации.

## Проблема: Ошибка «Поле не найдено»
**Причина:** В запросе указано несуществующее поле или опечатка в имени.
**Решение:** Проверьте состав полей через автодополнение. Убедитесь, что поле доступно в контексте выбранной таблицы.

## Проблема: Результат не отсортирован
**Причина:** В запросе отсутствует конструкция УПОРЯДОЧИТЬ ПО.
**Решение:** Добавьте сортировку в явном виде: `УПОРЯДОЧИТЬ ПО Наименование ВОЗР`.

## Проблема: Ошибка при выполнении пакетного запроса
**Причина:** Нарушен порядок инструкций или неверный менеджер временных таблиц.
**Решение:** Каждая инструкция должна заканчиваться точкой с запятой. Убедитесь, что временные таблицы создаются до их использования.

## Проблема: Не отображается результат запроса
**Причина:** Запрос возвращает только помещение во временную таблицу без итоговой выборки.
**Решение:** Добавьте в конец пакета инструкцию `ВЫБРАТЬ ... ИЗ ВТ_...` для вывода данных.
