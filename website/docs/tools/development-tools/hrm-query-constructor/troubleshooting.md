# Устранение неполадок

## Проблема: Сгенерированный код не работает в целевой конфигурации
**Причина:** В целевой конфигурации отсутствуют объекты метаданных, на которые ссылается код, или они имеют другие имена.
**Решение:** Проверьте точное имя таблицы и полей. Убедитесь, что конфигурация-приёмник содержит те же объекты метаданных.

## Проблема: Автодополнение не предлагает поля
**Причина:** Не выбрана основная таблица представления.
**Решение:** Укажите основную таблицу в свойствах представления. Список полей обновится автоматически.

## Проблема: Представление отображается, но данные пустые
**Причина:** Отборы исключают все записи или неверно указан тип представления.
**Решение:** Проверьте отборы. Временно отключите их. Убедитесь, что выбранный тип представления соответствует задаче (динамический список, отчёт и т.д.).

## Проблема: Ошибка при вставке кода в управляемую форму
**Причина:** Код вставлен не в тот контекст или содержит конфликтующие объявления.
**Решение:** Вставляйте код внутрь существующей процедуры или функции. Избегайте повторного объявления уже существующих переменных.

## Проблема: Не отображаются отборы для подчинённых таблиц
**Причина:** Отборы доступны только для основной таблицы.
**Решение:** Для фильтрации по полям подчинённых таблиц используйте параметры в тексте запроса представления.
