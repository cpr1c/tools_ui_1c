# Конструктор представлений «Зарплата и кадры»

Формирование представлений подсистемы ЗиК. Форк [SharedQueryDesignerHRM](https://github.com/iljyxa/SharedQueryDesignerHRM) с разрешения авторов.

## Назначение

- Создание представлений подсистемы Зарплата и кадры
- Тестирование запросов ЗиК
- Генерация кода для подключения

## Особенности

- Специализированный инструмент для ЗиК
- Поддержка всех типов представлений
- Генерация кода для конфигурации

## Использование

1. Перейдите в меню **Универсальные инструменты → Конструктор представлений ЗиК**
2. Выберите тип представления
3. Настройте параметры
4. Сгенерируйте код и вставьте в конфигурацию

## Возможности

## Основные возможности

- **Создание представлений подсистемы «Зарплата и кадры»** — визуальный конструктор представлений для подсистемы ЗиК.
- **Поддержка всех типов представлений** — работа с динамическими списками, отчётами и произвольными представлениями данных.
- **Генерация кода для конфигурации** — автоматическое создание готового BSL-кода для подключения представления к управляемым формам.
- **Настройка параметров представления** — отборы, сортировки, поля и группировки, доступные для выбранного типа.

## Дополнительные возможности

- **Предварительный просмотр** — проверка результата до генерации кода.
- **Библиотека шаблонов** — сохранение часто используемых настроек представлений.
- **Совместимость с типовыми конфигурациями** — инструмент адаптирован под структуру метаданных типовых конфигураций ЗиК.

## Интеграция

- Сгенерированный код можно протестировать в [Консоли кода](/docs/tools/development-tools/code-console).
- Запросы для представлений можно разработать в [Консоли запросов](/docs/tools/development-tools/query-console).
- Результат можно использовать совместно с [Редактором СКД](/docs/tools/development-tools/skd-editor) для создания отчётов.
- Инструмент основан на форке [SharedQueryDesignerHRM](https://github.com/iljyxa/SharedQueryDesignerHRM).

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Конструктор представлений ЗиК**.
2. Выберите тип представления (динамический список, отчёт, представление данных).
3. Настройте параметры: отборы, поля, сортировки.
4. Нажмите «Сгенерировать код».
5. Скопируйте сгенерированный код в конфигурацию.

## Сценарии использования

### Сценарий 1: Создание динамического списка сотрудников

1. Выберите тип представления — «Динамический список».
2. Укажите основную таблицу — `Справочник.Сотрудники`.
3. Настройте отбор: `Уволен = Ложь`.
4. Укажите поля для вывода: `ФИО, ТабельныйНомер, Подразделение, Должность`.
5. Сгенерируйте код.

Пример сгенерированного фрагмента:

```1c
Процедура СоздатьПредставление()
    ДинамическийСписок = Новый ДинамическийСписок;
    ДинамическийСписок.ОсновнаяТаблица = "Справочник.Сотрудники";
    ДинамическийСписок.ТекстЗапроса =
    "ВЫБРАТЬ
    |   Ссылка, Наименование, ТабельныйНомер,
    |   Подразделение, Должность
    |ИЗ
    |   Справочник.Сотрудники
    |ГДЕ
    |   Уволен = Ложь";
КонецПроцедуры
```

### Сценарий 2: Настройка представления для анализа кадровых изменений

1. Выберите тип представления — «Запрос к накоплениям».
2. Укажите регистр — `РегистрНакопления.ШтатнаяРасстановка`.
3. Настройте отбор по периоду и подразделению.
4. Сгенерируйте код для вставки в отчёт.

## Часто задаваемые вопросы

## Общие вопросы

### Для каких конфигураций предназначен инструмент?
Инструмент предназначен для типовых конфигураций подсистемы «Зарплата и кадры»: «Зарплата и управление персоналом», «Зарплата и кадры государственных учреждений», а также для отраслевых решений на их основе.

### Можно ли создавать представления для произвольных таблиц?
Да, можно указать любую таблицу, доступную в метаданных конфигурации. Однако автодополнение полей оптимизировано под объекты ЗиК.

### Чем отличается от Консоли запросов?
Конструктор представлений ЗиК генерирует специализированный код с настройками представлений (динамические списки, управляемые формы). Консоль запросов — универсальный инструмент для выполнения произвольных запросов.

## Технические вопросы

### В какой модуль вставлять сгенерированный код?
В модуль формы или модуль менеджера объекта, где требуется настроить представление. Обычно это процедура `ПриСозданииНаСервере` или внешняя обработка.

### Поддерживаются ли общие реквизиты?
Да, инструмент поддерживает общие реквизиты конфигурации. Они отображаются в списке доступных полей.

### Можно ли использовать конструктор в нетиповых конфигурациях?
Да, но автодополнение может работать некорректно из-за отличий в структуре метаданных. Проверяйте сгенерированный код перед вставкой.

### Генерируется ли код обработчиков событий?
Нет, формируется только код настройки представления. Обработчики событий (при выборе, при активизации строки) добавляются вручную.

## Решение проблем

## Проблема: Сгенерированный код не работает в целевой конфигурации
**Причина:** В целевой конфигурации отсутствуют объекты метаданных, на которые ссылается код, или они имеют другие имена.
**Решение:** Проверьте точное имя таблицы и полей. Убедитесь, что конфигурация-приёмник содержит те же объекты метаданных.

## Проблема: Автодополнение не предлагает поля
**Причина:** Не выбрана основная таблица представления.
**Решение:** Укажите основную таблицу в свойствах представления. Список полей обновится автоматически.

## Проблема: Представление отображается, но данные пустые
**Причина:** Отборы исключают все записи или неверно указан тип представления.
**Решение:** Проверьте отборы. Временно отключите их. Убедитесь, что выбранный тип представления соответствует задаче (динамический список, отчёт и т.д.).

## Проблема: Ошибка при вставке кода в управляемую форму
**Причина:** Код вставлен не в тот контекст или содержит конфликтующие объявления.
**Решение:** Вставляйте код внутрь существующей процедуры или функции. Избегайте повторного объявления уже существующих переменных.

## Проблема: Не отображаются отборы для подчинённых таблиц
**Причина:** Отборы доступны только для основной таблицы.
**Решение:** Для фильтрации по полям подчинённых таблиц используйте параметры в тексте запроса представления.
