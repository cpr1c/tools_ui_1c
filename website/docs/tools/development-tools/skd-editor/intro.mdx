# Редактор СКД

Конструктор схемы компоновки данных для тонкого клиента (без макетов и вложенных схем).

## Назначение

- Создание и редактирование схем компоновки данных
- Быстрое прототипирование отчетов
- Тестирование СКД без открытия конфигуратора

## Особенности

- Визуальный конструктор СКД
- Поддержка всех элементов СКД
- Экспорт в табличный документ

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор СКД**
2. Создайте новую схему или откройте существующую
3. Настройте данные, фильтры и компоновку
4. Выполните и посмотрите результат

## Связанные разделы

- [Консоль отчётов](/docs/tools/development-tools/report-console) — выполнение готовых компоновок

## Возможности

## Основные возможности

- **Визуальный конструктор СКД** — создание схем компоновки данных через интуитивный интерфейс без написания XML-разметки.
- **Поддержка всех элементов СКД** — наборы данных, поля, группировки, отборы, сортировки, условное оформление, параметры, макеты.
- **Редактирование вычисляемых полей** — конструктор выражений для создания полей с расчётами на языке компоновки данных.
- **Предпросмотр отчёта** — выполнение схемы СКД и просмотр результата без выхода из редактора.
- **Экспорт в XML** — сохранение схемы в формате XML для встраивания в конфигурацию.

## Дополнительные возможности

- **Редактирование ресурсов** — настройка агрегатных функций для полей ресурсов (Сумма, Количество, Максимум и др.).
- **Настройка отборов** — гибкая система фильтрации записей набора данных.
- **Параметры вывода** — настройка оформления, расположения полей и группировок.
- **Быстрое копирование элементов** — дублирование полей, группировок и отборов.

## Интеграция

- Готовые схемы СКД можно выполнять через [Консоль отчётов](/docs/tools/development-tools/report-console).
- Запросы для наборов данных можно подготовить в [Консоли запросов](/docs/tools/development-tools/query-console).
- Сгенерированный XML схемы можно обработать в [Консоли кода](/docs/tools/development-tools/code-console).

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Редактор СКД**.
2. Нажмите «Создать новую схему».
3. Добавьте набор данных — введите или вставьте текст запроса.
4. Настройте поля, группировки и отборы.
5. Нажмите «Выполнить» для предпросмотра отчёта.
6. Сохраните схему в XML-файл.

## Сценарии использования

### Сценарий 1: Создание простого отчёта по продажам

1. Добавьте набор данных — запрос:

```1c
ВЫБРАТЬ
    Продажи.Период,
    Продажи.Номенклатура.Наименование КАК Товар,
    Продажи.Количество,
    Продажи.СуммаОборот КАК Сумма
ИЗ
    РегистрНакопления.Продажи.Обороты КАК Продажи
ГДЕ
    Продажи.Период МЕЖДУ &НачалоПериода И &КонецПериода
```

2. Добавьте поле ресурса «Сумма» с агрегацией «Сумма».
3. Настройте группировку по полю «Товар».
4. Выполните и сохраните схему.

### Сценарий 2: Создание отчёта с диаграммой

1. Создайте схему с типом вывода «Диаграмма».
2. Укажите поле для серий (например, «Номенклатура»).
3. Укажите поле для точек (например, «Период»).
4. Выберите значение — ресурс «Сумма».
5. Выберите тип диаграммы (гистограмма, график, круговая).

### Сценарий 3: Добавление условного оформления

1. В настройках схемы выберите «Условное оформление».
2. Добавьте элемент оформления.
3. Укажите условие: `Сумма > 100000`.
4. Настройте оформление: цвет фона, жирный шрифт.
5. Выполните отчёт — строки, удовлетворяющие условию, будут выделены.

## Часто задаваемые вопросы

## Общие вопросы

### Какие типы наборов данных поддерживаются?
Поддерживаются все основные типы: запрос, объект, объединение. Наборы на основе внешних источников данных также доступны.

### Можно ли использовать вложенные схемы?
Редактор СКД предназначен для работы с простыми схемами (без макетов и вложенных схем). Для сложных схем используйте конфигуратор.

### Как преобразовать существующую схему из конфигурации?
Откройте XML-файл схемы через кнопку «Открыть файл». Редактор загрузит её в визуальный режим для редактирования.

## Технические вопросы

### Почему не выполняются вычисляемые поля?
Проверьте синтаксис выражения. Используйте только функции, доступные в языке компоновки данных (Вычислить, Сумма, Максимум и т.д.). Обратитесь к синтаксической подсказке в редакторе.

### Как добавить параметр отчёта?
В разделе «Параметры» нажмите «Добавить». Укажите имя, тип и значение по умолчанию. Далее используйте параметр в запросе как `&ИмяПараметра`.

### В чём отличие полей «Ресурсы» от обычных полей?
Ресурсы — это поля, для которых задаётся агрегатная функция (Сумма, Количество, Максимум, Минимум, Среднее). Они отображаются в итогах по группам. Обычные поля выводятся без агрегации.

### Поддерживается ли экспорт схемы в конфигурацию?
Редактор сохраняет схему в формате XML. Вы можете вставить этот XML в макет СКД в конфигураторе 1С.

## Решение проблем

## Проблема: Схема не выполняется, ошибка «Неверная структура XML»
**Причина:** XML-файл схемы повреждён или создан неподдерживаемой версией.
**Решение:** Попробуйте загрузить схему в конфигураторе и сохранить заново. Убедитесь, что версия платформы схемы соответствует текущей версии 1С.

## Проблема: Отчёт формируется без данных
**Причина:** В запросе набора данных нет записей, удовлетворяющих условиям отборов.
**Решение:** Проверьте запрос в [Консоли запросов](/docs/tools/development-tools/query-console). Временно отключите все отборы и проверьте, появляются ли данные.

## Проблема: Не отображаются итоги по группам
**Причина:** Поле не добавлено в ресурсы или не указана агрегатная функция.
**Решение:** Перейдите в раздел «Ресурсы», добавьте необходимые поля и укажите для них функцию агрегации (Сумма, Количество и т.д.).

## Проблема: Ошибка при указании выражения вычисляемого поля
**Причина:** В выражении используются недопустимые функции или неверный синтаксис.
**Решение:** Используйте справочник функций СКД. Для обращения к полям используйте имена в квадратных скобках, например: `[Сумма] * 0.87`.

## Проблема: При сохранении XML теряется часть настроек
**Причина:** Используются элементы, не поддерживаемые в редакторе (например, вложенные схемы).
**Решение:** Редактор сохраняет все стандартные элементы СКД. Если используются расширения, доработайте XML вручную после сохранения.
