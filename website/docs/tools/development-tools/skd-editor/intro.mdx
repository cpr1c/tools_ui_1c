# Редактор СКД

Конструктор схемы компоновки данных для тонкого клиента (без макетов и вложенных схем).

## Назначение

- Создание и редактирование схем компоновки данных
- Быстрое прототипирование отчетов
- Тестирование СКД без открытия конфигуратора

## Особенности

- Визуальный конструктор СКД
- Поддержка всех элементов СКД
- Экспорт в табличный документ

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор СКД**
2. Создайте новую схему или откройте существующую
3. Настройте данные, фильтры и компоновку
4. Выполните и посмотрите результат
