# Возможности

## Основные возможности

- **Автоматическое чтение WSDL** — загрузка описания веб-сервиса по URL, парсинг всех доступных операций и типов данных.
- **Поддержка SOAP 1.1 и 1.2** — работа с обеими версиями протокола SOAP, автоматический выбор версии на основе WSDL.
- **Формирование SOAP-запросов** — автоматическая генерация XML-тела запроса на основе WSDL-описания.
- **Просмотр SOAP-ответов** — форматированный вывод XML-ответа с возможностью навигации по структуре.
- **Сохранение запросов и ответов** — возможность сохранить примеры запросов и полученные ответы для документации.

## Дополнительные возможности

- **Поддержка сложных типов** — работа со вложенными элементами, массивами и перечислениями.
- **Работа с заголовками SOAP** — добавление кастомных SOAP-заголовков (Security, Routing и др.).
- **Аутентификация** — поддержка Basic Auth, WS-Security, сертификатов.
- **Импорт/экспорт** — сохранение проектов в XML для последующего использования.

## Интеграция

- Для отладки HTTP-части SOAP-запросов можно использовать [Консоль HTTP-запросов](/docs/tools/development-tools/http-console).
- Ответы веб-сервисов можно обрабатывать в [Консоли кода](/docs/tools/development-tools/code-console).
- Инструмент является аналогом soapUI для 1С.
