# Консоль веб-сервисов

Чтение и выполнение веб-сервисов, аналог soapUI. Форк [WSReader2](https://github.com/ghostaz/WSReader2) с разрешения авторов.

## Назначение

- Просмотр и тестирование веб-сервисов 1С
- Выполнение запросов к веб-сервисам
- Анализ SOAP-сообщений

## Особенности

- Автоматическое чтение WSDL
- Поддержка SOAP 1.1 и 1.2
- Возможность сохранения запросов и ответов

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль веб-сервисов**
2. Укажите URL веб-сервиса (WSDL)
3. Выберите необходимый метод
4. Заполните параметры и выполните запрос
