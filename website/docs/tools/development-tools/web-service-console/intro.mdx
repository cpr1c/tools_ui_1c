# Консоль веб-сервисов

Чтение и выполнение веб-сервисов (SOAP) на платформе 1С:Предприятие 8.3. Аналог soapUI. Позволяет загружать WSDL-описание веб-сервиса, просматривать его структуру, заполнять параметры операций и выполнять вызовы с отображением результата в виде XML и дерева значений.

:::info
Форк [WSReader2](https://github.com/ghostaz/WSReader2) (автор: Баданов Владимир, версия 2.0.2.2). [Лицензия GPL3](https://github.com/ghostaz/WSReader2/blob/master/LICENSE)
:::

---

## Назначение

- **Тестирование SOAP-веб-сервисов 1С** — выполнение операций веб-сервисов без написания кода и внешних обработок
- **Просмотр структуры WSDL** — навигация по сервисам, точкам подключения, операциям и параметрам
- **Отладка интеграций** — проверка SOAP-взаимодействий с внешними системами и веб-сервисами 1С
- **Анализ XDTO-данных** — просмотр результата в виде дерева значений с типами и вложенными элементами

---

## Основные возможности

- **Загрузка WSDL по URL** — чтение WSDL-документа, парсинг всех сервисов, точек подключения, операций и их параметров
- **Поддержка HTTPS** — защищённое соединение через OpenSSL (`ЗащищенноеСоединениеOpenSSL`)
- **Аутентификация** — передача имени пользователя и пароля при подключении к веб-сервису
- **Навигация по иерархии** — последовательный выбор: веб-сервис → точка подключения → операция → параметры
- **Редактирование параметров операций** — поддержка примитивных типов (Строка, Число, Булево, Дата) и сложного типа `Структура`
- **Редактор структуры** — отдельная форма для заполнения параметров типа `Структура` (набор пар «Ключ — Значение»)
- **Отображение результата** — результат выводится в двух видах:
  - **XML** — полный SOAP-ответ в виде строки
  - **Дерево значений** — структурированное представление с колонками «Свойство», «Значение», «Тип»
- **Поддержка XDTO** — корректная обработка `ОбъектXDTO`, `СписокXDTO`, `ЗначениеXDTO` с рекурсивным обходом вложенных свойств
- **Сохранение/загрузка WSDL-определений** — список подключений сохраняется в XML-файл через сериализацию XDTO
- **История подключений** — таблица `СписокWSОпределений` хранит ранее использованные URL, логины и пароли

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Консоль веб сервисов(WS) [УИ]**
2. Введите URL WSDL-документа веб-сервиса (например, `http://server/base/ws/MyWebService?wsdl`)
3. При необходимости укажите **Имя пользователя** и **Пароль** для аутентификации
4. Нажмите **Получить WSDL** — инструмент загрузит и разберёт WSDL
5. В списке **Сервисы** выберите нужный веб-сервис
6. В списке **Точки подключения** выберите точку подключения (binding)
7. В списке **Операции** выберите операцию для вызова
8. Заполните параметры операции в таблице **Параметры операции**
9. Нажмите **Выполнить операцию** — результат отобразится в панели результата (XML + дерево)

## Интерфейс

### Панель подключения

Верхняя часть формы содержит поля для подключения к веб-сервису:

| Поле                    | Назначение                              |
| ----------------------- | --------------------------------------- |
| **Местоположение WSDL** | URL WSDL-документа веб-сервиса          |
| **Имя пользователя**    | Логин для аутентификации (опционально)  |
| **Пароль**              | Пароль для аутентификации (опционально) |

Кнопка **Получить WSDL** (значок «Обновить») загружает и парсит WSDL-документ.

### Дерево навигации

Левая часть формы содержит четыре связанных списка с последовательным отбором:

| Список                 | Содержимое                                         |
| ---------------------- | -------------------------------------------------- |
| **Сервисы**            | Список веб-сервисов, объявленных в WSDL            |
| **Точки подключения**  | Точки подключения (binding) для выбранного сервиса |
| **Операции**           | Доступные операции для выбранной точки подключения |
| **Параметры операции** | Параметры выбранной операции с типами              |

При выборе элемента в вышестоящем списке нижестоящие автоматически фильтруются.

### Панель параметров операции

Таблица **Параметры операции** содержит колонки:

- **Имя параметра** — название параметра из WSDL-описания
- **Тип параметра** — XDTO-тип параметра (например, `{http://v8.1c.ru/8.1/data/core}Structure`)
- **Значение** — значение параметра (заполняется вручную)
- **Неопределено** — флаг, при установке которого передаётся `null` (полезно для необязательных параметров)
- **Структура** — для параметров типа `Структура` открывается отдельная форма редактирования

### Панель результата

Результат выполнения операции отображается в двух представлениях:

1. **XML** — текстовое поле с полным SOAP-ответом (сериализован через `ФабрикаXDTO.ЗаписатьXML`)
2. **Дерево результата** — иерархическое дерево значений с колонками:
   - **Свойство** — имя элемента/свойства
   - **Значение** — значение элемента
   - **Тип** — тип данных (XDTO-тип или тип 1С)

### Сохранение и загрузка

- **Сохранить** (значок «Сохранить») — сохраняет список WSDL-определений в XML-файл
- **Прочитать** (значок «Открыть») — загружает ранее сохранённый список WSDL-определений из XML-файла

Сохранённый файл содержит все URL, имена пользователей и пароли для быстрого восстановления подключений.

## Сценарии использования

### Сценарий 1: Тестирование веб-сервиса 1С

1. Откройте публикацию веб-сервиса 1С, например: `http://server/demo/ws/Exchange?wsdl`
2. Нажмите **Получить WSDL** — списки сервисов, точек подключения и операций заполнятся автоматически
3. Выберите сервис, точку подключения и операцию, например `GetData`
4. Заполните параметры: `Id = "123"`, `Date = "2026-06-18"`
5. Нажмите **Выполнить операцию**
6. Проанализируйте результат в XML и дереве значений

```xml
<?xml version="1.0" encoding="UTF-8"?>
<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/">
  <soap:Body>
    <GetDataResponse>
      <Result>
        <Name>Товар 1</Name>
        <Price>1500.00</Price>
      </Result>
    </GetDataResponse>
  </soap:Body>
</soap:Envelope>
```
