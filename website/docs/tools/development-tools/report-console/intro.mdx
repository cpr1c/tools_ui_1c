# Консоль отчётов

Переработанная консоль компоновок с диска ИТС. Позволяет создавать и выполнять компоновки отчетов без открытия конфигуратора.

## Назначение

- Быстрое создание и выполнение компоновок отчетов
- Тестирование отчетов без открытия конфигуратора
- Экспорт результатов в различные форматы

## Особенности

- Интуитивный интерфейс компоновки
- Поддержка всех типов отчетов платформы
- Сохранение настроек компоновки

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль отчётов**
2. Создайте или выберите существующую компоновку
3. Настройте параметры и фильтры
4. Выполните компоновку и посмотрите результат

## Возможности

## Основные возможности

- **Создание отчётов без конфигуратора** — полноценный конструктор схемы компоновки данных прямо в тонком клиенте.
- **Поддержка всех типов отчётов** — работа с табличными отчётами, диаграммами, списками и кросс-таблицами.
- **Гибкая настройка параметров** — удобный интерфейс для указания значений параметров компоновки, отборов и фильтров.
- **Экспорт результатов** — выгрузка отчёта в форматы MXL, XLS, PDF, HTML, CSV и XML.
- **Сохранение настроек** — компоновка и параметры сохраняются между сеансами работы.

## Дополнительные возможности

- **Детальные настройки** — расширенные возможности по настройке группировок, сортировок, условного оформления.
- **Просмотр расшифровки (drill-down)** — детализация значений отчёта одним кликом.
- **Работа с СКД** — полная поддержка возможностей системы компоновки данных 1С.

## Интеграция

- Схемы компоновки можно создавать в [Редакторе СКД](/docs/tools/development-tools/skd-editor) и выполнять через Консоль отчётов.
- Результаты [Консоли запросов](/docs/tools/development-tools/query-console) могут быть источником данных для отчёта.
- Сгенерированный код можно использовать в [Консоли кода](/docs/tools/development-tools/code-console) для программной работы с отчётами.

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Консоль отчётов**.
2. Создайте новую компоновку или откройте существующую.
3. Настройте набор данных, параметры и фильтры.
4. Нажмите **Сформировать** для выполнения отчёта.
5. Результат отобразится в панели предпросмотра.

## Сценарии использования

### Сценарий 1: Создание простого отчёта по остаткам товаров

1. Выберите тип схемы — «Таблица».
2. Добавьте набор данных — запрос из регистра остатков.
3. Настройте группировки по номенклатуре.
4. Укажите поля для вывода: Номенклатура, Количество, Сумма.
5. Сформируйте отчёт и экспортируйте в XLS.

### Сценарий 2: Отчёт с диаграммой

1. Выберите тип схемы — «Диаграмма».
2. Укажите источник данных (например, обороты по продажам).
3. Настройте оси: период — по горизонтали, сумма — по вертикали.
4. Выберите тип диаграммы (гистограмма, круговая, график).
5. Сформируйте и сохраните результат.

### Сценарий 3: Отчёт с условным оформлением


## Часто задаваемые вопросы

## Общие вопросы

### В чём отличие Консоли отчётов от Редактора СКД?
Консоль отчётов предназначена для выполнения готовых компоновок и быстрого тестирования. Редактор СКД — для углублённого создания и редактирования схем компоновки данных. Инструменты взаимно дополняют друг друга.

### Можно ли использовать внешние отчёты?
Да, вы можете открыть внешнюю обработку с готовой схемой компоновки и выполнить её через консоль отчётов.

### Какие форматы экспорта доступны?
MXL, XLS, PDF, HTML, CSV, XML, а также вывод на печать непосредственно из консоли.

## Технические вопросы

### Почему отчёт формируется медленно?
Убедитесь, что в запросе нет избыточных данных. Используйте фильтры и ограничения по периоду. Проверьте, что установлены индексы на поля, участвующие в отборах.

### Как применить отбор по нескольким значениям?
В настройках компоновки выберите вид сравнения «В списке» и укажите список значений через запятую.

### Можно ли настроить оформление для разных уровней группировки?
Да, условное оформление можно применить на любом уровне: детальные записи, итоги по группам и общие итоги настраиваются отдельно.

### Сохраняются ли настройки между сеансами?
Да, все настройки компоновки и параметры отчёта сохраняются автоматически при завершении работы.

## Решение проблем

## Проблема: Отчёт не формируется, ошибка «Неверный тип значения параметра»
**Причина:** Параметр отчёта имеет несовместимый тип.
**Решение:** Проверьте типы параметров в схеме компоновки. Убедитесь, что значение параметра соответствует ожидаемому типу (дата, число, ссылка и т.д.).

## Проблема: Пустой отчёт при наличии данных
**Причина:** В настройках компоновки указаны фильтры, исключающие все записи.
**Решение:** Проверьте отборы и условия. Временно отключите все фильтры и формируйте отчёт заново, постепенно их добавляя.

## Проблема: Ошибка «Недостаточно прав» при формировании отчёта
**Причина:** У текущего пользователя нет прав на чтение объектов метаданных, участвующих в запросе отчёта.
**Решение:** Проверьте права доступа для роли пользователя на соответствующие объекты (регистры, справочники, документы).

## Проблема: Не экспортируется в PDF
**Причина:** В системе не установлен компонент вывода в PDF.
**Решение:** Установите компонент печати PDF от 1С (если используется тонкий клиент) или используйте экспорт в XLS.

## Проблема: Пропадают данные при экспорте в CSV
**Причина:** Разделители в данных конфликтуют с разделителями CSV.
**Решение:** Используйте XML или MXL для данных с большим количеством спецсимволов.
