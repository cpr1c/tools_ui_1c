# Консоль отчётов

Переработанная консоль компоновок с диска ИТС. Позволяет создавать и выполнять компоновки отчетов без открытия конфигуратора.

## Назначение

- Быстрое создание и выполнение компоновок отчетов
- Тестирование отчетов без открытия конфигуратора
- Экспорт результатов в различные форматы

## Особенности

- Интуитивный интерфейс компоновки
- Поддержка всех типов отчетов платформы
- Сохранение настроек компоновки

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль отчётов**
2. Создайте или выберите существующую компоновку
3. Настройте параметры и фильтры
4. Выполните компоновку и посмотрите результат
