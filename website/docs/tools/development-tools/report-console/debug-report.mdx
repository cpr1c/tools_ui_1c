# Отладка СКД через `УИ_._От`

**Сценарий.** Разрабатывается внешний отчёт на СКД с внешними наборами данных и пакетными запросами. Отчёт возвращает неожиданный результат — нужно увидеть, какие данные попадают в наборы, как отрабатывают временные таблицы и что получается на выходе.

## Шаг 1. Создать схему и подготовить данные в коде

```bsl
Схема = Новый СхемаКомпоновкиДанных;
// ... наполнение схемы: наборы данных, поля, группировки ...

ВнешниеНаборы = Новый Структура;
ВнешниеНаборы.Вставить("Товары", ТаблицаТоваров);

МВТ = Новый МенеджерВременныхТаблиц;
Запрос = Новый Запрос;
Запрос.МенеджерВременныхТаблиц = МВТ;
Запрос.Текст =
"ВЫБРАТЬ
 |    Товары.Ссылка,
 |    Товары.Наименование
 |ПОМЕСТИТЬ ВТ_Товары
 |ИЗ
 |    Справочник.Номенклатура КАК Товары
 |ГДЕ
 |    Товары.ЭтоГруппа = Ложь";
Запрос.Выполнить();
```

## Шаг 2. Добавить отладку

```bsl
УИ_._От(Схема,
    НастройкиСКД, ВнешниеНаборы,
    "Имя отчета для данных отладки", МВТ);
```

## Шаг 3. Открыть данные отладки

После выполнения кода откройте форму **Данные для отладки** через **Универсальные инструменты → Данные для отладки**. Найдите запись с переданной схемой СКД.

## Шаг 4. Открыть консоль отчетов 

В форме данных отладки нажмите **Отладить**. Откроется **Консоль отчетов [УИ]** с загруженной схемой, внешними наборами и временными таблицами.
