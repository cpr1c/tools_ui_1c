# Отладка СКД динамического списка через УИ*.*От

**Сценарий.** На форме настроен динамический список с отборами, условным оформлением и параметрами. Список показывает не те данные, которые ожидались — нужно увидеть, какая схема СКД формируется, какие настройки применяются и что получается на выходе.

## Шаг 1. Создать форму с динамическим списком в коде

```bsl
// В модуле формы или обработки
Список = Элементы.Список; // ТаблицаФормы, связанная с динамическим списком

Список.Отбор.ЭтоГруппа.Установить(Ложь);
Список.УстановитьПараметр("ДатаНачала", НачалоМесяца(ТекущаяДата()));
```

## Шаг 2. Добавить отладку

Вызов `УИ_._От` должен выполняться **на сервере** — в серверном методе формы или обработки.

```bsl
&НаСервере
Процедура ВыполнитьОтладку()

    УИ_._От(Элементы.Список, "Список товаров на складе");

КонецПроцедуры
```

## Шаг 3. Открыть данные отладки

После выполнения кода откройте форму **Данные для отладки** через **Универсальные инструменты → Данные для отладки**. Найдите запись с комментарием «Список товаров на складе».

## Шаг 4. Открыть консоль отчетов и выполнить отладку

В форме данных отладки нажмите **Открыть в консоли отчетов**. Откроется **Консоль отчетов [УИ]** с извлечённой из динамического списка схемой СКД и настройками.
