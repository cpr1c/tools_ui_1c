# Устранение неполадок

## Проблема: Совпадения не отображаются в тестовой строке
**Причина:** Регулярное выражение не соответствует ни одному фрагменту текста или содержит синтаксическую ошибку.
**Решение:** Проверьте выражение на простой строке. Убедитесь, что не пропущены специальные символы. Используйте визуальный конструктор для пошаговой сборки выражения.

## Проблема: Выражение работает не так, как ожидается
**Причина:** Неверно используются квантификаторы или группы.
**Решение:** Жадные квантификаторы (`*`, `+`) захватывают максимум текста. Используйте ленивые (`*?`, `+?`) для минимального захвата. Проверьте каждый элемент выражения отдельно.

## Проблема: Ошибка «ActiveX component can't create object»
**Причина:** На системе отсутствует или отключён компонент VBScript.
**Решение:** Убедитесь, что компонент VBScript установлен в Windows. Включите его через «Включение/отключение компонентов Windows» → «Службы VBScript».

## Проблема: Сгенерированный код не работает в 1С
**Причина:** В коде используется COM-объект, который может быть недоступен в контексте сервера 1С.
**Решение:** Используйте COMSafeArray и убедитесь, что вызов выполняется в клиентском контексте или на сервере с включёнными COM-объектами.

## Проблема: Регулярка работает медленно на больших текстах
**Причина:** Сложное выражение с катастрофическим возвратом (catastrophic backtracking).
**Решение:** Упростите выражение. Избегайте вложенных квантификаторов типа `(a+)+`. Используйте атомарные группы (если поддерживаются).
