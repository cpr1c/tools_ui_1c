# Часто задаваемые вопросы

## Общие вопросы

### Зачем нужен конструктор, если можно писать регулярные выражения в коде?
Конструктор позволяет визуально тестировать выражение на разных строках и сразу видеть совпадения, что ускоряет разработку и отладку. Кроме того, он генерирует готовый код BSL.

### Как сохранить выражение для последующего использования?
Используйте кнопку «Сохранить в библиотеку». Выражения сохраняются в виде списка часто используемых шаблонов.

### Поддерживаются ли обратные ссылки (backreferences)?
Да, `VBScript.RegExp` поддерживает обратные ссылки вида `\1`, `\2` и т.д.

## Технические вопросы

### Почему инструмент не работает на Linux?
Инструмент использует COM-объект `VBScript.RegExp`, который доступен только на платформе Windows. В качестве альтернативы используйте обработку регулярных выражений в [Консоли кода](/docs/tools/development-tools/code-console) с помощью сторонних библиотек.

### Какие флаги поддерживаются?
Поддерживаются флаги: Global (поиск всех совпадений), IgnoreCase (игнорировать регистр), Multiline (многострочный режим).

### Как экранировать специальные символы?
Используйте обратный слеш перед спецсимволом: `\.` для точки, `\*` для звёздочки, `\\` для обратного слеша. Визуальный редактор показывает экранирование в реальном времени.

### Где используется сгенерированный код?
В модулях объектов, обработках, отчётах, где требуется разбор или валидация строк — проверка email, телефона, ИНН, кода товара и т.д.
