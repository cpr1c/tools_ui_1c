# Конструктор регулярных выражений

Построение и тестирование регулярных выражений с генерацией кода 1С. Только Windows.

## Назначение

- Создание и тестирование регулярных выражений
- Генерация кода для 1С
- Визуализация совпадений

## Особенности

- Визуальный редактор регулярных выражений
- Тестирование на примерах
- Генерация кода на BSL

## Использование

1. Перейдите в меню **Универсальные инструменты → Конструктор регулярных выражений**
2. Введите регулярное выражение
3. Протестируйте на примерах
4. Скопируйте сгенерированный код
