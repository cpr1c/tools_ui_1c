# Возможности

## Основные возможности

- **Визуальный редактор регулярных выражений** — интерактивное построение и отладка регулярных выражений с подсветкой совпадений.
- **Тестирование на примерах** — ввод тестовых строк и мгновенный просмотр всех совпадений.
- **Генерация кода на BSL** — автоматическое создание готового кода 1С для использования регулярного выражения в конфигурации.
- **Подсветка синтаксиса** — цветовое выделение групп, квантификаторов, классов символов и экранированных последовательностей.

## Дополнительные возможности

- **Пошаговое построение** — добавление частей выражения через визуальные конструкторы (группа, диапазон, повторение).
- **Сохранение библиотек** — сохранение часто используемых выражений для повторного использования.
- **Разбор выражения** — отображение пояснений к каждой части регулярного выражения.

## Интеграция

- Сгенерированный код можно выполнить в [Консоли кода](/docs/tools/development-tools/code-console) для проверки на реальных данных.
- Регулярные выражения могут использоваться в [Консоли запросов](/docs/tools/development-tools/query-console) для обработки строковых данных.
- Результаты разбора текста можно сохранить в [Редакторе JSON](/docs/tools/development-tools/json-editor).

**Примечание:** Инструмент работает только на платформе Windows (требует компоненту `VBScript.RegExp`).
