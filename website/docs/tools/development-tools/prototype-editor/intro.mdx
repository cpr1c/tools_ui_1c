# Редактор прототипов форм

Интерактивное построение прототипов форм. Форк [sketch1c](https://github.com/alehinsasha/sketch1c) с разрешения авторов.

## Назначение

- Быстрое создание прототипов интерфейсов
- Визуальное проектирование форм
- Тестирование дизайна без глубокой проработки

## Особенности

- Интерактивное рисование элементов
- Автоматическая генерация кода
- Экспорт в формат 1С

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор прототипов форм**
2. Создайте новую форму
3. Добавьте элементы и настройте их свойства
4. Посмотрите сгенерированный код

## Возможности

## Основные возможности

- **Визуальное проектирование форм** — создание прототипов интерфейсов путём перетаскивания и настройки элементов управления.
- **Автоматическая генерация кода** — формирование готового кода формы 1С на основе визуального прототипа.
- **Интерактивное рисование элементов** — добавление кнопок, полей ввода, таблиц, переключателей и других элементов управления.
- **Настройка свойств** — редактирование заголовков, размеров, положения и других свойств элементов через панель свойств.

## Дополнительные возможности

- **Экспорт в формат 1С** — сохранение прототипа в формате, готовом для встраивания в конфигурацию.
- **Предпросмотр** — визуализация того, как будет выглядеть форма в рантайме.
- **Быстрое прототипирование** — создание макета формы за минуты для согласования с заказчиком.

## Интеграция

- Сгенерированный код формы можно доработать в [Консоли кода](/docs/tools/development-tools/code-console) перед вставкой в конфигурацию.
- Прототипы форм можно использовать как основу для создания HTML-шаблонов в [Редакторе HTML](/docs/tools/development-tools/html-editor).
- Инструмент основан на форке [sketch1c](https://github.com/alehinsasha/sketch1c).

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Редактор прототипов форм**.
2. Нажмите «Создать новую форму».
3. Перетащите элементы управления из панели элементов на форму.
4. Настройте свойства каждого элемента в панели свойств справа.
5. Нажмите «Сгенерировать код» — готовый код формы отобразится в панели кода.
6. Скопируйте код и вставьте в конфигуратор 1С.

## Сценарии использования

### Сценарий 1: Создание формы подбора товаров

1. Добавьте на форму элементы:
   - Поле ввода «Наименование товара»
   - Таблицу для отображения результатов поиска
   - Кнопки «Найти», «Выбрать», «Отмена»
2. Настройте заголовки и размеры элементов.
3. Сгенерируйте код.
4. Доработайте обработчики событий в [Консоли кода](/docs/tools/development-tools/code-console):

```1c
Процедура НайтиНажатие(Элемент)
    Запрос = Новый Запрос;
    Запрос.Текст =
    "ВЫБРАТЬ
    |   Ссылка, Наименование, Артикул
    |ИЗ
    |   Справочник.Номенклатура
    |ГДЕ
    |   Наименование ПОДОБНО &Поиск";
    Запрос.УстановитьПараметр("Поиск", "%" + Объект.НаименованиеТовара + "%");
    Результат = Запрос.Выполнить();
    // ... обработка результата
КонецПроцедуры
```

### Сценарий 2: Макет для согласования

Создайте прототип формы документа, расположите все необходимые реквизиты, настройте их порядок обхода и видимость. Экспортируйте скриншот для согласования с заказчиком, затем используйте сгенерированный код для создания реальной формы.

## Часто задаваемые вопросы

## Общие вопросы

### Какие элементы управления доступны?
Все стандартные элементы управляемой формы 1С: поле ввода, переключатель, флажок, кнопка, таблица, группа, декорация, надпись, индикатор, поле выбора и другие.

### Создаёт ли редактор готовую форму 1С?
Редактор генерирует код формы на языке 1С (BSL), который можно вставить в модуль формы в конфигураторе. Для работы формы потребуется также настроить реквизиты и команды.

### Можно ли редактировать существующий прототип?
Да, вы можете загрузить ранее сохранённый прототип в формате XML и продолжить редактирование.

## Технические вопросы

### В каком формате генерируется код?
Код генерируется на языке 1С (BSL) в виде процедур и функций для управляемой формы, совместимых с платформой 8.3.

### Поддерживается ли иерархия элементов (группы, страницы)?
Да, можно создавать группы обычные и с переключением (страницы), а также размещать элементы внутри групп.

### Как изменить порядок обхода (TabOrder)?
Порядок обхода задаётся автоматически по расположению элементов на форме. Его можно изменить вручную в сгенерированном коде.

### Работает ли редактор на веб-клиенте?
Да, редактор прототипов работает во всех клиентах 1С.

## Решение проблем

## Проблема: Элементы отображаются не на своих местах
**Причина:** Неверно настроена привязка элементов или изменён размер контейнера.
**Решение:** Проверьте свойства «Положение» и «Размер» для каждого элемента. Используйте группы для объединения связанных элементов.

## Проблема: Сгенерированный код содержит ошибки
**Причина:** Использованы неподдерживаемые свойства или нестандартные комбинации элементов.
**Решение:** Проверьте совместимость с версией платформы. Упростите прототип, убрав нестандартные элементы, затем доработайте код вручную.

## Проблема: Не удаётся добавить элемент на форму
**Причина:** Элемент перекрыт другими элементами или область размещения заполнена.
**Решение:** Увеличьте размер формы или переместите существующие элементы, освободив место для нового.

## Проблема: Пропадают настройки при сохранении
**Причина:** Используется устаревшая версия формата прототипа.
**Решение:** Сохраните прототип в актуальном формате. Проверьте, что все настройки поддерживаются текущей версией редактора.

## Проблема: Кнопка не реагирует на нажатие в предпросмотре
**Причина:** Для кнопки не назначено действие или обработчик.
**Решение:** В предпросмотре отображается только визуальная часть. Обработчики добавляются в сгенерированном коде и не воспроизводятся в режиме предпросмотра.
