# Возможности

## Основные возможности

- **Визуальное проектирование форм** — создание прототипов интерфейсов путём перетаскивания и настройки элементов управления.
- **Автоматическая генерация кода** — формирование готового кода формы 1С на основе визуального прототипа.
- **Интерактивное рисование элементов** — добавление кнопок, полей ввода, таблиц, переключателей и других элементов управления.
- **Настройка свойств** — редактирование заголовков, размеров, положения и других свойств элементов через панель свойств.

## Дополнительные возможности

- **Экспорт в формат 1С** — сохранение прототипа в формате, готовом для встраивания в конфигурацию.
- **Предпросмотр** — визуализация того, как будет выглядеть форма в рантайме.
- **Быстрое прототипирование** — создание макета формы за минуты для согласования с заказчиком.

## Интеграция

- Сгенерированный код формы можно доработать в [Консоли кода](/docs/tools/development-tools/code-console) перед вставкой в конфигурацию.
- Прототипы форм можно использовать как основу для создания HTML-шаблонов в [Редакторе HTML](/docs/tools/development-tools/html-editor).
- Инструмент основан на форке [sketch1c](https://github.com/alehinsasha/sketch1c).
