# Редактор JSON

Редактирование JSON с подсветкой, деревом и авто-подстановками. На базе [jsoneditor](https://github.com/josdejong/jsoneditor).

## Назначение

- Визуальное редактирование JSON
- Проверка синтаксиса JSON
- Преобразование JSON в табличный вид

## Особенности

- Подсветка синтаксиса JSON
- Дерево структуры JSON
- Редактирование в виде таблицы
- Валидация JSON

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор JSON**
2. Вставьте JSON или откройте файл
3. Отредактируйте в любом удобном виде (код, дерево или таблица)
4. Сохраните результат

## Возможности

## Основные возможности

- **Подсветка синтаксиса JSON** — цветовое выделение ключей, строк, чисел, логических значений и null.
- **Режим «Дерево»** — визуальное представление JSON в виде сворачиваемого дерева узлов. Удобно для навигации по сложным структурам.
- **Режим «Таблица»** — отображение JSON-массива объектов в табличном виде с сортировкой по столбцам.
- **Режим «Код»** — редактирование JSON как текста с подсветкой синтаксиса и автодополнением.
- **Валидация JSON** — мгновенная проверка синтаксиса с указанием ошибок и их позиций.

## Дополнительные возможности

- **Форматирование** — автоматическое выравнивание и сжатие JSON (pretty print / minify).
- **Поиск и фильтрация** — поиск по ключам и значениям в режиме дерева.
- **Поддержка больших данных** — работа с JSON-файлами до нескольких десятков мегабайт.
- **История изменений** — отмена и повтор действий (Ctrl+Z, Ctrl+Y).

## Интеграция

- JSON из ответов [Консоли HTTP-запросов](/docs/tools/development-tools/http-console) можно открыть в редакторе.
- Результаты обработки JSON можно использовать в [Консоли кода](/docs/tools/development-tools/code-console).
- Инструмент построен на базе библиотеки [jsoneditor](https://github.com/josdejong/jsoneditor).

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Редактор JSON**.
2. Вставьте JSON-текст или откройте файл.
3. Выберите режим просмотра: Код, Дерево или Таблица.
4. Отредактируйте данные.
5. Сохраните результат в файл или скопируйте в буфер обмена.

## Сценарии использования

### Сценарий 1: Анализ структуры JSON

Вставьте JSON-ответ от API и включите режим «Дерево»:

```json
{
  "status": "success",
  "data": {
    "users": [
      {
        "id": 1,
        "name": "Иван",
        "email": "ivan@example.com"
      },
      {
        "id": 2,
        "name": "Мария",
        "email": "maria@example.com"
      }
    ],
    "total": 2
  }
}
```

В режиме дерева можно сворачивать и разворачивать узлы, быстро находить нужные поля.

### Сценарий 2: Редактирование в табличном режиме

Если JSON представляет собой массив объектов, переключитесь в режим «Таблица». Каждый объект станет строкой таблицы, а ключи — столбцами. Можно редактировать ячейки напрямую, добавлять и удалять строки.

### Сценарий 3: Конвертация JSON в BSL

Скопируйте JSON, обработайте его в [Консоли кода](/docs/tools/development-tools/code-console):

```1c
JSONСтрока = "{""name"": ""Товар"", ""price"": 100}";
ЧтениеJSON = Новый ЧтениеJSON;
ЧтениеJSON.УстановитьСтроку(JSONСтрока);
Результат = ПрочитатьJSON(ЧтениеJSON);
ЧтениеJSON.Закрыть();

Для каждого КлючЗначение Из Результат Цикл
    Сообщить(КлючЗначение.Ключ + ": " + КлючЗначение.Значение);
КонецЦикла;
```

## Часто задаваемые вопросы

## Общие вопросы

### В чём разница между режимами «Дерево» и «Таблица»?
Дерево показывает полную структуру JSON, включая вложенность. Таблица — удобна только для массивов однотипных объектов, где каждый объект — строка.

### Можно ли редактировать JSON в режиме дерева?
Да, все режимы (Код, Дерево, Таблица) поддерживают редактирование. Изменения синхронизируются между режимами.

### Как проверить корректность JSON?
JSON валидируется автоматически при вводе. Если есть ошибка, редактор подсветит проблемное место и покажет описание ошибки.

## Технические вопросы

### Какой максимальный размер JSON можно открыть?
Рекомендуется не более 50 МБ. При открытии файлов большего размера возможно замедление работы интерфейса.

### Как импортировать JSON из файла 1С (JSON в формате BSL)?
Файлы в формате 1С, сохранённые как JSON, открываются как обычный JSON. Если используется сериализация 1С, необходимо предварительно преобразовать формат.

### Работает ли редактор на веб-клиенте?
Да, редактор JSON работает во всех режимах клиента 1С: толстом, тонком и веб-клиенте.

### Можно ли настроить размер шрифта?
Да, размер шрифта настраивается в меню «Настройки» редактора.

## Решение проблем

## Проблема: Редактор показывает ошибку «Невалидный JSON»
**Причина:** JSON содержит синтаксическую ошибку: лишняя запятая, пропущенная кавычка, неверный формат числа.
**Решение:** Внимательно проверьте строку, на которую указывает редактор. Используйте функцию форматирования (Pretty Print) — она часто помогает обнаружить лишние символы.

## Проблема: В режиме «Таблица» отображается только одна строка
**Причина:** JSON не является массивом объектов или содержит разнородные объекты с разными ключами.
**Решение:** Переключитесь в режим «Дерево» для просмотра полной структуры. Табличный режим работает только для однородных массивов.

## Проблема: Не сохраняется отредактированный JSON
**Причина:** Отсутствие прав на запись в выбранную папку.
**Решение:** Выберите другую папку для сохранения или запустите 1С от имени администратора.

## Проблема: Медленно работает при большом JSON
**Причина:** Размер JSON превышает 10-20 МБ.
**Решение:** Закройте другие вкладки с JSON. Используйте режим «Код» вместо «Дерево» — он менее требователен к ресурсам.

## Проблема: Потерялось форматирование после редактирования
**Причина:** Редактирование в режиме «Код» могло нарушить отступы.
**Решение:** Используйте кнопку «Форматировать» (Pretty Print) для восстановления читаемого вида.
