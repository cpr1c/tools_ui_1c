# Навигатор по метаданным

Замена меню «Все функции» с дополнительными административными функциями.

## Назначение

- Быстрый поиск объектов метаданных
- Управление правами доступа
- Просмотр зависимостей объектов

## Особенности

- Расширенный поиск по метаданным
- Просмотр зависимостей
- Управление правами доступа

## Использование

1. Перейдите в меню **Универсальные инструменты → Навигатор по метаданным**
2. Введите имя объекта или используйте фильтры
3. Выберите нужный объект
4. Выполните нужное действие (права, зависимости и т.д.)

## Возможности

## Основные возможности

- **Расширенный поиск объектов метаданных** — быстрый поиск по имени, синониму или комментарию с фильтрацией по типу объекта.
- **Просмотр зависимостей** — отображение полного дерева зависимостей для выбранного объекта: где используется и какие объекты использует сам.
- **Управление правами доступа** — просмотр и редактирование прав доступа на объекты метаданных в наглядном табличном виде.
- **Просмотр свойств объекта** — отображение всех свойств выбранного объекта метаданных: реквизиты, табличные части, формы, макеты.

## Дополнительные возможности

- **Сравнение объектов** — сравнение свойств двух объектов метаданных.
- **Экспорт списка метаданных** — выгрузка полного дерева метаданных в текстовый файл для документирования.
- **Административные функции** — блокировка соединений, просмотр активных пользователей, запуск под другим пользователем.
- **Просмотр кода модулей** — быстрый переход к просмотру модулей объекта.

## Интеграция

- Через навигатор можно запускать другие инструменты под указанным пользователем.
- Найденные через навигатор объекты могут быть проанализированы в [Консоли кода](/docs/tools/development-tools/code-console) и [Консоли запросов](/docs/tools/development-tools/query-console).
- Инструмент является расширенной заменой стандартного меню «Все функции» 1С.

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Навигатор по метаданным**.
2. В поле поиска введите имя объекта (или его часть).
3. Используйте фильтры по типу объекта (справочники, документы, регистры и т.д.).
4. Выберите объект из результатов поиска.
5. Просмотрите свойства, зависимости или права объекта.

## Сценарии использования

### Сценарий 1: Поиск объекта и просмотр зависимостей

1. Введите в поиске «Номенклатура».
2. Выберите «Справочник.Номенклатура» из результатов.
3. Перейдите на вкладку «Зависимости»:
   - Раздел «Где используется» — показывает все объекты, ссылающиеся на номенклатуру.
   - Раздел «Использует» — показывает объекты, на которые ссылается сам справочник.
4. Используйте эту информацию для оценки влияния изменений перед доработкой.

### Сценарий 2: Управление правами доступа

1. Выберите объект (например, документ «РеализацияТоваровУслуг»).
2. Перейдите на вкладку «Права доступа».
3. Просмотрите текущие права для каждой роли.
4. Отметьте необходимые права (чтение, запись, проведение и т.д.).
5. Сохраните изменения.

### Сценарий 3: Запуск под другим пользователем

1. В меню навигатора выберите «Запуск под пользователем».
2. Укажите пользователя, от имени которого нужно выполнить операцию.
3. Запустите любой инструмент в контексте указанного пользователя.
4. Это удобно для тестирования прав доступа без выхода из сеанса.

## Часто задаваемые вопросы

## Общие вопросы

### Чем навигатор лучше стандартного меню «Все функции»?
Навигатор предоставляет расширенный поиск, просмотр зависимостей, управление правами и административные функции в одном интерфейсе. «Все функции» — только иерархический список объектов.

### Какие типы объектов доступны для поиска?
Все типы метаданных 1С: справочники, документы, регистры сведений, регистры накопления, отчёты, обработки, перечисления, ПВХ, бизнес-процессы, задачи и другие.

### Можно ли просматривать модули объектов?
Да, для выбранного объекта можно открыть просмотр его модулей (модуль объекта, модуль менеджера, модуль формы) в режиме чтения.

## Технические вопросы

### Работает ли поиск по синонимам?
Да, поиск выполняется по имени, синониму объекта и полному наименованию на языке конфигурации.

### Отображаются ли права для подчинённых объектов?
Да, если у объекта есть подчинённые реквизиты или табличные части, их права также можно просмотреть и отредактировать.

### Как обновить список метаданных при изменении конфигурации?
Список метаданных обновляется при каждом открытии навигатора. При изменении конфигурации достаточно закрыть и снова открыть форму навигатора.

### Можно ли через навигатор изменить структуру метаданных?
Нет, навигатор — средство просмотра и администрирования. Изменение структуры выполняется через конфигуратор.

### Поддерживается ли отбор по общим реквизитам?
Да, в результатах поиска можно фильтровать объекты по наличию общих реквизитов, а также просматривать значения общих реквизитов для выбранных объектов.

## Решение проблем

## Проблема: Поиск не находит существующий объект
**Причина:** Объект добавлен в конфигурацию после открытия навигатора.
**Решение:** Закройте и снова откройте форму навигатора для обновления списка метаданных.

## Проблема: Не отображаются зависимости для объекта
**Причина:** Поиск зависимостей может выполняться долго для объектов, которые используются в большом количестве мест.
**Решение:** Подождите завершения построения дерева зависимостей. Если объектов много, используйте фильтры для сужения результатов.

## Проблема: Ошибка при попытке сохранить права доступа
**Причина:** У текущего пользователя нет прав на изменение метаданных.
**Решение:** Запустите 1С с правами полного доступа (администратор). Используйте запуск под пользователем с необходимыми привилегиями.

## Проблема: Дерево метаданных отображается с ошибками
**Причина:** Повреждена или неполная конфигурация базы данных.
**Решение:** Выполните тестирование и исправление базы данных через конфигуратор. Проверьте целостность метаданных.

## Проблема: Не открывается просмотр модуля
**Причина:** Отсутствие прав на чтение модулей у текущего пользователя или модуль заблокирован.
**Решение:** Проверьте права доступа на подсистему «Администрирование». В некоторых конфигурациях доступ к модулям ограничен.
