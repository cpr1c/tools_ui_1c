# Возможности: Структура хранения базы данных

## Дерево таблиц базы данных

Иерархическое отображение всех таблиц информационной базы с группировкой по типам метаданных (справочники, документы, регистры и т.д.).

## Связь таблиц с метаданными

Для каждой таблицы показывается соответствующий объект метаданных, что упрощает анализ физической модели данных.

## Информация о размерах таблиц

Отображение количества записей и занимаемого места для каждой таблицы.

## Просмотр полей таблицы

Детальная информация о структуре таблицы:
- Имя поля
- Тип данных
- Длина
- Индексы

## Поиск по таблицам

Быстрый поиск таблицы по имени или по объекту метаданных.
