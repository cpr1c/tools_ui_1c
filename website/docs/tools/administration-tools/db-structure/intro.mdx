# Структура хранения базы данных

Просмотр имён таблиц и связей с объектами метаданных.

## Назначение

- Просмотр структуры хранения базы
- Связи таблиц и объектов метаданных
- Анализ физической структуры базы

## Особенности

- Дерево таблиц базы
- Связи с метаданными
- Просмотр размеров таблиц

## Использование

1. Перейдите в меню **Универсальные инструменты → Структура хранения**
2. Посмотрите дерево таблиц
3. Выберите таблицу для просмотра связей
4. Проанализируйте структуру
