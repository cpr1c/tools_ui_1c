# Структура хранения базы данных

Просмотр имён таблиц и связей с объектами метаданных.

## Назначение

- Просмотр структуры хранения базы
- Связи таблиц и объектов метаданных
- Анализ физической структуры базы

## Особенности

- Дерево таблиц базы
- Связи с метаданными
- Просмотр размеров таблиц

## Использование

1. Перейдите в меню **Универсальные инструменты → Структура хранения**
2. Посмотрите дерево таблиц
3. Выберите таблицу для просмотра связей
4. Проанализируйте структуру

## Возможности

## Дерево таблиц базы данных

Иерархическое отображение всех таблиц информационной базы с группировкой по типам метаданных (справочники, документы, регистры и т.д.).

## Связь таблиц с метаданными

Для каждой таблицы показывается соответствующий объект метаданных, что упрощает анализ физической модели данных.

## Информация о размерах таблиц

Отображение количества записей и занимаемого места для каждой таблицы.

## Просмотр полей таблицы

Детальная информация о структуре таблицы:
- Имя поля
- Тип данных
- Длина
- Индексы

## Поиск по таблицам

Быстрый поиск таблицы по имени или по объекту метаданных.

## Использование

## Запуск инструмента

Откройте меню **Универсальные инструменты → Структура хранения базы данных**.

## Просмотр дерева таблиц

В левой части формы отображается дерево всех таблиц базы. Разверните узел, чтобы увидеть таблицы определённого вида метаданных.

## Просмотр структуры таблицы

Выберите таблицу в дереве. В правой части отобразятся:
- Список полей таблицы
- Типы данных полей
- Размер таблицы
- Количество записей

## Поиск таблицы

Используйте строку поиска в верхней части дерева. Поиск выполняется по имени таблицы и по имени объекта метаданных.

## Программный доступ

```bsl
МетаданныеТаблицы = ПолучитьСтруктуруХраненияБазДанных();
Для Каждого Таблица Из МетаданныеТаблицы Цикл
    Сообщить(Таблица.ИмяТаблицы);
```

## Часто задаваемые вопросы

## Можно ли изменить структуру таблицы?

Нет, инструмент предназначен только для просмотра. Изменение структуры выполняется через конфигуратор.

## Почему не отображаются все таблицы?

Убедитесь, что у пользователя есть права на чтение системной информации. Проверьте подключение к базе.

## Как определить размер таблицы?

Выберите таблицу в дереве — размер отображается в колонке **Размер** или **Количество записей**.

## Что означает сообщение "Таблица не найдена"?

Ошибка возникает, если физическая таблица отсутствует в базе, но объект метаданных существует. Возможная причина — неполное обновление конфигурации базы данных.

## Решение проблем

## Дерево таблиц пустое

1. Проверьте права пользователя на чтение метаданных
2. Убедитесь, что база данных доступна
3. Перезапустите инструмент

## Ошибка получения структуры

1. Проверьте версию платформы 1С (требуется не ниже 8.3.10)
2. Возможно, используется некластерное соединение
3. Проверьте настройки безопасности информационной базы

## Размер таблицы не отображается

Некоторые СУБД не предоставляют информацию о размере таблиц. Запустите инструмент под пользователем с правами администратора.
