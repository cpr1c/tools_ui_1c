# Использование: Структура хранения базы данных

## Запуск инструмента

Откройте меню **Универсальные инструменты → Структура хранения базы данных**.

## Просмотр дерева таблиц

В левой части формы отображается дерево всех таблиц базы. Разверните узел, чтобы увидеть таблицы определённого вида метаданных.

## Просмотр структуры таблицы

Выберите таблицу в дереве. В правой части отобразятся:
- Список полей таблицы
- Типы данных полей
- Размер таблицы
- Количество записей

## Поиск таблицы

Используйте строку поиска в верхней части дерева. Поиск выполняется по имени таблицы и по имени объекта метаданных.

## Программный доступ

```bsl
МетаданныеТаблицы = ПолучитьСтруктуруХраненияБазДанных();
Для Каждого Таблица Из МетаданныеТаблицы Цикл
    Сообщить(Таблица.ИмяТаблицы);
КонецЦикла;
```
