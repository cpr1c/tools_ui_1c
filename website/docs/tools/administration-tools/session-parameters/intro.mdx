# Редактор параметров сеанса

Просмотр и изменение параметров сеанса.

## Назначение

- Просмотр параметров текущего сеанса
- Изменение параметров сеанса
- Отладка параметров

## Особенности

- Список всех параметров сеанса
- Возможность изменения
- История изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор параметров сеанса**
2. Посмотрите параметры текущего сеанса
3. Измените нужные параметры
4. Примените изменения

## Возможности

## Просмотр параметров сеанса

Отображение всех параметров текущего сеанса с их текущими значениями и типами данных.

## Изменение параметров

Возможность изменять значения параметров сеанса в реальном времени. Изменения применяются немедленно.

## Фильтрация и поиск

Быстрый поиск параметра по имени. Фильтрация по значению и типу данных.

## История изменений

Журнал изменений параметров сеанса с указанием времени и предыдущего значения.

## Экспорт параметров

Выгрузка списка параметров сеанса в текстовый или табличный документ для анализа.

## Использование

## Запуск инструмента

Откройте меню **Универсальные инструменты → Редактор параметров сеанса**.

## Просмотр параметров

После открытия отображается таблица всех параметров текущего сеанса с колонками: имя, значение, тип.

## Поиск параметра

Используйте строку поиска в верхней части формы для фильтрации списка по имени параметра.

## Изменение параметра

1. Выделите параметр в списке
2. Нажмите **Изменить** или дважды кликните
3. Введите новое значение
4. Нажмите **Применить**

## Программное изменение

```bsl
// Установка параметра сеанса программно
Параметр = ПараметрыСеанса.Параметр;
Параметр.Установить(НовоеЗначение);
```

## Экспорт

Нажмите **Экспорт** для выгрузки списка параметров в файл.

## Часто задаваемые вопросы

## Безопасно ли изменять параметры сеанса?

Изменение параметров сеанса может повлиять на работу системы в рамках текущего сеанса. Будьте осторожны — некоторые параметры критичны для функционирования.

## Почему параметр не изменяется?

Некоторые параметры доступны только для чтения. Убедитесь, что параметр не является системным.

## Как сбросить изменения?

Закройте и откройте заново сеанс, чтобы параметры вернулись к значениям по умолчанию (если они не были изменены в настройках).

## Можно ли добавить новый параметр?

Нет, инструмент позволяет только просматривать и изменять существующие параметры сеанса.

## Решение проблем

## Параметр не сохраняется после перезапуска

Параметры сеанса действуют только в рамках текущего сеанса. Для постоянного изменения настройте параметры через конфигуратор.

## Ошибка "Недостаточно прав"

Для изменения некоторых параметров требуются права администратора. Обратитесь к администратору системы.

## Неверное значение параметра

1. Убедитесь, что тип введённого значения соответствует типу параметра
2. Проверьте допустимые значения в документации
3. При ошибке сбросьте сеанс

## Параметр не отображается в списке

Некоторые параметры скрыты системой. Фильтры могут быть включены, проверьте настройки фильтрации.
