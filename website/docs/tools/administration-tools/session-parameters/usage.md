# Использование: Редактор параметров сеанса

## Запуск инструмента

Откройте меню **Универсальные инструменты → Редактор параметров сеанса**.

## Просмотр параметров

После открытия отображается таблица всех параметров текущего сеанса с колонками: имя, значение, тип.

## Поиск параметра

Используйте строку поиска в верхней части формы для фильтрации списка по имени параметра.

## Изменение параметра

1. Выделите параметр в списке
2. Нажмите **Изменить** или дважды кликните
3. Введите новое значение
4. Нажмите **Применить**

## Программное изменение

```bsl
// Установка параметра сеанса программно
Параметр = ПараметрыСеанса.Параметр;
Параметр.Установить(НовоеЗначение);
```

## Экспорт

Нажмите **Экспорт** для выгрузки списка параметров в файл.
