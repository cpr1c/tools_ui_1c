# Решение проблем: Удаление помеченных объектов

## Ошибка удаления: "Объект не найден"

Объект был удалён другим пользователем или транзакцией. Обновите список помеченных объектов.

## Недостаточно прав

Для удаления объектов требуются права:
- Администратор информационной базы
- Право на удаление для конкретных видов объектов

## Ошибка блокировки базы данных

При удалении большого количества объектов может возникнуть конфликт блокировок. Повторите операцию в нерабочее время.

## Объект не удаляется из-за ссылочной целостности

1. Включите флаг **Удалять с проверкой ссылок**
2. Просмотрите список ссылающихся объектов
3. Удалите или снимите пометки с ссылающихся объектов
