# Удаление помеченных объектов

Копия стандартной обработки из БСП, адаптированная для жизни вне БСП.

## Назначение

- Удаление помеченных на удаление объектов
- Очистка базы данных
- Освобождение места

## Особенности

- Поддержка всех типов объектов
- Просмотр списка удаляемых объектов
- Предварительный просмотр результатов

## Использование

1. Перейдите в меню **Универсальные инструменты → Удаление помеченных объектов**
2. Выберите типы объектов
3. Нажмите **Найти помеченные**
4. Просмотрите список и удалите

## Возможности

## Полный поиск помеченных объектов

Инструмент находит все объекты, помеченные на удаление, по всем типам метаданных.

## Выборочное удаление по типам

Возможность указать, объекты каких типов необходимо искать и удалять (справочники, документы, регистры и т.д.).

## Предварительный просмотр

Перед удалением показывается полный список найденных объектов с возможностью исключения отдельных позиций.

## Контроль ссылочной целостности

Анализ ссылок на удаляемые объекты. Инструмент предупреждает, если на объект есть ссылки из других объектов.

## Режимы удаления

- Обычное удаление
- Удаление с проверкой ссылок
- Полное удаление без проверки

## Использование

## Запуск инструмента

Откройте меню **Универсальные инструменты → Удаление помеченных объектов**.

## Поиск объектов

1. Выберите типы объектов для поиска (или оставьте все)
2. Нажмите **Найти помеченные**
3. Дождитесь завершения поиска

## Просмотр результатов

После поиска отобразится список объектов с колонками: наименование, вид объекта, дата пометки.

## Удаление объектов

```bsl
// Программное удаление через инструмент
Обработка = ВнешниеОбработки.Создать("УдалениеПомеченныхОбъектов");
Обработка.УдалитьОбъектыПометок(Истина);  // Истина — удалять с проверкой
```

## Исключение объектов

Снимите флажки с объектов, которые не нужно удалять, затем нажмите **Удалить**.

## Часто задаваемые вопросы

## Можно ли восстановить удалённые объекты?

Нет. Удаление выполняется физически из базы данных. Рекомендуется перед массовым удалением создавать резервную копию.

## Почему некоторые объекты не удаляются?

На объект есть ссылки из других объектов базы. Используйте режим удаления с проверкой ссылок, чтобы увидеть, какие объекты ссылаются на удаляемый.

## Сколько времени занимает удаление?

Зависит от количества объектов и производительности сервера. Для больших объёмов данных может потребоваться длительное время.

## Нужна ли предварительная пометка объектов?

Да. Инструмент работает только с объектами, которые были ранее помечены на удаление стандартным способом (через пометку удаления).

## Решение проблем

## Ошибка удаления: "Объект не найден"

Объект был удалён другим пользователем или транзакцией. Обновите список помеченных объектов.

## Недостаточно прав

Для удаления объектов требуются права:
- Администратор информационной базы
- Право на удаление для конкретных видов объектов

## Ошибка блокировки базы данных

При удалении большого количества объектов может возникнуть конфликт блокировок. Повторите операцию в нерабочее время.

## Объект не удаляется из-за ссылочной целостности

1. Включите флаг **Удалять с проверкой ссылок**
2. Просмотрите список ссылающихся объектов
3. Удалите или снимите пометки с ссылающихся объектов
