# Удаление помеченных объектов

Копия стандартной обработки из БСП, адаптированная для жизни вне БСП.

## Назначение

- Удаление помеченных на удаление объектов
- Очистка базы данных
- Освобождение места

## Особенности

- Поддержка всех типов объектов
- Просмотр списка удаляемых объектов
- Предварительный просмотр результатов

## Использование

1. Перейдите в меню **Универсальные инструменты → Удаление помеченных объектов**
2. Выберите типы объектов
3. Нажмите **Найти помеченные**
4. Просмотрите список и удалите
