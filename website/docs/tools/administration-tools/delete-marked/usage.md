# Использование: Удаление помеченных объектов

## Запуск инструмента

Откройте меню **Универсальные инструменты → Удаление помеченных объектов**.

## Поиск объектов

1. Выберите типы объектов для поиска (или оставьте все)
2. Нажмите **Найти помеченные**
3. Дождитесь завершения поиска

## Просмотр результатов

После поиска отобразится список объектов с колонками: наименование, вид объекта, дата пометки.

## Удаление объектов

```bsl
// Программное удаление через инструмент
Обработка = ВнешниеОбработки.Создать("УдалениеПомеченныхОбъектов");
Обработка.УдалитьОбъектыПометок(Истина);  // Истина — удалять с проверкой
```

## Исключение объектов

Снимите флажки с объектов, которые не нужно удалять, затем нажмите **Удалить**.
