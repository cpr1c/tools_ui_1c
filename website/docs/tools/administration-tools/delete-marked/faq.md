# Часто задаваемые вопросы: Удаление помеченных объектов

## Можно ли восстановить удалённые объекты?

Нет. Удаление выполняется физически из базы данных. Рекомендуется перед массовым удалением создавать резервную копию.

## Почему некоторые объекты не удаляются?

На объект есть ссылки из других объектов базы. Используйте режим удаления с проверкой ссылок, чтобы увидеть, какие объекты ссылаются на удаляемый.

## Сколько времени занимает удаление?

Зависит от количества объектов и производительности сервера. Для больших объёмов данных может потребоваться длительное время.

## Нужна ли предварительная пометка объектов?

Да. Инструмент работает только с объектами, которые были ранее помечены на удаление стандартным способом (через пометку удаления).
