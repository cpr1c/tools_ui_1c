# Возможности: Удаление помеченных объектов

## Полный поиск помеченных объектов

Инструмент находит все объекты, помеченные на удаление, по всем типам метаданных.

## Выборочное удаление по типам

Возможность указать, объекты каких типов необходимо искать и удалять (справочники, документы, регистры и т.д.).

## Предварительный просмотр

Перед удалением показывается полный список найденных объектов с возможностью исключения отдельных позиций.

## Контроль ссылочной целостности

Анализ ссылок на удаляемые объекты. Инструмент предупреждает, если на объект есть ссылки из других объектов.

## Режимы удаления

- Обычное удаление
- Удаление с проверкой ссылок
- Полное удаление без проверки
