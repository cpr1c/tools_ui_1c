# Менеджер хранилищ настроек

Управление хранилищами системных настроек.

## Назначение

- Просмотр хранилищ системных настроек
- Редактирование настроек
- Управление версиями настроек

## Особенности

- Список всех хранилищ
- Просмотр содержимого
- Редактирование настроек

## Использование

1. Перейдите в меню **Универсальные инструменты → Менеджер хранилищ**
2. Выберите хранилище
3. Просмотрите или отредактируйте настройки

## Возможности

## Просмотр хранилищ настроек

Отображение всех зарегистрированных хранилищ системных настроек в информационной базе.

## Просмотр содержимого

Для каждого хранилища доступен просмотр всех сохранённых настроек с их значениями.

## Редактирование настроек

Изменение значений настроек непосредственно в форме. Поддерживаются различные типы данных: строки, числа, даты, структуры.

## Версионирование

Просмотр истории изменений настроек и возможность отката к предыдущей версии.

## Поиск по настройкам

Быстрый поиск конкретной настройки по имени или значению среди всех хранилищ.

## Использование

## Запуск инструмента

Откройте меню **Универсальные инструменты → Менеджер хранилищ настроек**.

## Выбор хранилища

В левой части формы выберите хранилище настроек. Справа отобразится список всех настроек выбранного хранилища.

## Просмотр настройки

Выберите настройку из списка. В нижней части формы отобразится её текущее значение и тип данных.

## Редактирование настройки

1. Выберите настройку
2. Нажмите **Изменить** или дважды кликните по строке
3. Измените значение
4. Сохраните изменения

## Просмотр истории

Нажмите **История**, чтобы увидеть список изменений настройки с датами и авторами.

## Программный доступ

```bsl
Хранилище = Новый ХранилищеНастроек("СистемныеНастройки");
Значение = Хранилище.Получить("ПараметрОтчёта");
```

## Часто задаваемые вопросы

## Можно ли удалить настройку?

Да, выберите настройку и нажмите **Удалить**. Будьте осторожны — удалённые настройки могут повлиять на работу системы.

## Что делать, если значение не сохраняется?

Убедитесь, что у пользователя есть права на запись в хранилище настроек.

## Как откатить изменение?

Откройте **Историю** настройки, выберите нужную версию и нажмите **Восстановить**.

## Почему хранилище пустое?

Возможно, настройки ещё не сохранены. Либо у пользователя нет прав на чтение данного хранилища.

## Решение проблем

## Ошибка при сохранении настройки

1. Проверьте, что значение соответствует типу данных настройки
2. Убедитесь, что хранилище не заблокировано другим сеансом
3. Проверьте права пользователя

## Не отображаются все хранилища

Инструмент показывает хранилища, доступные текущему пользователю. Некоторые хранилища могут быть недоступны из-за ограничений безопасности.

## Ошибка при восстановлении версии

1. Убедитесь, что версия, которую вы восстанавливаете, совместима с текущей структурой настроек
2. Проверьте, не был ли удалён тип настройки в конфигурации
