# Использование: Файловый менеджер

## Запуск инструмента

Откройте меню **Универсальные инструменты → Файловый менеджер**.

## Навигация по каталогам

1. Введите путь в строке адреса или выберите папку из дерева каталогов
2. Содержимое папки отобразится в таблице
3. Двойным кликом переходите в подпапки

## Загрузка файла на сервер

1. Перейдите в целевой каталог
2. Нажмите **Загрузить**
3. Выберите файл на клиентском компьютере
4. Подтвердите загрузку

## Выгрузка файла

1. Выделите файл в списке
2. Нажмите **Выгрузить**
3. Укажите путь сохранения на клиенте

## Программное использование

```bsl
ФайловыйМенеджер = ВнешниеОбработки.Создать("ФайловыйМенеджер");
ФайловыйМенеджер.СкопироватьНаСервер("/tmp/отчёт.pdf", "/home/user/отчёт.pdf");
```
