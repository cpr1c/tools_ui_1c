# Часто задаваемые вопросы: Файловый менеджер

## Безопасно ли удалять файлы через этот инструмент?

Удаление выполняется безвозвратно. Рекомендуется перед удалением создавать резервные копии важных файлов.

## Почему не отображаются некоторые папки?

У пользователя, под которым работает сервер 1С, могут отсутствовать права на чтение определённых каталогов.

## Можно ли редактировать файлы на сервере?

Нет, инструмент поддерживает только просмотр, загрузку, выгрузку и удаление. Для редактирования необходимо выгрузить файл на клиент.

## Какие ограничения по размеру файлов?

Ограничения определяются настройками платформы 1С и веб-сервера. Обычно не рекомендуется передавать файлы размером более 100 МБ.
