# Файловый менеджер

Работа с файлами между клиентом и сервером: передача, просмотр, удаление.

## Назначение

- Передача файлов между клиентом и сервером
- Просмотр файловой системы сервера
- Управление файлами на сервере

## Возможности

### Просмотр файловой системы сервера

Обзор каталогов и файлов на сервере 1С с возможностью навигации по папкам.

### Загрузка файлов на сервер

Передача файлов с клиентского компьютера на сервер в выбранный каталог.

### Выгрузка файлов с сервера

Сохранение файлов с сервера на клиентский компьютер.

### Удаление файлов

Безвозвратное удаление файлов и папок на сервере.

### Навигация по каталогам

Поддержка перехода по пути, возврат к предыдущему каталогу, обновление содержимого.

## Использование

### Запуск инструмента

Откройте меню **Универсальные инструменты → Файловый менеджер**.

### Навигация по каталогам

1. Введите путь в строке адреса или выберите папку из дерева каталогов
2. Содержимое папки отобразится в таблице
3. Двойным кликом переходите в подпапки

### Загрузка файла на сервер

1. Перейдите в целевой каталог
2. Нажмите **Загрузить**
3. Выберите файл на клиентском компьютере
4. Подтвердите загрузку

### Выгрузка файла

1. Выделите файл в списке
2. Нажмите **Выгрузить**
3. Укажите путь сохранения на клиенте

### Программное использование

```bsl
ФайловыйМенеджер = ВнешниеОбработки.Создать("ФайловыйМенеджер");
ФайловыйМенеджер.СкопироватьНаСервер("/tmp/отчёт.pdf", "/home/user/отчёт.pdf");
```

## Часто задаваемые вопросы

### Безопасно ли удалять файлы через этот инструмент?

Удаление выполняется безвозвратно. Рекомендуется перед удалением создавать резервные копии важных файлов.

### Почему не отображаются некоторые папки?

У пользователя, под которым работает сервер 1С, могут отсутствовать права на чтение определённых каталогов.

### Можно ли редактировать файлы на сервере?

Нет, инструмент поддерживает только просмотр, загрузку, выгрузку и удаление. Для редактирования необходимо выгрузить файл на клиент.

### Какие ограничения по размеру файлов?

Ограничения определяются настройками платформы 1С и веб-сервера. Обычно не рекомендуется передавать файлы размером более 100 МБ.

## Решение проблем

### Ошибка доступа к каталогу

1. Проверьте права на чтение каталога у пользователя сервера 1С
2. Убедитесь, что каталог существует
3. Проверьте сетевые пути (для сетевых папок)

### Ошибка загрузки файла

1. Проверьте размер файла (превышение ограничений)
2. Убедитесь, что на сервере достаточно места
3. Проверьте права на запись в целевой каталог

### Синхронные вызовы

Инструмент использует синхронные вызовы, что может блокировать интерфейс при работе с большими файлами. Используйте в нерабочее время.

### Файл не удаляется

Проверьте права на удаление. Файл может быть заблокирован другим процессом.

## Важно

**Файловый менеджер** на текущий момент содержит синхронные вызовы.
