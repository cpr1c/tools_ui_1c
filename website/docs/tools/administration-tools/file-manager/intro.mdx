# Файловый менеджер

Работа с файлами между клиентом и сервером: передача, просмотр, удаление.

## Назначение

- Передача файлов между клиентом и сервером
- Просмотр файловой системы сервера
- Управление файлами на сервере

## Особенности

- Обзор файловой системы сервера
- Загрузка и выгрузка файлов
- Удаление файлов

## Использование

1. Перейдите в меню **Универсальные инструменты → Файловый менеджер**
2. Выберите папку на сервере
3. Выполните нужное действие (загрузка, выгрузка, удаление)

## Важно

**Файловый менеджер** на текущий момент содержит синхронные вызовы.
