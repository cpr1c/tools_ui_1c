# Решение проблем: Файловый менеджер

## Ошибка доступа к каталогу

1. Проверьте права на чтение каталога у пользователя сервера 1С
2. Убедитесь, что каталог существует
3. Проверьте сетевые пути (для сетевых папок)

## Ошибка загрузки файла

1. Проверьте размер файла (превышение ограничений)
2. Убедитесь, что на сервере достаточно места
3. Проверьте права на запись в целевой каталог

## Синхронные вызовы

Инструмент использует синхронные вызовы, что может блокировать интерфейс при работе с большими файлами. Используйте в нерабочее время.

## Файл не удаляется

Проверьте права на удаление. Файл может быть заблокирован другим процессом.
