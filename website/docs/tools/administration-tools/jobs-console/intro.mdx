# Консоль заданий

Просмотр и настройка регламентных и фоновых заданий. Форк [JobsConsole2019](https://github.com/kuzyara/JobsConsole2019.epf) с разрешения авторов.

## Назначение

- Просмотр всех заданий базы
- Запуск и остановка заданий
- Настройка параметров заданий

## Особенности

- Полный список всех заданий
- Статус выполнения
- Логи выполнения

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль заданий**
2. Посмотрите список заданий
3. Выберите задание и настройте параметры
4. Запустите или остановите задание

## Возможности

## Полный перечень регламентных и фоновых заданий

Отображение всех заданий, зарегистрированных в информационной базе, с группировкой по метаданным.

## Мониторинг состояния

Отслеживание текущего статуса каждого задания: активно, остановлено, выполняется, ожидает.

## Управление заданиями

- Быстрый запуск задания
- Остановка выполнения
- Изменение расписания
- Настройка параметров задания (для фоновых заданий)

## Просмотр логов

Возможность просматривать последние сообщения и ошибки выполнения каждого задания непосредственно в форме.

## Отбор по видам заданий

Фильтрация списка по типу задания: регламентные, фоновые, общие.

## Программный интерфейс

```bsl
КонсольЗаданий = ВнешниеОбработки.Создать("КонсольЗаданий");
КонсольЗаданий.ПоказатьСписокЗаданий();
```

## Использование

## Запуск инструмента

Откройте меню **Универсальные инструменты → Консоль заданий**.

## Просмотр списка заданий

После открытия отображается полный список всех регламентных и фоновых заданий информационной базы. Для каждого задания видны наименование, идентификатор, статус и расписание.

## Запуск и остановка задания

1. Выделите задание в списке
2. Нажмите кнопку **Выполнить** для немедленного запуска
3. Для остановки используйте кнопку **Остановить**

## Изменение расписания

1. Выберите задание
2. Нажмите **Настроить расписание**
3. Задайте новое расписание в стандартной форме
4. Сохраните изменения

## Настройка параметров фонового задания

```bsl
// Пример установки параметров
Параметры = Новый Структура;
Параметры.Вставить("Период", НачалоМесяца(ТекущаяДата()));
Параметры.Вставить("ОчищатьПередЗагрузкой", Истина);
```

## Просмотр логов

Дважды кликните по заданию или нажмите **Лог выполнения** для просмотра истории запусков и сообщений.

## Часто задаваемые вопросы

## Почему задание не запускается?

Проверьте, не установлен ли признак **Использование** и не заблокировано ли выполнение заданий на уровне сервера.

## Как отменить запущенное задание?

Выделите задание в списке и нажмите **Остановить**. Если задание зависло, может потребоваться перезапуск сервера 1С.

## Можно ли создать новое задание?

Инструмент предназначен только для просмотра и управления существующими заданиями. Создание выполняется через конфигуратор.

## Как обновить список заданий?

Нажмите кнопку **Обновить** или клавишу F5.

## Почему не отображаются логи?

Убедитесь, что для задания ведется регистрация сообщений. Настройте уровень логирования в параметрах задания.

## Решение проблем

## Задание не выполняется по расписанию

1. Проверьте, включено ли выполнение регламентных заданий в параметрах информационной базы
2. Убедитесь, что задания не отключены в настройках самого задания
3. Проверьте расписание на корректность

## Ошибка при запуске задания

Если при запуске возникает ошибка, проверьте:
- Доступность сервера 1С
- Корректность параметров задания
- Наличие необходимых прав у пользователя

## Задание зависло в статусе "Выполняется"

1. Попробуйте остановить задание через интерфейс
2. Если не помогает, проверьте соединение с сервером
3. В крайнем случае перезапустите кластер серверов 1С

## Не отображаются все задания

Убедитесь, что у текущего пользователя есть права администратора информационной базы.
