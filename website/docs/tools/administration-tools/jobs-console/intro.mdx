# Консоль заданий

Просмотр и настройка регламентных и фоновых заданий. Форк [JobsConsole2019](https://github.com/kuzyara/JobsConsole2019.epf) с разрешения авторов.

## Назначение

- Просмотр всех заданий базы
- Запуск и остановка заданий
- Настройка параметров заданий

## Особенности

- Полный список всех заданий
- Статус выполнения
- Логи выполнения

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль заданий**
2. Посмотрите список заданий
3. Выберите задание и настройте параметры
4. Запустите или остановите задание
