# Часто задаваемые вопросы: Консоль заданий

## Почему задание не запускается?

Проверьте, не установлен ли признак **Использование** и не заблокировано ли выполнение заданий на уровне сервера.

## Как отменить запущенное задание?

Выделите задание в списке и нажмите **Остановить**. Если задание зависло, может потребоваться перезапуск сервера 1С.

## Можно ли создать новое задание?

Инструмент предназначен только для просмотра и управления существующими заданиями. Создание выполняется через конфигуратор.

## Как обновить список заданий?

Нажмите кнопку **Обновить** или клавишу F5.

## Почему не отображаются логи?

Убедитесь, что для задания ведется регистрация сообщений. Настройте уровень логирования в параметрах задания.
