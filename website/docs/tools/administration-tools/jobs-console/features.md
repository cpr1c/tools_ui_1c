# Возможности: Консоль заданий

## Полный перечень регламентных и фоновых заданий

Отображение всех заданий, зарегистрированных в информационной базе, с группировкой по метаданным.

## Мониторинг состояния

Отслеживание текущего статуса каждого задания: активно, остановлено, выполняется, ожидает.

## Управление заданиями

- Быстрый запуск задания
- Остановка выполнения
- Изменение расписания
- Настройка параметров задания (для фоновых заданий)

## Просмотр логов

Возможность просматривать последние сообщения и ошибки выполнения каждого задания непосредственно в форме.

## Отбор по видам заданий

Фильтрация списка по типу задания: регламентные, фоновые, общие.

## Программный интерфейс

```bsl
КонсольЗаданий = ВнешниеОбработки.Создать("КонсольЗаданий");
КонсольЗаданий.ПоказатьСписокЗаданий();
```
