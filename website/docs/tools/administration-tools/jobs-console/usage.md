# Использование: Консоль заданий

## Запуск инструмента

Откройте меню **Универсальные инструменты → Консоль заданий**.

## Просмотр списка заданий

После открытия отображается полный список всех регламентных и фоновых заданий информационной базы. Для каждого задания видны наименование, идентификатор, статус и расписание.

## Запуск и остановка задания

1. Выделите задание в списке
2. Нажмите кнопку **Выполнить** для немедленного запуска
3. Для остановки используйте кнопку **Остановить**

## Изменение расписания

1. Выберите задание
2. Нажмите **Настроить расписание**
3. Задайте новое расписание в стандартной форме
4. Сохраните изменения

## Настройка параметров фонового задания

```bsl
// Пример установки параметров
Параметры = Новый Структура;
Параметры.Вставить("Период", НачалоМесяца(ТекущаяДата()));
Параметры.Вставить("ОчищатьПередЗагрузкой", Истина);
```

## Просмотр логов

Дважды кликните по заданию или нажмите **Лог выполнения** для просмотра истории запусков и сообщений.
