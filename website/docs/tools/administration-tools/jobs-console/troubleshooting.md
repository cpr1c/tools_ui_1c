# Решение проблем: Консоль заданий

## Задание не выполняется по расписанию

1. Проверьте, включено ли выполнение регламентных заданий в параметрах информационной базы
2. Убедитесь, что задания не отключены в настройках самого задания
3. Проверьте расписание на корректность

## Ошибка при запуске задания

Если при запуске возникает ошибка, проверьте:
- Доступность сервера 1С
- Корректность параметров задания
- Наличие необходимых прав у пользователя

## Задание зависло в статусе "Выполняется"

1. Попробуйте остановить задание через интерфейс
2. Если не помогает, проверьте соединение с сервером
3. В крайнем случае перезапустите кластер серверов 1С

## Не отображаются все задания

Убедитесь, что у текущего пользователя есть права администратора информационной базы.
