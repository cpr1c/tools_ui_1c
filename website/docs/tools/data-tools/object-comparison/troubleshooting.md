# Устранение неполадок

## Проблемы

### Ошибка «Объекты разных типов»

Выберите два объекта одного типа метаданных. Нельзя сравнить, например, элемент справочника «Номенклатура» с документом «Реализация».

### Результат сравнения пустой

Убедитесь, что вы выбрали два разных объекта. Если выбраны одинаковые объекты, различий не будет. Проверьте, что сравниваются актуальные (не устаревшие) версии объектов.

### Не отображаются различия по табличным частям

Убедитесь, что у обоих объектов есть записи в табличных частях. Сравнение выполняется по равенству ключевых полей строк.

### Ошибка при получении объекта

Объект мог быть удалён из базы другим пользователем. Обновите список или введите актуальную ссылку.

### Сравнение выполняется слишком долго

Для объектов с большими табличными частями (сотни строк) время обработки может быть увеличено. Уменьшите количество сравниваемых реквизитов.

### Цветовое выделение не работает

Проверьте настройки табличного документа в используемой версии платформы. В некоторых режимах условное оформление может не поддерживаться.
