# FAQ

## Общие вопросы

### Какие объекты можно сравнивать?

Любые ссылочные объекты одного типа метаданных: справочники, документы, планы счетов, планы видов расчёта и т.д.

### Можно ли сравнить объекты разных типов?

Нет, сравнение возможно только для объектов одного типа метаданных, так как сравниваются одноимённые реквизиты.

### Сравниваются ли табличные части?

Да, обработка автоматически сравнивает строки табличных частей и выводит различия.

### Какие реквизиты исключаются из сравнения?

По умолчанию исключаются служебные реквизиты: Ссылка, ПометкаУдаления, Предопределённый, Код, Номер и т.д.

### Как экспортировать результат сравнения?

Результат формируется в виде табличного документа. Вы можете сохранить его в форматах MXL или XLSX.

### Можно ли настроить список сравниваемых реквизитов?

Да, на форме обработки есть возможность выбрать конкретные реквизиты для сравнения.

### Что делать, если различий много?

Используйте фильтрацию по значимым реквизитам или экспортируйте результат в Excel для дальнейшего анализа.
