# Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Сравнение объектов**.
2. Выберите первый объект (объект А).
3. Выберите второй объект (объект Б).
4. Нажмите **Сравнить**.
5. Просмотрите результат — таблицу с различиями.

## Сценарии

### Сравнение двух элементов справочника

```bsl
// Программное сравнение двух объектов
ОбъектА = Справочники.Номенклатура.НайтиПоКоду("00-00123").ПолучитьОбъект();
ОбъектБ = Справочники.Номенклатура.НайтиПоКоду("00-00456").ПолучитьОбъект();

Результат = Обработки.СравнениеОбъектов.Сравнить(ОбъектА, ОбъектБ);
Если Результат.ЕстьРазличия Тогда
    Для Каждого Реквизит Из Результат.Различия Цикл
        Сообщить(Реквизит.Имя + ": " + Реквизит.ЗначениеА + " → " + Реквизит.ЗначениеБ);
    КонецЦикла;
КонецЕсли;
```

### Сравнение с экспортом результата

```bsl
ТабДок = Обработки.СравнениеОбъектов.СравнитьВТабличныйДокумент(ОбъектА, ОбъектБ);
ТабДок.Записать("Сравнение_объектов.mxl", ТипФайлаТабличногоДокумента.MXL);
```

### Сравнение табличных частей

```bsl
// Обработка сравнивает табличные части автоматически
// при стандартном выполнении. Результат содержит отдельную
// таблицу сравнения строк табличных частей.
ТЧ_А = ОбъектА.Товары;
ТЧ_Б = ОбъектБ.Товары;
РезультатСравнения = Обработки.СравнениеОбъектов.СравнитьТабличныеЧасти(ТЧ_А, ТЧ_Б, "Номенклатура");
```
