# Возможности

## Основные возможности

- **Сравнение двух ссылочных объектов** — попарное сравнение объектов одного типа по всем реквизитам.
- **Выявление различий** — отображение только тех реквизитов, значения которых различаются.
- **Вывод в табличный документ** — формирование наглядного отчёта с колонками «Реквизит», «Значение А», «Значение Б».
- **Сравнение по составным типам** — корректная обработка полей с составными типами данных.

## Дополнительные возможности

- **Сравнение табличных частей** — построчное сравнение табличных частей объектов.
- **Подсветка различий** — цветовое выделение отличающихся значений в табличном документе.
- **Экспорт результата** — сохранение отчёта сравнения в файл.
- **Пропуск служебных реквизитов** — игнорирование стандартных полей (Ссылка, ПометкаУдаления и т.д.) при сравнении.

## Сценарии использования

- Проверка корректности изменений после редактирования.
- Сравнение объектов из разных баз данных.
- Аудит синхронизации данных.
- Отладка обменов данными.
