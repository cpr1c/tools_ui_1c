# Сравнение объектов

Сравнение ссылочных объектов по реквизитам с выводом в табличный документ.

## Назначение

- Сравнение двух объектов
- Выявление различий
- Проверка корректности изменений

## Особенности

- Сравнение по всем реквизитам
- Вывод различий в табличном виде
- Поддержка сложных типов

## Использование

1. Перейдите в меню **Универсальные инструменты → Сравнение объектов**
2. Выберите два объекта для сравнения
3. Нажмите **Сравнить**
4. Посмотрите различия

## Возможности

## Основные возможности

- **Сравнение двух ссылочных объектов** — попарное сравнение объектов одного типа по всем реквизитам.
- **Выявление различий** — отображение только тех реквизитов, значения которых различаются.
- **Вывод в табличный документ** — формирование наглядного отчёта с колонками «Реквизит», «Значение А», «Значение Б».
- **Сравнение по составным типам** — корректная обработка полей с составными типами данных.

## Дополнительные возможности

- **Сравнение табличных частей** — построчное сравнение табличных частей объектов.
- **Подсветка различий** — цветовое выделение отличающихся значений в табличном документе.
- **Экспорт результата** — сохранение отчёта сравнения в файл.
- **Пропуск служебных реквизитов** — игнорирование стандартных полей (Ссылка, ПометкаУдаления и т.д.) при сравнении.

## Сценарии использования

- Проверка корректности изменений после редактирования.
- Сравнение объектов из разных баз данных.
- Аудит синхронизации данных.
- Отладка обменов данными.

## Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Сравнение объектов**.
2. Выберите первый объект (объект А).
3. Выберите второй объект (объект Б).
4. Нажмите **Сравнить**.
5. Просмотрите результат — таблицу с различиями.

## Сценарии

### Сравнение двух элементов справочника

```bsl
// Программное сравнение двух объектов
ОбъектА = Справочники.Номенклатура.НайтиПоКоду("00-00123").ПолучитьОбъект();
ОбъектБ = Справочники.Номенклатура.НайтиПоКоду("00-00456").ПолучитьОбъект();

Результат = Обработки.СравнениеОбъектов.Сравнить(ОбъектА, ОбъектБ);
Если Результат.ЕстьРазличия Тогда
    Для Каждого Реквизит Из Результат.Различия Цикл
        Сообщить(Реквизит.Имя + ": " + Реквизит.ЗначениеА + " → " + Реквизит.ЗначениеБ);
    КонецЦикла;
КонецЕсли;
```

### Сравнение с экспортом результата

```bsl
ТабДок = Обработки.СравнениеОбъектов.СравнитьВТабличныйДокумент(ОбъектА, ОбъектБ);
ТабДок.Записать("Сравнение_объектов.mxl", ТипФайлаТабличногоДокумента.MXL);
```

### Сравнение табличных частей

```bsl
// Обработка сравнивает табличные части автоматически
// при стандартном выполнении. Результат содержит отдельную
// таблицу сравнения строк табличных частей.
ТЧ_А = ОбъектА.Товары;
ТЧ_Б = ОбъектБ.Товары;
РезультатСравнения = Обработки.СравнениеОбъектов.СравнитьТабличныеЧасти(ТЧ_А, ТЧ_Б, "Номенклатура");
```

## Часто задаваемые вопросы

## Общие вопросы

### Какие объекты можно сравнивать?

Любые ссылочные объекты одного типа метаданных: справочники, документы, планы счетов, планы видов расчёта и т.д.

### Можно ли сравнить объекты разных типов?

Нет, сравнение возможно только для объектов одного типа метаданных, так как сравниваются одноимённые реквизиты.

### Сравниваются ли табличные части?

Да, обработка автоматически сравнивает строки табличных частей и выводит различия.

### Какие реквизиты исключаются из сравнения?

По умолчанию исключаются служебные реквизиты: Ссылка, ПометкаУдаления, Предопределённый, Код, Номер и т.д.

### Как экспортировать результат сравнения?

Результат формируется в виде табличного документа. Вы можете сохранить его в форматах MXL или XLSX.

### Можно ли настроить список сравниваемых реквизитов?

Да, на форме обработки есть возможность выбрать конкретные реквизиты для сравнения.

### Что делать, если различий много?

Используйте фильтрацию по значимым реквизитам или экспортируйте результат в Excel для дальнейшего анализа.

## Решение проблем

## Проблемы

### Ошибка «Объекты разных типов»

Выберите два объекта одного типа метаданных. Нельзя сравнить, например, элемент справочника «Номенклатура» с документом «Реализация».

### Результат сравнения пустой

Убедитесь, что вы выбрали два разных объекта. Если выбраны одинаковые объекты, различий не будет. Проверьте, что сравниваются актуальные (не устаревшие) версии объектов.

### Не отображаются различия по табличным частям

Убедитесь, что у обоих объектов есть записи в табличных частях. Сравнение выполняется по равенству ключевых полей строк.

### Ошибка при получении объекта

Объект мог быть удалён из базы другим пользователем. Обновите список или введите актуальную ссылку.

### Сравнение выполняется слишком долго

Для объектов с большими табличными частями (сотни строк) время обработки может быть увеличено. Уменьшите количество сравниваемых реквизитов.

### Цветовое выделение не работает

Проверьте настройки табличного документа в используемой версии платформы. В некоторых режимах условное оформление может не поддерживаться.
