# Сравнение объектов

Сравнение ссылочных объектов по реквизитам с выводом в табличный документ.

## Назначение

- Сравнение двух объектов
- Выявление различий
- Проверка корректности изменений

## Особенности

- Сравнение по всем реквизитам
- Вывод различий в табличном виде
- Поддержка сложных типов

## Использование

1. Перейдите в меню **Универсальные инструменты → Сравнение объектов**
2. Выберите два объекта для сравнения
3. Нажмите **Сравнить**
4. Посмотрите различия
