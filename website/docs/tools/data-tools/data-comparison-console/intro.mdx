# Консоль сравнения данных

Сравнение данных из разных источников (1С, SQL, CSV, XML и др.).

## Назначение

- Сравнение данных из разных источников
- Поиск расхождений
- Интеграционное тестирование

## Особенности

- Поддержка множества источников данных
- Операции реляционной алгебры
- Гибкие настройки сравнения

## Поддерживаемые источники

- Текущая база 1С 8
- База 1С 7.7 (через COM)
- База данных SQL (MS SQL, PostgreSQL и др.)
- Файлы: CSV, TXT, DBF, XLS, DOC, XML
- Строка JSON
- Табличный документ, заполненный вручную

## Использование

1. Перейдите в меню **Универсальные инструменты → Консоль сравнения данных**
2. Выберите операцию реляционной алгебры
3. Настройте источники данных А и Б
4. Настройте условия сравнения
5. Нажмите **Сравнить данные**

## Инструкция

Подробная [PDF-инструкция](/docs/tools/data-tools/data-comparison-console/instruction) по работе с инструментом.

## Возможности

## Основные возможности

- **Сравнение данных из разных источников** — текущая база 1С, внешняя база через COM, SQL, CSV, TXT, DBF, XLS, XML, JSON.
- **Операции реляционной алгебры** — левое соединение, пересечение, полное внешнее соединение, разность и другие.
- **Гибкая настройка ключей сравнения** — указание количества столбцов в ключе, типов столбцов.
- **Условия вывода строк** — фильтрация результатов сравнения по любым полям.
- **Условия запрета вывода строк** — исключение определённых строк из результата.

## Поддерживаемые источники

- Текущая база 1С 8 (встроенный язык запросов).
- База 1С 7.7 (через COM-соединение, только файловая).
- База данных SQL (MS SQL, PostgreSQL, другие через ODBC).
- Файлы форматов: CSV, TXT, DBF, XLS, XML.
- Строка JSON.
- Табличный документ, заполненный на форме.

## Дополнительные возможности

- **Выгрузка результата** — сохранение таблицы расхождений в файл.
- **Настройка периода** — ограничение данных по дате.
- **Вывод типов столбцов ключа** — диагностика типов для отладки.
- **Контроль строк чтения** — ограничение количества обрабатываемых строк.

## Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Консоль сравнения данных**.
2. Выберите операцию реляционной алгебры (левое соединение, пересечение и т.д.) в верхней панели.
3. Настройте общие параметры: количество столбцов в ключе, период, путь выгрузки.
4. Настройте источник А: выберите тип (1С, SQL, файл и т.д.) и параметры подключения.
5. Настройте источник Б аналогично.
6. Настройте условия вывода и запрета вывода строк.
7. Нажмите **Сравнить данные** (F7).

## Сценарии

### Сравнение с внешней базой 1С через COM

```bsl
// Инициализация внешнего подключения
ВнешняяБаза = Новый COMОбъект("V81.COMConnector");
СтрокаПодключения = "File=""\\server\share\base"";Usr=Администратор;Pwd=;";
Соединение = ВнешняяБаза.Connect(СтрокаПодключения);
// Далее через обработку выполняется запрос к внешней базе
```

### Сравнение с SQL-таблицей

```bsl
// В обработке: источник Б — SQL
// Параметры:
// ТипСУБД = "MSSQLServer"
// Сервер = "localhost"
// База = "MyDatabase"
// Пользователь = "sa"
// Пароль = "***"
// ТекстЗапроса = "SELECT Code, Name FROM Products"
```

### Настройка периода

```bsl
// На вкладке «Общие настройки — Основные»
// установите даты начала и окончания периода
Параметры.Вставить("ДатаНачала", '20240101');
Параметры.Вставить("ДатаОкончания", '20240630');
```

## Часто задаваемые вопросы

## Общие вопросы

### Какие операции реляционной алгебры доступны?

Левое соединение, правое соединение, полное внешнее соединение, внутреннее соединение (пересечение), разность А \ Б, разность Б \ А, симметрическая разность.

### Можно ли сравнить данные из трёх источников?

Обработка поддерживает сравнение только двух источников за раз (А и Б). Для сравнения более двух источников выполните несколько сравнений.

### Как подключиться к 1С 7.7?

Укажите тип источника «1С 7.7 (COM)» и путь к файловой базе. Требуется установленная платформа 1С 7.7 на компьютере.

### Поддерживается ли PostgreSQL?

Да, поддерживаются любые СУБД с ODBC-драйвером: MS SQL, PostgreSQL, MySQL, Oracle и др.

### Как выгрузить результат сравнения?

Путь к файлу выгрузки укажите на вкладке «Общие настройки — Основные». Поддерживается формат табличного документа.

### Можно ли использовать обработку для синхронизации данных?

Нет, обработка только находит расхождения. Для синхронизации используйте соответствующие механизмы платформы (обмены данными).

### Что такое «столбцы ключа»?

Это поля, по которым сравниваются записи из источников А и Б. Например, при сравнении по коду товара ключом будет код.

## Решение проблем

## Проблемы

### Ошибка подключения к внешней базе 1С через COM

Убедитесь, что на компьютере установлена платформа 1С соответствующей версии. Проверьте строку подключения. Для файловых баз укажите полный путь к папке с базой.

### SQL-подключение не работает

Проверьте, установлен ли ODBC-драйвер для нужной СУБД. Убедитесь, что сервер доступен по сети, а имя пользователя и пароль корректны.

### Результат сравнения пустой

Проверьте, что в обоих источниках есть данные. Убедитесь, что ключи сравнения настроены правильно и существует хотя бы частичное совпадение данных.

### Ошибка при чтении CSV-файла

Проверьте кодировку файла и разделитель полей. В настройках источника укажите правильные параметры (разделитель, кодировка, наличие заголовков).

### Превышено время выполнения

Для больших объёмов данных установите ограничение на количество строк. Используйте более точные ключи и условия отбора.

### Ошибка «Неверный тип столбца ключа»

Убедитесь, что типы столбцов, используемых в ключе, совместимы в обоих источниках. Например, не сравнивайте строковое поле с числовым.
