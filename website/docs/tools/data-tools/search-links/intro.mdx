# Поиск ссылок на объект

Аналог стандартной обработки из меню «Все функции».

## Назначение

- Поиск ссылок на объект в других объектах
- Проверка зависимостей
- Подготовка к удалению объектов

## Особенности

- Поиск по всем объектам базы
- Просмотр цепочек ссылок
- Экспорт результатов

## Использование

1. Перейдите в меню **Универсальные инструменты → Поиск ссылок**
2. Выберите объект для поиска
3. Настройте параметры поиска
4. Посмотрите результат

## Возможности

## Основные возможности

- **Поиск ссылок на объект** — обнаружение всех объектов базы, которые ссылаются на указанный элемент.
- **Проверка зависимостей перед удалением** — выявление препятствий для удаления объекта.
- **Просмотр цепочек ссылок** — отслеживание ссылочной связности объектов.
- **Экспорт результатов** — выгрузка найденных ссылок в табличный документ.

## Дополнительные возможности

- **Поиск по всем объектам метаданных** — автоматический обход всех справочников, документов, регистров и других объектов.
- **Фильтрация по типу объекта** — ограничение поиска только нужными видами объектов.
- **Группировка по объектам-владельцам** — наглядное отображение найденных ссылок с группировкой.
- **Переход к найденным объектам** — открытие формы найденного объекта из результата.

## Интеграция

- Тесная интеграция с обработкой «Поиск и удаление дублей».
- Подготовка данных перед выгрузкой или удалением объектов.
- Аудит ссылочной целостности базы.

## Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Поиск ссылок**.
2. Выберите объект для поиска (справочник, документ и т.д.).
3. Настройте параметры поиска: по каким объектам искать.
4. Нажмите **Найти ссылки**.
5. Просмотрите результат — объекты, ссылающиеся на искомый.

## Сценарии

### Поиск ссылок перед удалением

```bsl
// Проверка, есть ли ссылки на элемент перед удалением
Ссылка = Справочники.Номенклатура.НайтиПоКоду("00-00123");
Если Не Ссылка.Пустая() Тогда
    Результат = Обработки.ПоискСсылокНаОбъект.НайтиСсылки(Ссылка);
    Если Результат.Количество() > 0 Тогда
        Сообщить("Найдено ссылок: " + Результат.Количество());
    Иначе
        Сообщить("Ссылок не найдено, можно удалять");
    КонецЕсли;
КонецЕсли;
```

### Получение списка объектов-владельцев

```bsl
// Программный вызов функциональности поиска
ПараметрыПоиска = Новый Структура;
ПараметрыПоиска.Вставить("Ссылка", СсылкаНаОбъект);
ПараметрыПоиска.Вставить("ИскатьВоВсехОбъектах", Истина);
Результаты = Обработки.ПоискСсылокНаОбъект.ВыполнитьПоиск(ПараметрыПоиска);
```

### Поиск с ограничением по типам

```bsl
// Поиск только в документах
ПараметрыПоиска.Вставить("ОбъектыПоиска", Новый Массив);
ПараметрыПоиска.ОбъектыПоиска.Добавить(Метаданные.Документы.РеализацияТоваровУслуг);
ПараметрыПоиска.ОбъектыПоиска.Добавить(Метаданные.Документы.СчетНаОплату);
Результаты = Обработки.ПоискСсылокНаОбъект.ВыполнитьПоиск(ПараметрыПоиска);
```

## Часто задаваемые вопросы

## Общие вопросы

### Какие объекты проверяются на ссылки?

Все объекты метаданных, содержащие реквизиты ссылочного типа: справочники, документы, регистры, обработки, планы счетов, планы видов расчёта и т.д.

### Можно ли найти ссылки в табличных частях?

Да, поиск выполняется в том числе по строкам табличных частей всех объектов.

### Как долго выполняется поиск?

Время зависит от объёма базы и количества проверяемых объектов. Для больших баз используйте фильтрацию по типам объектов.

### Как удалить объект, если на него есть ссылки?

Используйте обработку «Поиск и удаление дублей» или вручную замените ссылки через Редактор реквизитов объекта.

### Можно ли экспортировать результаты поиска?

Да, результаты можно выгрузить в табличный документ (MXL, XLSX) для дальнейшего анализа.

### Почему поиск не нашёл очевидные ссылки?

Убедитесь, что объекты поиска (документы, регистры) включены в параметры поиска. Проверьте, что поиск выполняется по всей базе, а не по выбранным объектам.

### Сколько объектов можно проверить за раз?

Ограничений нет. Для ускорения работы при большом количестве объектов используйте отбор по конкретным видам метаданных.

## Решение проблем

## Проблемы

### Поиск выполняется слишком долго

- Уменьшите количество объектов поиска, отключив ненужные типы.
- Используйте отбор по конкретным метаданным.
- Проверьте, не заблокирована ли база другими процессами.

### Ошибка «Недостаточно памяти»

Поиск ссылок по всем объектам большой базы может потребовать много памяти. Запустите поиск с ограничением по типам объектов.

### Результаты поиска пустые

Убедитесь, что выбранный объект существует в базе. Проверьте, что включены объекты для поиска. Некоторые объекты могут быть исключены из выборки функциональными опциями.

### Не отображаются ссылки из регистров

Регистры сведений и накопления обрабатываются отдельно. Убедитесь, что в параметрах поиска установлен флаг «Искать в регистрах».

### Ошибка «Неизвестный объект метаданных»

Объект мог быть изменён или удалён из конфигурации. Обновите метаданные через меню «Все функции — Обновить метаданные».

### Дублирование результатов

Если один документ содержит несколько ссылок на искомый объект, в результатах может быть несколько записей для одного документа. Группировка по объектам-владельцам позволяет объединить такие результаты.
