# Динамический список

Просмотр списков таблиц базы из одной обработки.

## Назначение

- Быстрый просмотр данных из любых таблиц базы
- Проверка содержимого таблиц
- Экспорт данных

## Особенности

- Выбор любой таблицы базы
- Фильтрация и сортировка
- Экспорт в табличный документ

## Использование

1. Перейдите в меню **Универсальные инструменты → Динамический список**
2. Выберите таблицу из списка
3. Настройте фильтр (если нужно)
4. Посмотрите результат

## Возможности

## Основные возможности

- **Просмотр любых таблиц базы** — доступ к таблицам справочников, документов, регистров и других объектов метаданных.
- **Динамический отбор** — настройка произвольных условий фильтрации по любым полям таблицы.
- **Сортировка данных** — упорядочивание записей по одному или нескольким полям.
- **Экспорт в табличный документ** — выгрузка результатов просмотра в формат MXL, XLSX, ODF.
- **Поиск по строке** — быстрый поиск значения в текущем списке.

## Дополнительные возможности

- **Иерархический просмотр** — отображение данных с учётом иерархии для справочников.
- **Настройка видимости колонок** — выбор отображаемых полей таблицы.
- **Отображение периодических регистров** — просмотр срезов на дату.
- **Копирование ячеек** — копирование выделенных значений в буфер обмена.

## Интеграция

- Экспорт данных для дальнейшего анализа.
- Просмотр содержимого таблиц перед выгрузкой через обмен.
- Быстрая проверка наличия записей в регистрах.

## Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Динамический список**.
2. В поле «Таблица» выберите нужный объект метаданных.
3. При необходимости настройте отбор по полям.
4. Нажмите **Сформировать** для отображения данных.

## Часто задаваемые вопросы

## Общие вопросы

### Можно ли увидеть данные регистров?

Да, динамический список поддерживает любые таблицы: справочники, документы, регистры сведений, накопления, бухгалтерии, расчёта.

### Почему список пустой, хотя данные есть?

Проверьте установленные отборы — возможно, условия фильтрации исключают все записи. Сбросьте отборы и повторите формирование.

### Можно ли редактировать данные через динамический список?

Нет, динамический список предназначен только для просмотра. Для редактирования используйте Редактор реквизитов объекта.

### Как увидеть срез последних для периодического регистра?

В настройках регистра выберите виртуальную таблицу «СрезПоследних» или установите флаг «Показывать последние».

### Поддерживается ли отбор по составным типам?

Да, отбор работает со всеми типами данных, включая составные поля и ссылочные типы.

### Как быстро найти конкретную запись?

Используйте поле поиска над таблицей — поиск выполняется по всем видимым колонкам.

## Решение проблем

## Проблемы

### Ошибка при выборе таблицы «Неизвестный объект метаданных»

Объект мог быть удалён из конфигурации или отключён в функциональных опциях. Обновите метаданные и переоткройте обработку.

### Не загружаются данные — ошибка временного отсутствия

Увеличьте время ожидания выполнения запроса на вкладке «Настройки». Проверьте соединение с сервером 1С.

### Экспорт в Excel даёт пустой файл

Убедитесь, что в таблице есть данные. При экспорте пустого динамического списка формируется пустой табличный документ.

### Не работает фильтрация по полю составного типа

Для составных полей указывайте конкретный тип в отборе. Например, если поле «Ответственный» может быть ссылкой на Пользователя или КонтактноеЛицо — укажите тип в параметре отбора.

### Ошибка при открытии формы «Поле не найдено»

Возникает, если состав таблицы изменился после обновления конфигурации. Закройте и откройте обработку заново.

### Медленная работа с регистрами большого объёма

Используйте отборы по ключевым полям. Для регистров накопления обязательно задавайте период и ограничивайте количество записей.
