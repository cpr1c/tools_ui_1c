# Возможности

## Основные возможности

- **Просмотр любых таблиц базы** — доступ к таблицам справочников, документов, регистров и других объектов метаданных.
- **Динамический отбор** — настройка произвольных условий фильтрации по любым полям таблицы.
- **Сортировка данных** — упорядочивание записей по одному или нескольким полям.
- **Экспорт в табличный документ** — выгрузка результатов просмотра в формат MXL, XLSX, ODF.
- **Поиск по строке** — быстрый поиск значения в текущем списке.

## Дополнительные возможности

- **Иерархический просмотр** — отображение данных с учётом иерархии для справочников.
- **Настройка видимости колонок** — выбор отображаемых полей таблицы.
- **Отображение периодических регистров** — просмотр срезов на дату.
- **Копирование ячеек** — копирование выделенных значений в буфер обмена.

## Интеграция

- Экспорт данных для дальнейшего анализа.
- Просмотр содержимого таблиц перед выгрузкой через обмен.
- Быстрая проверка наличия записей в регистрах.
