# Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Динамический список**.
2. В поле «Таблица» выберите нужный объект метаданных.
3. При необходимости настройте отбор по полям.
4. Нажмите **Сформировать** для отображения данных.

## Сценарии

### Просмотр остатков регистра накопления

```bsl
// Программный эквивалент формирования динамического списка
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
│   ТоварыНаСкладах.Номенклатура,
│   ТоварыНаСкладах.КоличествоОстаток
│ИЗ
│   РегистрНакопления.ТоварыНаСкладах.Остатки КАК ТоварыНаСкладах
│ГДЕ
│   ТоварыНаСкладах.КоличествоОстаток > 0";
```

### Поиск документов за период

```bsl
// В обработке: выберите документ, установите период и отбор
// Далее программно
Список = ЭлементыФормы.Список;
Список.УстановитьПараметр("ДатаНачала", НачалоМесяца(ТекущаяДата()));
Список.УстановитьПараметр("ДатаОкончания", КонецМесяца(ТекущаяДата()));
Список.Отбор["Проведен"].Установить(Истина);
```

### Экспорт в Excel

```bsl
ТабДок = ЭлементыФормы.Результат.Выгрузить();
ТабДок.Записать("Выгрузка.xlsx", ТипФайлаТабличногоДокумента.XLSX);
```
