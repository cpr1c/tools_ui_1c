# Редактор констант

Редактирование значений констант в режиме таблицы.

## Назначение

- Быстрое редактирование констант
- Массовое изменение значений
- Просмотр всех констант в одной таблице

## Особенности

- Редактирование в табличном виде
- Поддержка всех типов констант
- Проверка корректности изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор констант**
2. Откройте нужную константу
3. Отредактируйте значения
4. Сохраните изменения

## Возможности

## Основные возможности

- **Табличное редактирование** — просмотр и изменение всех констант конфигурации в удобном табличном виде.
- **Массовое изменение** — изменение значений нескольких констант за одну операцию.
- **Фильтрация по имени** — быстрый поиск нужной константы по наименованию.
- **Проверка корректности** — контроль типов вводимых значений согласно метаданным.
- **Сохранение изменений** — фиксация изменений одной кнопкой или откат при необходимости.

## Дополнительные возможности

- **Групповые операции** — установка одинакового значения для нескольких выбранных констант.
- **Отображение типа** — наглядное отображение типа данных каждой константы (Строка, Число, Дата, ХранилищеЗначения и т.д.).
- **Сортировка** — упорядочивание списка по имени, типу или значению.

## Безопасность

- Проверка прав доступа перед выполнением записи.
- Подтверждение изменений перед сохранением.
- Защита от случайного изменения системных констант.

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Редактор констант**.
2. В таблице отобразится список всех констант конфигурации.
3. Найдите нужную константу по имени или прокрутите список.
4. Отредактируйте значение в колонке «Значение».
5. Нажмите **Сохранить**.

## Сценарии

### Изменение одной константы

```bsl
// Программный аналог редактирования
Константа = Константы.НазваниеОрганизации.Получить();
Константы.НазваниеОрганизации.Установить("ООО «Новое название»");
```

### Массовое обновление через обработку

```bsl
// В обработке выберите несколько констант
// и установите общее значение
```

## Часто задаваемые вопросы

## Общие вопросы

### Какие типы констант поддерживаются?

Поддерживаются все типы данных, доступные для констант в платформе 1С: Число, Строка, Дата, Булево, ХранилищеЗначения, Ссылки и составные типы.

### Можно ли отменить изменения?

Да, до нажатия кнопки «Сохранить» можно закрыть форму без сохранения. После сохранения изменения фиксируются в базе.

### Почему не отображаются все константы?

Проверьте права доступа — пользователь должен иметь право на просмотр констант. Некоторые константы могут быть скрыты при настройке РИБ.

### Есть ли ограничение на длину строковой константы?

Ограничение определяется длиной строки в платформе 1С — до 1024 символов для констант метаданных.

### Можно ли редактировать константы, помеченные как «Не использовать»?

Да, они отображаются в списке и доступны для редактирования. Рекомендуется проявлять осторожность.

### Работает ли обработка в управляемом приложении?

Да, обработка полностью совместима с управляемыми формами и обычным приложением.

## Решение проблем

## Проблемы

### Значение не сохраняется

Проверьте, есть ли у пользователя права на запись констант. При работе в режиме управляемого приложения убедитесь, что форма активна.

### Ошибка «Значение поля не является значением этого типа»

Убедитесь, что вводимое значение соответствует типу константы. Например, в поле с типом «Число» нельзя ввести текст или дату.

### Не отображается список констант

- Проверьте, что обработка выполняется в контексте конфигурации, где есть константы.
- Убедитесь, что пользователь имеет права на чтение метаданных.
- При подключении через внешнее соединение передайте корректную ссылку на обработку.

### Ошибка при записи константы с типом «ХранилищеЗначения»

Такие константы редактируются только через специализированный интерфейс загрузки файла. В табличном виде их изменение может быть недоступно.

### Константа не найдена в списке, хотя существует в метаданных

Попробуйте обновить форму обработки. Некоторые константы могут не отображаться, если они принадлежат другому расширению или отключены в функциональных опциях.
