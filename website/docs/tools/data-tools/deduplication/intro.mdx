# Поиск и удаление дублей

Форк обработки из БСП с дополнительными параметрами замены.

## Назначение

- Поиск дублирующихся объектов
- Удаление дублей с заменой ссылок
- Объединение дублирующихся записей

## Особенности

- Настраиваемые критерии дублирования
- Автоматическая замена ссылок
- Предварительный просмотр результатов

## Использование

1. Перейдите в меню **Универсальные инструменты → Поиск и удаление дублей**
2. Выберите справочник
3. Настройте критерии поиска дублей
4. Выполните поиск и удаление

## Возможности

## Основные возможности

- **Поиск дублирующихся объектов** — обнаружение записей с одинаковыми значениями заданных полей.
- **Автоматическая замена ссылок** — замена ссылок с удаляемого дубля на оставляемый объект.
- **Объединение дублирующихся записей** — перенос данных из дубля в основной элемент.
- **Предварительный просмотр** — просмотр найденных дублей и предполагаемых результатов замены до выполнения.

## Дополнительные возможности

- **Настраиваемые критерии дублирования** — выбор полей для сравнения и порога совпадения.
- **Фильтрация по группам** — поиск дублей в определённой группе справочника.
- **Пакетная обработка** — последовательная обработка нескольких справочников.
- **Работа с произвольными справочниками** — любые справочники конфигурации.

## Безопасность

- Проверка ссылочной целостности перед удалением.
- Формирование отчёта о выполненных заменах.
- Возможность отката операций (при наличии резервной копии).
- Контроль прав доступа к объектам.

## Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Поиск и удаление дублей**.
2. Выберите справочник для поиска дублей.
3. Настройте критерии: укажите поля, по которым сравнивать.
4. Нажмите **Найти дубли**.
5. Просмотрите найденные дубли.
6. Выберите действие: удалить дубли с заменой или объединить.

## Сценарии

### Поиск дублей контрагентов по наименованию

```bsl
// Программный вызов поиска дублей
ПараметрыПоиска = Новый Структура;
ПараметрыПоиска.Вставить("Справочник", Метаданные.Справочники.Контрагенты);
ПараметрыПоиска.Вставить("ПоляСравнения", "Наименование, ИНН");
ПараметрыПоиска.Вставить("ИспользоватьПолноеСовпадение", Истина);
Результат = Обработки.ПоискИУдалениеДублей.НайтиДубли(ПараметрыПоиска);
```

### Поиск дублей по частичному совпадению

```bsl
ПараметрыПоиска.Вставить("ИспользоватьПолноеСовпадение", Ложь);
ПараметрыПоиска.Вставить("ПроцентСовпадения", 85);
Результат = Обработки.ПоискИУдалениеДублей.НайтиДубли(ПараметрыПоиска);
```

### Автоматическое удаление с заменой

```bsl
// После выбора основного и дублирующего элементов
Основной = Справочники.Номенклатура.НайтиПоКоду("00-00123");
Дубль = Справочники.Номенклатура.НайтиПоКоду("00-00456");
Обработки.ПоискИУдалениеДублей.УдалитьДубльСЗаменой(Дубль, Основной);
```

## Часто задаваемые вопросы

## Общие вопросы

### Какие справочники поддерживаются?

Любые справочники конфигурации, включая те, что добавлены расширениями. Иерархические и подчинённые справочники также поддерживаются.

### Что произойдёт со ссылками на удаляемый объект?

Ссылки во всех объектах базы будут автоматически заменены на оставляемый элемент. Проверка выполняется перед удалением.

### Можно ли восстановить удалённый дубль?

Прямое восстановление после удаления с заменой невозможно. Рекомендуется создавать резервную копию базы перед массовым удалением дублей.

### Как выбрать основной элемент из группы дублей?

Рекомендуется оставлять элемент с более полным заполнением реквизитов и наибольшим количеством ссылок в базе.

### Работает ли обработка с дублями в документах?

Нет, обработка предназначена для справочников. Поиск дублей документов не поддерживается.

### Можно ли настроить свои критерии сравнения?

Да, вы можете указать любые реквизиты справочника для сравнения и настроить порог совпадения.

### Как проверить результат до удаления?

Используйте режим предварительного просмотра — он покажет, какие связи будут заменены и какие объекты будут удалены.

## Решение проблем

## Проблемы

### Поиск дублей не находит очевидные совпадения

Проверьте критерии сравнения. Возможно, поля, по которым выполняется сравнение, содержат невидимые символы (пробелы, табуляция). Используйте частичное совпадение с высоким процентом.

### Ошибка при удалении дубля «Объект используется»

На удаляемый объект есть ссылки в документах или других справочниках. Обработка должна автоматически заменить ссылки. Если ошибка сохраняется, проверьте, что у пользователя есть права на запись объектов-владельцев ссылок.

### Замена ссылок не выполняется

Убедитесь, что не установлены блокировки объектов другими сеансами. Проверьте, что пользователь имеет полные права на все объекты, содержащие ссылки.

### Дубли не отображаются в списке после поиска

Возможно, для выбранного справочника не настроены критерии поиска. Установите хотя бы одно поле для сравнения.

### Ошибка «Недостаточно памяти» при поиске

Для справочников с большим количеством записей используйте поиск в пределах одной группы или с дополнительными фильтрами.

### После удаления дубля пропали данные в документах

Проверьте, что замена ссылок была выполнена корректно. Используйте отчёт о выполненной замене для анализа. При наличии резервной копии восстановите базу.
