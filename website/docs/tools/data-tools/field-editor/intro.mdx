# Редактор реквизитов объекта

Низкоуровневое редактирование ссылочных объектов, включая движения документов.

## Назначение

- Редактирование реквизитов объектов
- Просмотр и изменение движений
- Низкоуровневая отладка

## Особенности

- Редактирование всех реквизитов
- Просмотр движений документов
- История изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор реквизитов**
2. Выберите объект
3. Отредактируйте реквизиты
4. Сохраните изменения
