# Редактор реквизитов объекта

Низкоуровневое редактирование ссылочных объектов, включая движения документов.

## Назначение

- Редактирование реквизитов объектов
- Просмотр и изменение движений
- Низкоуровневая отладка

## Особенности

- Редактирование всех реквизитов
- Просмотр движений документов
- История изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор реквизитов**
2. Выберите объект
3. Отредактируйте реквизиты
4. Сохраните изменения

## Возможности

## Основные возможности

- **Низкоуровневое редактирование** — изменение любых реквизитов ссылочных объектов напрямую.
- **Просмотр и изменение движений документов** — редактирование записей регистров, формируемых документом.
- **Редактирование табличных частей** — добавление, изменение и удаление строк табличных частей.
- **Просмотр истории изменений** — отслеживание даты и автора последнего изменения объекта.
- **Работа с помеченными на удаление** — просмотр и редактирование объектов с пометкой удаления.

## Дополнительные возможности

- **Обход прав доступа** — возможность редактирования даже при отсутствии прав на форму объекта (требуются административные права).
- **Пакетное редактирование** — последовательное изменение нескольких объектов.
- **Копирование ссылки** — быстрый доступ к ссылке на объект в текстовом представлении.
- **Навигация по ссылкам** — переход по ссылочным реквизитам.

## Безопасность

- Все изменения фиксируются с указанием пользователя.
- Работа только в монопольном режиме для обеспечения целостности.
- Предупреждение о критических изменениях.

## Использование

## Быстрый старт

1. Перейдите в меню **Универсальные инструменты → Редактор реквизитов**.
2. Укажите ссылку на объект или выберите его из списка.
3. Отредактируйте нужные реквизиты.
4. Нажмите **Записать** для сохранения изменений.

## Сценарии

### Изменение реквизита объекта

```bsl
// Программный аналог через объектную модель
Объект = Справочники.Номенклатура.НайтиПоКоду("00-00123").ПолучитьОбъект();
Объект.Наименование = "Новое наименование";
Объект.Артикул = "АРТ-001";
Объект.Записать();
```

### Редактирование движений документа

```bsl
// Через обработку: выберите документ, перейдите на вкладку «Движения»
ДокументОбъект = Документы.РеализацияТоваровУслуг.НайтиПоНомеру("0001-000001").ПолучитьОбъект();
Набор = ДокументОбъект.Движения;
Если Набор.Количество() > 0 Тогда
    Набор[0].Количество = 10;
    Набор[0].Сумма = 1000;
    Набор.Записать();
КонецЕсли;
```

### Очистка табличной части

```bsl
// Удаление всех строк табличной части
Объект = Справочники.Номенклатура.НайтиПоКоду("00-00123").ПолучитьОбъект();
Объект.Составы.Очистить();
Объект.Записать();
```

## Часто задаваемые вопросы

## Общие вопросы

### Можно ли редактировать непроведённые документы?

Да, обработка работает с любыми объектами вне зависимости от состояния проведения.

### Безопасно ли редактировать движения напрямую?

Редактирование движений может нарушить целостность учёта. Рекомендуется только для отладки или исправления ошибок обмена.

### Почему некоторые реквизиты недоступны для редактирования?

Некоторые служебные реквизиты (Ссылка, ПометкаУдаления, Проведён и т.д.) заблокированы для редактирования через обработку.

### Работает ли обработка с иерархическими справочниками?

Да, обработка корректно отображает и позволяет редактировать элементы и группы иерархических справочников.

### Как увидеть автора последнего изменения?

На вкладке «История» отображается дата и пользователь, выполнивший последнюю запись объекта.

### Можно ли отменить изменения после записи?

Нет, после записи изменения фиксируются. Рекомендуется сохранять ссылки на объекты до начала редактирования.

## Решение проблем

## Проблемы

### Ошибка «Объект не найден» при вводе ссылки

Проверьте правильность ссылки. Для получения ссылки используйте «Скопировать ссылку» из контекстного меню объекта в форме списка.

### Изменения не сохраняются — «Недостаточно прав»

Обработка требует полных прав на запись объекта. Для обхода ограничений потребуются административные привилегии.

### Не отображаются движения документа

Убедитесь, что документ проведён. Для непроведённых документов движения формируются, но не записаны в базу. Проверьте, что у регистров есть записи для выбранного документа.

### Ошибка при записи «Запись не установлена»

Обработка работает только в установленном сеансе 1С. При подключении через внешнее соединение убедитесь, что передан корректный менеджер обработки.

### Не редактируется табличная часть

Табличная часть может быть недоступна, если она помечена как «Не использовать» в функциональных опциях. Проверьте, что объект не заблокирован другим пользователем.

### Значение реквизита сбрасывается после записи

Проверьте, не установлено ли для реквизита автоматическое заполнение при записи (например, через обработчики событий или подписки на события).
