# Возможности

## Основные возможности

- **Массовое изменение реквизитов** — изменение значений любых реквизитов справочников и документов по отбору.
- **Групповое удаление объектов** — удаление объектов с возможностью контроля ссылочной целостности.
- **Групповое перемещение в группу** — перемещение элементов справочников между группами.
- **Групповое копирование** — создание копий объектов с изменением заданных реквизитов.
- **Установка пометки удаления** — массовая установка и снятие пометки удаления.
- **Проведение и отмена проведений** — массовое проведение и отмена проведения документов.

## Дополнительные возможности

- **Гибкая фильтрация** — отбор объектов по произвольным условиям, дате, состоянию проведения.
- **Предварительный просмотр** — просмотр списка объектов, попадающих под обработку, до выполнения.
- **Работа в пакетном режиме** — выполнение нескольких операций последовательно.
- **Поддержка всех типов объектов** — любые справочники и документы конфигурации.

## Безопасность

- Контроль прав доступа при выполнении операций.
- Возможность отката изменений при ошибках.
- Журналирование всех выполненных действий.
