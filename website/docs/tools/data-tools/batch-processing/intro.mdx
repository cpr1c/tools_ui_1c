# Групповая обработка справочников и документов

Аналог типовой обработки с диска ИТС.

## Назначение

- Массовое изменение объектов справочников и документов
- Групповое удаление объектов
- Групповое перемещение объектов

## Особенности

- Поддержка всех типов объектов
- Фильтрация объектов
- Предварительный просмотр изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Групповая обработка**
2. Выберите объект (справочник или документ)
3. Настройте фильтр
4. Выберите действие и выполните

## Возможности

## Основные возможности

- **Массовое изменение реквизитов** — изменение значений любых реквизитов справочников и документов по отбору.
- **Групповое удаление объектов** — удаление объектов с возможностью контроля ссылочной целостности.
- **Групповое перемещение в группу** — перемещение элементов справочников между группами.
- **Групповое копирование** — создание копий объектов с изменением заданных реквизитов.
- **Установка пометки удаления** — массовая установка и снятие пометки удаления.
- **Проведение и отмена проведений** — массовое проведение и отмена проведения документов.

## Дополнительные возможности

- **Гибкая фильтрация** — отбор объектов по произвольным условиям, дате, состоянию проведения.
- **Предварительный просмотр** — просмотр списка объектов, попадающих под обработку, до выполнения.
- **Работа в пакетном режиме** — выполнение нескольких операций последовательно.
- **Поддержка всех типов объектов** — любые справочники и документы конфигурации.

## Безопасность

- Контроль прав доступа при выполнении операций.
- Возможность отката изменений при ошибках.
- Журналирование всех выполненных действий.

## Использование

## Быстрый старт

1. Откройте меню **Универсальные инструменты → Групповая обработка**.
2. Выберите вид объекта (справочник или документ) и конкретный объект метаданных.
3. Настройте отбор объектов при необходимости.
4. Выберите действие: изменить реквизиты, удалить, переместить и т.д.
5. Нажмите **Выполнить**.

## Сценарии

### Массовое изменение реквизита

```bsl
// Пример: установить ставку НДС 20% для всех номенклатур
ОбработкаОбъект = РеквизитФормыВЗначение("Объект");
ОбработкаОбъект.ВидОбъекта = "Справочник.Номенклатура";
ОбработкаОбъект.УстановитьРеквизит("СтавкаНДС", "20%");
ОбработкаОбъект.Выполнить();
```

### Групповое перемещение в группу

```bsl
// Перемещение выбранных элементов в новую группу
ОбработкаОбъект.НоваяГруппа = Справочники.Номенклатура.НайтиПоКоду("00-00123");
ОбработкаОбъект.ВыполнитьПеремещение();
```

### Массовое проведение документов за период

```bsl
// Проведение всех документов Реализация за январь
ОбработкаОбъект.ОбъектМетаданных = Метаданные.Документы.РеализацияТоваровУслуг;
ОбработкаОбъект.ДатаНачала = '20240101';
ОбработкаОбъект.ДатаОкончания = '20240131';
ОбработкаОбъект.ВыполнитьПроведение();
```

## Часто задаваемые вопросы

## Общие вопросы

### Можно ли отменить изменения после выполнения?

Нет, изменения применяются непосредственно к объектам базы данных. Рекомендуется перед массовыми операциями создавать резервную копию базы.

### Работает ли обработка с любыми справочниками?

Да, поддерживаются все виды справочников и документов, включая те, что добавлены расширениями.

### Есть ли ограничение на количество обрабатываемых объектов?

Ограничение определяется только производительностью сервера и временем выполнения. Для очень больших объёмов используйте отборы.

### Можно ли настроить несколько действий за один проход?

Да, используйте пакетный режим — вы можете добавить несколько операций, и они выполнятся последовательно.

### Как проверить, какие объекты попадут под обработку?

Используйте режим предварительного просмотра перед выполнением операции.

### Поддерживается ли обработка иерархических справочников?

Да, есть возможность обрабатывать элементы с учётом иерархии — только текущий уровень или все подчинённые.

## Решение проблем

## Проблемы

### Не отображается список объектов для выбора

Проверьте, что у пользователя есть права на чтение метаданных конфигурации. При работе через внешнее соединение убедитесь, что передан корректный контекст.

### Ошибка при выполнении операции «Недостаточно прав»

Убедитесь, что у пользователя есть права на изменение выбранных объектов. Для проведения документов требуются права на проведение.

### Операция выполняется слишком долго

- Используйте более точные отборы для уменьшения количества объектов.
- Проверьте нагрузку на сервер 1С.
- Разбейте операцию на несколько запусков по периодам.

### Некоторые объекты пропущены

Проверьте, не заблокированы ли объекты другими сеансами. Некоторые объекты могли быть исключены из выборки из-за прав доступа или установленных отборов.

### Ошибка «Объект не найден»

Возникает, если объект был удалён другим пользователем между формированием списка и выполнением операции. Обновите список и повторите попытку.
