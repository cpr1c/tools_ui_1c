# Групповая обработка справочников и документов

Аналог типовой обработки с диска ИТС.

## Назначение

- Массовое изменение объектов справочников и документов
- Групповое удаление объектов
- Групповое перемещение объектов

## Особенности

- Поддержка всех типов объектов
- Фильтрация объектов
- Предварительный просмотр изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Групповая обработка**
2. Выберите объект (справочник или документ)
3. Настройте фильтр
4. Выберите действие и выполните
