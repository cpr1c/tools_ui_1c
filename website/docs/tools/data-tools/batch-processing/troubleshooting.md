# Устранение неполадок

## Проблемы

### Не отображается список объектов для выбора

Проверьте, что у пользователя есть права на чтение метаданных конфигурации. При работе через внешнее соединение убедитесь, что передан корректный контекст.

### Ошибка при выполнении операции «Недостаточно прав»

Убедитесь, что у пользователя есть права на изменение выбранных объектов. Для проведения документов требуются права на проведение.

### Операция выполняется слишком долго

- Используйте более точные отборы для уменьшения количества объектов.
- Проверьте нагрузку на сервер 1С.
- Разбейте операцию на несколько запусков по периодам.

### Некоторые объекты пропущены

Проверьте, не заблокированы ли объекты другими сеансами. Некоторые объекты могли быть исключены из выборки из-за прав доступа или установленных отборов.

### Ошибка «Объект не найден»

Возникает, если объект был удалён другим пользователем между формированием списка и выполнением операции. Обновите список и повторите попытку.
