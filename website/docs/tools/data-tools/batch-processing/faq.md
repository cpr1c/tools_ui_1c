# FAQ

## Общие вопросы

### Можно ли отменить изменения после выполнения?

Нет, изменения применяются непосредственно к объектам базы данных. Рекомендуется перед массовыми операциями создавать резервную копию базы.

### Работает ли обработка с любыми справочниками?

Да, поддерживаются все виды справочников и документов, включая те, что добавлены расширениями.

### Есть ли ограничение на количество обрабатываемых объектов?

Ограничение определяется только производительностью сервера и временем выполнения. Для очень больших объёмов используйте отборы.

### Можно ли настроить несколько действий за один проход?

Да, используйте пакетный режим — вы можете добавить несколько операций, и они выполнятся последовательно.

### Как проверить, какие объекты попадут под обработку?

Используйте режим предварительного просмотра перед выполнением операции.

### Поддерживается ли обработка иерархических справочников?

Да, есть возможность обрабатывать элементы с учётом иерархии — только текущий уровень или все подчинённые.
