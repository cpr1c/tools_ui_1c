# Менеджер открытых форм

Перехват открытых окон, информация о формах, открытие системных форм. Форк [ManagerOpenForms](https://github.com/SeiOkami/ManagerOpenForms) с разрешения авторов.

## Назначение

- Просмотр открытых форм
- Информация о формах
- Открытие системных форм

## Особенности

- Список всех открытых форм
- Информация о параметрах форм
- Возможность открытия системных форм

## Использование

1. Перейдите в меню **Универсальные инструменты → Менеджер открытых форм**
2. Посмотрите список открытых форм
3. Выберите форму для просмотра информации
4. Откройте системную форму при необходимости
