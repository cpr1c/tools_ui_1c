# Менеджер открытых форм

Перехват открытых окон, информация о формах, открытие системных форм. Форк [ManagerOpenForms](https://github.com/SeiOkami/ManagerOpenForms) с разрешения авторов.

## Назначение

- Просмотр открытых форм
- Информация о формах
- Открытие системных форм

## Особенности

- Список всех открытых форм
- Информация о параметрах форм
- Возможность открытия системных форм

## Использование

1. Перейдите в меню **Универсальные инструменты → Менеджер открытых форм**
2. Посмотрите список открытых форм
3. Выберите форму для просмотра информации
4. Откройте системную форму при необходимости

## Возможности

## Основные возможности

- **Просмотр всех открытых форм** — отображение списка всех окон, открытых в текущем сеансе;
- **Информация о форме** — детальные сведения о выбранной форме: владелец, параметры, реквизиты, команды;
- **Открытие системных форм** — доступ к служебным формам 1С: журналы регистрации, монитор производительности, список пользователей и другие.

## Режимы работы

- **Активные формы** — только формы, открытые в данный момент;
- **Все формы** — включая скрытые и служебные формы;
- **Поиск** — фильтрация списка по имени формы или объекта.

## Отображаемая информация

- Имя формы и её синоним;
- Имя объекта-владельца;
- Режим открытия (основной, вспомогательный);
- Состояние (активна, свернута, скрыта);
- Параметры, переданные при открытии;
- Список реквизитов и команд формы.

## Управление формами

- Переключение фокуса на выбранную форму;
- Закрытие формы из списка;
- Обновление информации о форме в реальном времени.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Менеджер открытых форм**.

## Просмотр открытых форм

Сразу после открытия обработка отображает список всех форм текущего сеанса. Для обновления списка используйте кнопку **Обновить**.

## Детальная информация

Выберите форму в списке. В нижней части отобразится подробная информация:

- **Параметры формы** — значения, переданные при открытии;
- **Реквизиты** — основные и дополнительные реквизиты формы;
- **Команды** — список доступных команд формы.

## Открытие системной формы

1. Нажмите **Открыть системную форму**;
2. Выберите нужную форму из предложенного списка;
3. Форма откроется в отдельном окне.

## Программное использование

```bsl
// Получение списка открытых форм через общий модуль
Формы = УИ_Отладка.ПолучитьСписокОткрытыхФорм();
Для Каждого Форма Из Формы Цикл
    Сообщить(Форма.ИмяФормы + " - " + Форма.Заголовок);
КонецЦикла;
```

## Закрытие формы

Выберите форму в списке и нажмите **Закрыть**. Форма будет закрыта программно.

## Часто задаваемые вопросы

## Почему некоторые формы не отображаются в списке?

Модальные окна и диалоги могут не отображаться, если они открыты в отдельном потоке или с особыми флагами. Нажмите **Обновить** для перезагрузки списка.

## Можно ли открыть форму, которая уже открыта?

Да. Обработка позволяет переключиться на уже открытую форму, передав ей фокус. Повторное открытие той же формы может создать дубликат.

## Какие системные формы доступны для открытия?

Журнал регистрации, монитор производительности, список активных пользователей, окно настроек, панель сообщений и другие служебные формы 1С.

## Безопасно ли закрывать формы через менеджер?

Да, закрытие формы программно аналогично закрытию через стандартный интерфейс. Однако не рекомендуется закрывать системные служебные формы.

## Работает ли в веб-клиенте?

Полный функционал доступен в тонком клиенте. В веб-клиенте возможны ограничения на получение списка форм из-за особенностей безопасности браузеров.

## Решение проблем

## Список форм пуст

Обновите список кнопкой **Обновить**. Если список остаётся пустым, возможно, подсистема мониторинга форм неактивна. Проверьте настройки подсистемы УИ_Отладка.

## Не открывается системная форма

Убедитесь, что у текущего пользователя есть права на открытие данной системной формы. Некоторые системные формы доступны только администраторам.

## Информация о форме неполная

Параметры, реквизиты и команды могут отображаться не полностью, если форма защищена от внешнего доступа. Это нормальное поведение для некоторых типов форм.

## Не удаётся закрыть форму

Форма может быть защищена от программного закрытия (например, главное окно программы). Попробуйте закрыть её штатным способом.

## Ошибка при получении списка

Возникает в веб-клиенте при ограничении прав безопасности. Используйте тонкий клиент для полного функционала.
