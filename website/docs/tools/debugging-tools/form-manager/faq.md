# FAQ

## Почему некоторые формы не отображаются в списке?

Модальные окна и диалоги могут не отображаться, если они открыты в отдельном потоке или с особыми флагами. Нажмите **Обновить** для перезагрузки списка.

## Можно ли открыть форму, которая уже открыта?

Да. Обработка позволяет переключиться на уже открытую форму, передав ей фокус. Повторное открытие той же формы может создать дубликат.

## Какие системные формы доступны для открытия?

Журнал регистрации, монитор производительности, список активных пользователей, окно настроек, панель сообщений и другие служебные формы 1С.

## Безопасно ли закрывать формы через менеджер?

Да, закрытие формы программно аналогично закрытию через стандартный интерфейс. Однако не рекомендуется закрывать системные служебные формы.

## Работает ли в веб-клиенте?

Полный функционал доступен в тонком клиенте. В веб-клиенте возможны ограничения на получение списка форм из-за особенностей безопасности браузеров.
