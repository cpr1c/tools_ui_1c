# Инструменты отладки

Раздел **Отладка** содержит инструменты для исследования данных и управления сеансом разработки.

## Содержание

- [Данные для отладки](/docs/tools/debugging-tools/debug-data) — сохранение объектов отладки
- [Просмотр значения](/docs/tools/debugging-tools/value-viewer) — вычисление выражений и исследование значений любых типов
- [Менеджер открытых форм](/docs/tools/debugging-tools/form-manager) — управление формами
- [Редактор временного хранилища](/docs/tools/debugging-tools/temp-storage-editor) — временное хранилище

## Программный вызов отладки

Основной способ быстрого доступа к инструментам — вызов из отладчика:

```bsl
УИ_._От(Запрос)
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД)
УИ_._От(HTTPЗапрос, СоединениеHTTP)
```

Подробнее: [Отладка из кода](/docs/guides/debugging).

## Отладка внешних обработок БСП

Для дополнительных отчётов и обработок БСП доступна настройка отладки с диска. См. [Отладка внешних обработок БСП](/docs/guides/debugging-bsp-external).
