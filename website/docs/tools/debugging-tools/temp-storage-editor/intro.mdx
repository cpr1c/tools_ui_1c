# Редактор временного хранилища

Просмотр, правка и помещение данных во временное хранилище 1С.

## Назначение

- Просмотр данных во временном хранилище
- Редактирование значений
- Помещение новых данных

## Особенности

- Поддержка всех типов временного хранилища
- Редактирование значений
- История изменений

## Использование

1. Перейдите в меню **Универсальные инструменты → Редактор временного хранилища**
2. Посмотрите данные во временном хранилище
3. Отредактируйте или добавьте данные
4. Сохраните изменения

## Возможности

## Основные возможности

- **Просмотр временного хранилища** — отображение всех адресов временного хранилища текущего сеанса;
- **Редактирование значений** — изменение данных, размещённых во временном хранилище;
- **Помещение новых данных** — добавление произвольных значений по указанному адресу.

## Поддерживаемые операции

- **Чтение** — получение значения по адресу временного хранилища;
- **Запись** — помещение нового значения с перезаписью существующего;
- **Удаление** — очистка конкретного адреса хранилища;
- **Очистка всех** — удаление всех временных данных сеанса.

## Поддерживаемые типы данных

- Примитивные типы (Строка, Число, Дата, Булево);
- Двоичные данные (ДвоичныеДанные, Картинка);
- Таблицы значений, деревья значений;
- Структуры, соответствия, массивы;
- Хранилища значений (ValueStorage).

## Интерфейс

- Удобная таблица с адресами хранилищ и типами значений;
- Встроенный редактор для просмотра и изменения содержимого;
- Возможность помещения данных из файла.

## Интеграция

- Прямая интеграция с [Просмотром значения](/docs/tools/debugging-tools/value-viewer);
- Сохранение истории изменений.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Редактор временного хранилища**.

## Просмотр данных

После открытия обработка автоматически загружает список всех адресов временного хранилища текущего сеанса. Выберите строку для просмотра значения в нижней панели.

## Редактирование данных

1. Выберите адрес хранилища;
2. Нажмите **Редактировать** или дважды кликните по строке;
3. Измените данные в редакторе;
4. Нажмите **Сохранить**.

## Помещение новых данных

```bsl
// Размещение данных в хранилище программно
Адрес = ПоместитьВоВременноеХранилище(Новый Массив);
Сообщить("Адрес: " + Адрес);

// Размещение с указанием адреса
Данные = Новый Структура("Ключ, Значение", "Параметр1", 123);
Адрес = ПоместитьВоВременноеХранилище(Данные, УникальныйИдентификатор);
```

## Помещение данных из редактора

1. Введите или вставьте данные в поле редактора;
2. Укажите адрес (или оставьте пустым для автоматической генерации);
3. Нажмите **Поместить**.

## Удаление данных

Выберите адрес и нажмите **Удалить**. Для полной очистки используйте **Очистить всё**.

## Часто задаваемые вопросы

## Какие адреса отображаются?

Отображаются все адреса временного хранилища, созданные в текущем сеансе, включая системные (например, адреса, возвращаемые при размещении картинок и двоичных данных).

## Можно ли редактировать данные, помещённые другими обработками?

Да, все данные временного хранилища в рамках одного сеанса доступны для просмотра и редактирования, независимо от того, какая обработка их разместила.

## Безопасно ли редактировать данные?

Редактирование данных временного хранилища может повлиять на работу открытых форм и обработок, использующих эти данные. Будьте внимательны при изменении.

## Почему я не вижу данные?

Временное хранилище привязано к текущему сеансу. Если данные были размещены в другом сеансе (например, фоновым заданием), они не будут отображаться.

## Можно ли сохранить данные из временного хранилища в файл?

Да. Выберите адрес и нажмите **Сохранить в файл**. Данные будут сохранены в формате, соответствующем их типу.

## Поддерживается ли поиск по адресу?

Да, используйте поле поиска в верхней части списка. Поиск работает по частичному совпадению адреса.

## Решение проблем

## Ошибка «Адрес не найден»

Указанный адрес не существует в хранилище текущего сеанса. Проверьте правильность адреса. Адреса временного хранилища действительны только в рамках одного сеанса.

## Не удаётся изменить значение

Проверьте, что новый тип данных соответствует ожидаемому типу. Некоторые значения могут быть защищены от изменений (например, если они используются активной формой).

## Ошибка при помещении данных

Убедитесь, что данные могут быть сериализованы. Некоторые COM-объекты и внешние объекты не поддерживают помещение во временное хранилище.

## Список пуст после открытия

Убедитесь, что в текущем сеансе есть данные во временном хранилище. Создайте тестовые данные через консоль кода для проверки.

## Ошибка «Недостаточно прав»

Временное хранилище доступно только в рамках текущего сеанса. Проверьте, что вы работаете в том же сеансе, где были размещены данные. Данные доступа ролями не регулируются.
