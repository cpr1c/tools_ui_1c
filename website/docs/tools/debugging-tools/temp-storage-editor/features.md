# Возможности

## Основные возможности

- **Просмотр временного хранилища** — отображение всех адресов временного хранилища текущего сеанса;
- **Редактирование значений** — изменение данных, размещённых во временном хранилище;
- **Помещение новых данных** — добавление произвольных значений по указанному адресу.

## Поддерживаемые операции

- **Чтение** — получение значения по адресу временного хранилища;
- **Запись** — помещение нового значения с перезаписью существующего;
- **Удаление** — очистка конкретного адреса хранилища;
- **Очистка всех** — удаление всех временных данных сеанса.

## Поддерживаемые типы данных

- Примитивные типы (Строка, Число, Дата, Булево);
- Двоичные данные (ДвоичныеДанные, Картинка);
- Таблицы значений, деревья значений;
- Структуры, соответствия, массивы;
- Хранилища значений (ValueStorage).

## Интерфейс

- Удобная таблица с адресами хранилищ и типами значений;
- Встроенный редактор для просмотра и изменения содержимого;
- Возможность помещения данных из файла.

## Интеграция

- Прямая интеграция с [Просмотром значения](/docs/tools/debugging-tools/value-viewer);
- Сохранение истории изменений.
