# Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Просмотр значения**.

## Вычисление выражения

1. Введите выражение на встроенном языке 1С в поле ввода;
2. Нажмите **Вычислить** (или клавишу Enter);
3. Просмотрите результат в нижней панели.

## Примеры выражений

```bsl
// Просмотр конкретного объекта
Справочники.Номенклатура.НайтиПоКоду("00-0001")

// Просмотр системной информации
Метаданные.Справочники.Номенклатура.Реквизиты

// Вычисление набора данных
Новый Массив

// Работа с контекстом
ПараметрыСеанса.ТекущийПользователь

// Дерево значений
Новый ДеревоЗначений
```

## Навигация по результату

- Щёлкните по ссылочному полю для перехода к объекту;
- Раскройте строку таблицы для просмотра колонок;
- Используйте контекстное меню для копирования значения.

## Сохранение результата

Нажмите **Сохранить в данных отладки**, чтобы сохранить результат для последующего просмотра или передачи другому разработчику.
