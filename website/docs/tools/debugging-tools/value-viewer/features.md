# Возможности

## Основные возможности

- **Просмотр значений произвольных типов** — аналог окна «Вычислить выражение» штатного отладчика 1С;
- **Просмотр свойств и методов** — детальный анализ структуры объекта с возможностью навигации по вложенным свойствам;
- **История вычислений** — автоматическое сохранение введённых выражений с результатами.

## Поддерживаемые типы

- **Примитивные типы** — Строка, Число, Дата, Булево;
- **Ссылочные типы** — ссылки на справочники, документы, регистры;
- **Коллекции** — Массив, Структура, Соответствие, СписокЗначений, ТаблицаЗначений, ДеревоЗначений;
- **Специализированные** — ValueStorage, ХранилищеЗначения, COM-объекты.

## Визуализация данных

- Отображение структуры таблиц и деревьев значений в удобном табличном виде;
- Просмотр реквизитов ссылочных объектов;
- Рекурсивный просмотр вложенных свойств с контролем глубины.

## Дополнительно

- Копирование результатов в буфер обмена;
- Сохранение результата в [Данные для отладки](/docs/tools/debugging-tools/debug-data);
- Поддержка выражений произвольной сложности.
