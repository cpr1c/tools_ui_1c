# Устранение неполадок

## Ошибка при вычислении выражения

Проверьте синтаксис выражения. Убедитесь, что все используемые функции и переменные существуют в данном контексте. В консоли отладки недоступны локальные переменные вызывающего кода.

## Результат не отображается

Возможно, выражение возвращает неопределённое значение (Null/Неопределено). Убедитесь, что выражение возвращает осмысленный результат, выполнив его в штатном отладчике.

## Долгое вычисление

Выражения, обращающиеся к большим объёмам данных (например, `ВесьСправочник.Выбрать()`), могут выполняться долго. Ограничьте выборку с помощью условия.

## Некорректное отображение таблицы

Для табличных значений убедитесь, что колонки имеют корректные имена. Безымянные колонки могут отображаться как «Колонка1», «Колонка2» и т.д.

## Невозможно просмотреть свойство объекта

Объект может не иметь публичных свойств или доступ к свойству закрыт модификатором доступа. Используйте `ЗначениеВСтрокуВнутр()` для диагностики.
