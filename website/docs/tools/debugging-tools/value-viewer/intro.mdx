# Просмотр значения

Просмотр значений и свойств произвольных типов — аналог «Вычислить выражение» отладчика.

## Назначение

- Просмотр значений переменных
- Анализ свойств объектов
- Быстрая отладка выражений

## Особенности

- Поддержка всех типов значений 1С
- Визуализация сложных структур
- История вычислений

## Использование

1. Перейдите в меню **Универсальные инструменты → Просмотр значения**
2. Введите выражение для вычисления
3. Нажмите **Вычислить**
4. Посмотрите результат

## Связанные разделы

- [Отладка из кода](/docs/guides/debugging) — программный вызов отладки

## Возможности

## Основные возможности

- **Просмотр значений произвольных типов** — аналог окна «Вычислить выражение» штатного отладчика 1С;
- **Просмотр свойств и методов** — детальный анализ структуры объекта с возможностью навигации по вложенным свойствам;
- **История вычислений** — автоматическое сохранение введённых выражений с результатами.

## Поддерживаемые типы

- **Примитивные типы** — Строка, Число, Дата, Булево;
- **Ссылочные типы** — ссылки на справочники, документы, регистры;
- **Коллекции** — Массив, Структура, Соответствие, СписокЗначений, ТаблицаЗначений, ДеревоЗначений;
- **Специализированные** — ValueStorage, ХранилищеЗначения, COM-объекты.

## Визуализация данных

- Отображение структуры таблиц и деревьев значений в удобном табличном виде;
- Просмотр реквизитов ссылочных объектов;
- Рекурсивный просмотр вложенных свойств с контролем глубины.

## Дополнительно

- Копирование результатов в буфер обмена;
- Сохранение результата в [Данные для отладки](/docs/tools/debugging-tools/debug-data);
- Поддержка выражений произвольной сложности.

## Использование

## Запуск обработки

Откройте меню **Универсальные инструменты → Просмотр значения**.

## Вычисление выражения

1. Введите выражение на встроенном языке 1С в поле ввода;
2. Нажмите **Вычислить** (или клавишу Enter);
3. Просмотрите результат в нижней панели.

## Примеры выражений

```bsl
// Просмотр конкретного объекта
Справочники.Номенклатура.НайтиПоКоду("00-0001")

// Просмотр системной информации
Метаданные.Справочники.Номенклатура.Реквизиты

// Вычисление набора данных
Новый Массив

// Работа с контекстом
ПараметрыСеанса.ТекущийПользователь

// Дерево значений
Новый ДеревоЗначений
```

## Навигация по результату

- Щёлкните по ссылочному полю для перехода к объекту;
- Раскройте строку таблицы для просмотра колонок;
- Используйте контекстное меню для копирования значения.

## Сохранение результата

Нажмите **Сохранить в данных отладки**, чтобы сохранить результат для последующего просмотра или передачи другому разработчику.

## Часто задаваемые вопросы

## Какие выражения можно вводить?

Любые корректные выражения на встроенном языке 1С. Поддерживаются системные функции, глобальный контекст, обращения к данным базы и метаданным.

## Можно ли изменять значения свойств объектов?

Нет, инструмент предназначен только для просмотра. Для изменения используйте штатные механизмы 1С или редактор временного хранилища.

## Почему в результатах отображаются не все свойства?

Глубина рекурсивного просмотра ограничена настройками (по умолчанию 5 уровней). Увеличьте глубину в настройках обработки.

## Поддерживается ли просмотр COM-объектов?

Да, поддерживается. Однако структура COM-объекта может отображаться не полностью из-за особенностей COM-интерфейса.

## Сохраняется ли история выражений?

Да, история автоматически сохраняется между сеансами. Вы можете очистить историю в настройках обработки. Для удаления отдельных записей используйте кнопку очистки в панели истории.

## Решение проблем

## Ошибка при вычислении выражения

Проверьте синтаксис выражения. Убедитесь, что все используемые функции и переменные существуют в данном контексте. В консоли отладки недоступны локальные переменные вызывающего кода.

## Результат не отображается

Возможно, выражение возвращает неопределённое значение (Null/Неопределено). Убедитесь, что выражение возвращает осмысленный результат, выполнив его в штатном отладчике.

## Долгое вычисление

Выражения, обращающиеся к большим объёмам данных (например, `ВесьСправочник.Выбрать()`), могут выполняться долго. Ограничьте выборку с помощью условия.

## Некорректное отображение таблицы

Для табличных значений убедитесь, что колонки имеют корректные имена. Безымянные колонки могут отображаться как «Колонка1», «Колонка2» и т.д.

## Невозможно просмотреть свойство объекта

Объект может не иметь публичных свойств или доступ к свойству закрыт модификатором доступа. Используйте `ЗначениеВСтрокуВнутр()` для диагностики.
