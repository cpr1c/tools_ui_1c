# FAQ

## Какие выражения можно вводить?

Любые корректные выражения на встроенном языке 1С. Поддерживаются системные функции, глобальный контекст, обращения к данным базы и метаданным.

## Можно ли изменять значения свойств объектов?

Нет, инструмент предназначен только для просмотра. Для изменения используйте штатные механизмы 1С или редактор временного хранилища.

## Почему в результатах отображаются не все свойства?

Глубина рекурсивного просмотра ограничена настройками (по умолчанию 5 уровней). Увеличьте глубину в настройках обработки.

## Поддерживается ли просмотр COM-объектов?

Да, поддерживается. Однако структура COM-объекта может отображаться не полностью из-за особенностей COM-интерфейса.

## Сохраняется ли история выражений?

Да, история автоматически сохраняется между сеансами. Вы можете очистить историю в настройках обработки. Для удаления отдельных записей используйте кнопку очистки в панели истории.
