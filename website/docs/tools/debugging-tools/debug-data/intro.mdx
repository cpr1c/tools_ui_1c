# Данные для отладки

Справочник с сохранёнными объектами отладки (запросы, СКД, HTTP и др.) для тонкого/веб-клиента.

## Назначение

- Сохранение объектов отладки
- Просмотр истории отладки
- Восстановление объектов отладки

## Особенности

- Сохранение в справочнике
- Поддержка всех типов объектов отладки
- Доступ из тонкого и веб-клиента

## Использование

1. Перейдите в меню **Универсальные инструменты → Данные для отладки**
2. Посмотрите сохраненные объекты
3. Выберите объект и откройте его

## Связанные разделы

- [Отладка из кода](/docs/guides/debugging) — программный вызов отладки

## Возможности

## Основные возможности

- **Сохранение объектов отладки** — сохранение запросов, СКД, HTTP-запросов и других объектов для последующего анализа;
- **Просмотр истории отладки** — доступ к ранее сохранённым объектам с фильтрацией по дате и типу;
- **Восстановление объектов** — повторное открытие сохранённых объектов для анализа или доработки.

## Поддерживаемые объекты отладки

- **Запросы** — сохранение текста запроса, параметров и результата выполнения;
- **Схемы компоновки данных** — сохранение настроек СКД, вариантов и расшифровок;
- **HTTP-запросы и ответы** — сохранение URL, заголовков, тела запроса и ответа;
- **Произвольные структуры** — любые значения, переданные из кода разработчиком.

## Удобный интерфейс

- Список с группировкой по типу объекта;
- Быстрый поиск по наименованию и дате;
- Предварительный просмотр содержимого без открытия.

## Интеграция с подсистемой отладки

- Программное сохранение объектов через общие модули подсистемы;
- Автоматическое сохранение при возникновении исключений;
- Интеграция с [Просмотром значения](/docs/tools/debugging-tools/value-viewer).

## Использование

## Запуск справочника

Откройте меню **Универсальные инструменты → Данные для отладки**.

## Просмотр сохранённых объектов

В форме списка отображаются все сохранённые объекты. Используйте отбор по типу объекта или дате для быстрого поиска.

## Программное сохранение объекта

```bsl
// Сохранение результата запроса в данные отладки
Запрос = Новый Запрос(
    "ВЫБРАТЬ
    |   Номенклатура.Наименование,
    |   Номенклатура.Код
    |ИЗ
    |   Справочник.Номенклатура КАК Номенклатура
    |ГДЕ
    |   Номенклатура.ЭтоГруппа = Ложь");
Результат = Запрос.Выполнить();

// Программное сохранение через общий модуль
УИ_Отладка.СохранитьОбъектОтладки(
    "Запрос номенклатуры",
    Результат);
```

```bsl
// Сохранение произвольных данных
Данные = Новый Структура;
Данные.Вставить("Параметр1", "Значение1");
Данные.Вставить("Параметр2", 123);

УИ_Отладка.СохранитьОбъектОтладки(
    "Тестовые данные",
    Данные);
```

## Открытие сохранённого объекта

Выберите строку в списке и нажмите **Открыть**. Объект откроется в соответствующем редакторе.

## Часто задаваемые вопросы

## Какие объекты можно сохранять?

Любые значения 1С: результат запроса, набор записей регистра, таблица значений, дерево значений, структура, соответствие, массив, а также специализированные объекты — схемы СКД, HTTP-сервисы, настройки компоновки.

## Не теряются ли данные при обновлении конфигурации?

Справочник **Данные для отладки** сохраняется при обновлении конфигурации, если он помечен для сохранения при обновлении. Однако рекомендуется периодически экспортировать важные данные.

## Можно ли очистить историю?

Да. Используйте кнопку **Очистить историю** или удалите ненужные записи вручную. Можно настроить автоматическую очистку записей старше N дней.

## Как передать объект отладки другому разработчику?

Объекты хранятся в справочнике внутри базы. Для передачи выгрузите элемент справочника в XML через стандартную выгрузку 1С или скопируйте данные через буфер обмена.

## Есть ли ограничение на размер сохраняемых данных?

Ограничения нет, но рекомендуется не сохранять объекты размером более 10 МБ во избежание замедления работы справочника.

## Решение проблем

## Объект не сохраняется

Проверьте, что тип значения поддерживается для сохранения. Некоторые COM-объекты и внешние объекты не могут быть сериализованы.

## Не открывается сохранённый объект

Возможно, объект был сохранён в старой версии конфигурации и формат данных изменился. Попробуйте открыть через универсальный механизм или обратитесь к разработчику.

## Справочник пуст

Убедитесь, что в вашей версии подсистемы реализовано программное сохранение объектов. Проверьте, что код сохранения действительно вызывается.

## Долго открывается список

При большом количестве сохранённых объектов (более 1000) может наблюдаться замедление. Используйте отборы по типу и дате, либо настройте автоматическую очистку старых записей.

## Ошибка при открытии результата запроса

Возможно, структура результата не соответствует ожидаемой. Попробуйте сохранять результат в виде таблицы значений через `Результат.Выгрузить()`.
