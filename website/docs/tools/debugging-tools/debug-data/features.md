# Возможности

## Основные возможности

- **Сохранение объектов отладки** — сохранение запросов, СКД, HTTP-запросов и других объектов для последующего анализа;
- **Просмотр истории отладки** — доступ к ранее сохранённым объектам с фильтрацией по дате и типу;
- **Восстановление объектов** — повторное открытие сохранённых объектов для анализа или доработки.

## Поддерживаемые объекты отладки

- **Запросы** — сохранение текста запроса, параметров и результата выполнения;
- **Схемы компоновки данных** — сохранение настроек СКД, вариантов и расшифровок;
- **HTTP-запросы и ответы** — сохранение URL, заголовков, тела запроса и ответа;
- **Произвольные структуры** — любые значения, переданные из кода разработчиком.

## Удобный интерфейс

- Список с группировкой по типу объекта;
- Быстрый поиск по наименованию и дате;
- Предварительный просмотр содержимого без открытия.

## Интеграция с подсистемой отладки

- Программное сохранение объектов через общие модули подсистемы;
- Автоматическое сохранение при возникновении исключений;
- Интеграция с [Просмотром значения](/docs/tools/debugging-tools/value-viewer).
