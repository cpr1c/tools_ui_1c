# Доработка через Конфигуратор

Инструкция для тех, кто предпочитает работать в Конфигураторе 1С.

## Необходимое ПО

1. Платформа 1С версии 8.3.12 и выше
2. БСП последней версии с режимом совместимости 8.3.12 (например, 3.0.3.341)

## Правила

1. Поищите задачу в [GitHub Issues](https://github.com/cpr1c/tools_ui_1c/issues)
2. Если задачи нет — создайте новую, опишите требования и обсудите реализацию
3. Возьмите версию из **актуального релиза** на момент старта разработки. Скачайте файл полной версии `UI.cfe`
4. Выполните необходимые доработки
5. **Приложите файл** доработанного расширения к задаче, которую реализовывали (через вставку файла в комментарий)

## Дополнительно

- Нежелательно использовать **табличные части** обработок и отчетов (особенности сборки портативных инструментов)
- Желательно придерживаться [стандартов разработки 1С](https://its.1c.ru/db/v8std)
- Для использования чужих обработок нужно разрешение автора или подходящая лицензия
