# Настройка окружения в EDT

Инструкция для доработки подсистемы через 1С:EDT.

## Необходимое ПО

1. **JDK** — скачайте [bellsoft](https://bell-sw.com/pages/downloads/) (рекомендуемая версия — JDK 11)
2. **Платформа 1С** версии 8.3.12 и выше с поддержкой EDT (рекомендуемая — 8.3.15)
3. **1С:EDT** — [скачать](https://edt.1c.ru/docs/new/download.php) версию 2020.5 и выше
4. **БСП** последней версии с режимом совместимости 8.3.12 (например, 3.0.3.341)

## Запуск среды для разработки

### Настройка Git

Выполните настройку Git согласно [инструкции 1С](https://its.1c.ru/db/edtdoc#content:10054:hdoc:t000054__настройки-групповой-разработки).

### Создание fork проекта

1. Создайте fork проекта ветки `develop` в свой репозиторий на GitHub
2. Клонируйте свой репозиторий на локальный ПК:

```bash
git clone https://github.com/ВАШАКАУНТ/tools_ui_1c.git
```

### Создание информационной базы из шаблона БСП

1. Создайте новую базу в 1С из шаблона «Библиотека стандартных подсистем (демо)» → 3.0.3.341
2. Откройте базу в Конфигураторе, перейдите в Расширения, снимите активность со всех расширений и удалите их
3. Примените изменения, закройте Конфигуратор

### Настройка проекта в 1С:EDT

1. Откройте `1CEDT Start`, авторизуйтесь через [аккаунт разработчика](https://developer.1c.ru/)
2. Добавьте **Новый проект**, укажите прикладное решение версии 2021.1.2 (если не установлено — загрузится автоматически)
3. Введите имя проекта и папку
4. Запустите среду EDT, при запуске снова авторизуйтесь
5. Импортируйте проект из GIT из локальной папки (ваш fork)
6. Импортируйте шаблон БСП в Навигатор через которую будет осуществляться запуск и отладка расширения. Имя проекта — **ТестоваяДляРазработкиУИ**
7. Дождитесь окончания загрузки
8. Обновите конфигурацию базы данных из EDT (Shift+F7)

Готово. Можно приступать к разработке.

## Правила разработки

1. Перед началом работы [поищите задачу в issues](https://github.com/cpr1c/tools_ui_1c/issues)
2. Если задачи нет — создайте новую, опишите требования. Обсудите реализацию
3. Сделайте fork проекта, создайте свою ветку на базе `develop`
4. Выполните доработки
5. Сделайте pull-request в проект (выбирайте ветку `develop`, убедитесь что fork синхронизирован)

## Дополнительно

- Нежелательно использовать **табличные части** обработок и отчетов (особенности сборки портативных инструментов)
- Желательно придерживаться [стандартов разработки 1С](https://its.1c.ru/db/v8std)
- Для использования чужих обработок нужно разрешение автора или подходящая лицензия
- Учитывайте [проблемы совместимости платформ](coding-guidelines#совместимость-с-разными-платформами)
