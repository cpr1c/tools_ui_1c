# Разработчикам (внести вклад)

Больше идей — лучше конечное решение. Любая помощь приветствуется :)

## Как можно помочь

### 1. Писать код

Вносить изменения и добавлять новую функциональность.

- [Инструкция для EDT](setup-edt) — настройка среды через 1С:EDT
- [Инструкция для Конфигуратора](setup-configurator) — доработка через Конфигуратор
- [Правила оформления кода](coding-guidelines)
- [Процесс Pull Request](pull-request-process)

### 2. Документация

Писать пользовательские инструкции, делать видеоинструкции. [Инструкция по написанию документации](documentation) — формат файлов, структура, как запустить локально и отправить изменения.

### 3. Тестирование

Искать баги и регистрировать задачи с описанием, как воспроизвести ошибку. Создавайте issue в [GitHub Issues](https://github.com/cpr1c/tools_ui_1c/issues).

### 4. Дизайн

Думать и разрабатывать расположение визуальных элементов. Регистрировать идеи и концепты в задачах проекта.

### 5. Поддержка

Помогать другим пользователям в освоении инструментов. Присоединяйтесь к [Telegram-чату](https://t.me/tools_ui_1c) и отвечайте на вопросы новичков.

### 6. Другое

Любые другие действия, идущие на развитие продукта.

## Кодекс поведения

- Будьте уважительны к другим участникам сообщества
- Конструктивная критика приветствуется
- Перед началом работы над новой функцией создайте issue для обсуждения
