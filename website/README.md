# Универсальные инструменты 1С — сайт документации

Сайт продукта [Универсальные инструменты 1С](https://github.com/cpr1c/tools_ui_1c), построенный на [Docusaurus](https://docusaurus.io/).

## Установка

```bash
npm install
```

## Локальная разработка

```bash
npm start
```

## Сборка

```bash
npm build
```

## Структура

- `src/pages/` — лендинг
- `docs/` — документация по инструментам, руководства и API

Исходный код продукта: [github.com/cpr1c/tools_ui_1c](https://github.com/cpr1c/tools_ui_1c)
